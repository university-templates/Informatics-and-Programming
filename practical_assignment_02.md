## 2.1. Мета роботи

Навчитися реалізовувати алгоритми з розгалуженнями: програма має вибирати, які дії виконувати, залежно від вхідних даних, та коректно обробляти граничні значення.

## 2.2. Навчальні результати

Після виконання роботи студент вміє:

1. Пояснити, що таке логічне значення `True`/`False` і як воно утворюється.
2. Записувати умови за допомогою операторів порівняння та логічних операторів `and`, `or`, `not`.
3. Використовувати конструкції `if`, `if-else`, `if-elif-else`.
4. Записувати вкладені умовні конструкції.
5. Визначати граничні значення й перевіряти програму на них.
6. Порівнювати числа та рядки.
7. Знаходити типові помилки в умовах (`=` замість `==`, неправильний порядок `elif` тощо).

## 2.3. Необхідні знання і навички

З роботи №1: `input()`, `print()`, змінні, типи `int`, `float`, `str`, перетворення типів, арифметичні оператори, f-рядки, функції `math.sqrt()`, `len()`.

## 2.4. Теоретичний мінімум

### 2.4.1. Логічні значення та оператори порівняння

**Означення.** **Логічне значення** (тип `bool`) може бути лише `True` («істина») або `False` («хибність»). Воно виникає як результат **порівняння**.

| Оператор | Значення | Приклад | Результат |
| -------- | -------- | ------- | --------- |
| `==` | дорівнює | `5 == 5` | `True` |
| `!=` | не дорівнює | `5 != 5` | `False` |
| `>` | більше | `7 > 3` | `True` |
| `<` | менше | `7 < 3` | `False` |
| `>=` | більше або дорівнює | `4 >= 4` | `True` |
| `<=` | менше або дорівнює | `4 <= 3` | `False` |

**Приклад.**

```python
age = 18

print(age >= 18)
print(age == 17)
print("abc" == "abc")
print("abc" == "ABC")
```

Очікуваний результат:

```text
True
False
True
False
```

**Пояснення.** Кожне порівняння обчислюється й дає `True` або `False`. Рядки порівнюються символ за символом **з урахуванням регістру**, тому `"abc"` і `"ABC"` — різні рядки.

**Важливо.**

- Знак `=` — це **присвоювання**, а `==` — **порівняння**. Це різні операції.
- Рядок можна порівнювати з рядком, число — з числом. Порівняння `"5" == 5` дає `False` (різні типи), а `"5" > 3` викликає `TypeError`.
- Дійсні числа зберігаються наближено: `0.1 + 0.2 == 0.3` дає `False`. Тому точне порівняння на рівність для дробових результатів обчислень може давати несподіваний результат; для введених користувачем «круглих» значень (наприклад, `3.0 == 3.0`) воно працює.

**Подвійне порівняння.** У Python можна записати «число лежить у проміжку» без `and`:

```python
x = 15
print(10 <= x <= 20)
```

Очікуваний результат:

```text
True
```

### 2.4.2. Логічні оператори `and`, `or`, `not`

| Оператор | Значення | `True`, коли… |
| -------- | -------- | ------------- |
| `A and B` | «і» | істинні **обидві** умови |
| `A or B` | «або» | істинна **хоча б одна** умова |
| `not A` | «не» | умова `A` хибна |

**Приклад.**

```python
age = 20
has_ticket = True

print(age >= 18 and has_ticket)
print(age < 18 or not has_ticket)
print(not (age > 30))
```

Очікуваний результат:

```text
True
False
True
```

**Пояснення.** Перший рядок: обидві умови істинні. Другий: `age < 18` — `False`, `not has_ticket` — `False`, тож `or` дає `False`. Третій: `age > 30` — `False`, `not` перетворює його на `True`.

**Порядок виконання:** спочатку порівняння, потім `not`, потім `and`, потім `or`. Щоб уникнути плутанини, використовуйте круглі дужки.

**Типова помилка.** Запис `x == 1 or 2` не означає «x дорівнює 1 або 2». Правильно: `x == 1 or x == 2`.

### 2.4.3. Конструкція `if`

**Означення.** Умовна конструкція `if` виконує блок команд лише тоді, коли умова істинна.

**Синтаксис.**

```text
if умова:
    команди, які виконуються, якщо умова істинна
```

**Правила запису.**

- Після умови обов'язково ставиться двокрапка `:`.
- Команди, що належать блоку, записуються з **відступом** (рекомендовано 4 пробіли). Відступ показує, які рядки належать блоку.
- Рядок без відступу вже не належить блоку й виконується завжди.

**Приклад.**

```python
temperature = float(input("Temperature: "))

if temperature < 0:
    print("Freezing")

print("Done")
```

Приклад запуску (вводимо `-5`):

```text
Temperature: -5
Freezing
Done
```

Приклад запуску (вводимо `10`):

```text
Temperature: 10
Done
```

**Пояснення.** Рядок `print("Freezing")` має відступ, тому належить блоку `if` і виконується лише при `temperature < 0`. Рядок `print("Done")` стоїть без відступу й виконується завжди.

**Типові помилки.** Забута двокрапка після умови (`SyntaxError`); відсутній відступ у блоці (`IndentationError`); різна кількість пробілів у рядках одного блоку.

### 2.4.4. Конструкція `if–else`

**Синтаксис.**

```text
if умова:
    команди, якщо умова істинна
else:
    команди, якщо умова хибна
```

**Приклад.** Парність числа.

```python
number = int(input("Number: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
```

Приклад запуску (вводимо `7`):

```text
Number: 7
Odd
```

**Пояснення.** Остача від ділення на 2 дорівнює нулю для парних чисел. Виконується рівно одна з двох гілок: або `if`, або `else`.

### 2.4.5. Конструкція `if–elif–else`

**Означення.** Коли варіантів більше двох, додають гілки `elif` («інакше якщо»).

**Синтаксис.**

```text
if умова1:
    команди 1
elif умова2:
    команди 2
elif умова3:
    команди 3
else:
    команди, якщо жодна умова не виконалася
```

**Як це працює.** Умови перевіряються **зверху вниз**. Виконується блок **першої** істинної умови, після цього решта гілок пропускається. Блок `else` необов'язковий і виконується, якщо жодна умова не була істинною.

**Приклад.** Категорія температури.

```python
temperature = float(input("Temperature: "))

if temperature < 0:
    category = "freezing"
elif temperature < 15:
    category = "cold"
elif temperature < 25:
    category = "warm"
else:
    category = "hot"

print(f"Category: {category}")
```

Результати для різних вхідних даних:

| Ввід | Вивід |
| ---- | ----- |
| `-3` | `Category: freezing` |
| `0` | `Category: cold` |
| `14.9` | `Category: cold` |
| `15` | `Category: warm` |
| `25` | `Category: hot` |

**Пояснення.** Значення `0` не менше за 0, тому перша гілка пропускається; друга умова (`< 15`) істинна. Значення `15` потрапляє в третю гілку, а `25` — у `else`. Завдяки перевірці зверху вниз не потрібно записувати нижню межу в кожній умові.

**Типова помилка — неправильний порядок гілок.**

```python
score = 75

if score >= 60:
    print("Pass")
elif score >= 90:
    print("Excellent")
```

Фрагмент завжди виведе тільки `Pass`: умова `score >= 90` ніколи не перевіряється для чисел, що не менші за 60. Гілки слід розташовувати від найвужчої умови до найширшої (тут: спершу `>= 90`, потім `>= 60`).

**Різниця між `elif` і кількома `if`.**

```python
n = 10

if n > 5:
    print("big")
if n > 8:
    print("very big")
```

Очікуваний результат:

```text
big
very big
```

Окремі `if` перевіряються **незалежно**, тому спрацювали обидва. Якщо записати другу умову як `elif`, виведеться лише `big`.

### 2.4.6. Вкладені умовні конструкції

**Означення.** Усередині блоку `if`, `elif` або `else` можна записати інший `if`. Його блок має ще один рівень відступу.

**Приклад.** Перевірка допустимості значення та вибір відповіді.

```python
hour = int(input("Hour (0-23): "))

if 0 <= hour <= 23:
    if hour < 12:
        print("Before noon")
    else:
        print("After noon")
else:
    print("Error: hour must be from 0 to 23")
```

Результати:

| Ввід | Вивід |
| ---- | ----- |
| `9` | `Before noon` |
| `12` | `After noon` |
| `25` | `Error: hour must be from 0 to 23` |

**Пояснення.** Зовнішній `if` перевіряє, чи число допустиме. Лише якщо так, виконується внутрішня перевірка. Такий підхід дозволяє спершу відсіяти некоректні дані, а потім виконувати основні дії.

**Порада.** Якщо вкладеність перевищує два-три рівні, спробуйте об'єднати умови через `and` або перепишіть алгоритм з `elif`.

### 2.4.7. Граничні значення

**Означення.** **Граничні значення** — це значення на межі між двома гілками алгоритму. Саме тут найчастіше трапляються помилки через плутанину `<` і `<=`.

**Правило тестування.** Для умови `x < 15` перевіряйте значення `14.9`, `15`, `15.1`; для проміжків `0 ≤ x ≤ 100` — значення `-1`, `0`, `100`, `101`. Кожне значення, що змінює результат умови, має бути у вашому тестовому наборі.

**Приклад.** Кордони проміжку 60–100.

```python
score = int(input("Score: "))

if 60 <= score <= 100:
    print("Pass")
else:
    print("Not pass")
```

| Ввід | Вивід |
| ---- | ----- |
| `59` | `Not pass` |
| `60` | `Pass` |
| `100` | `Pass` |
| `101` | `Not pass` |

### 2.4.8. Умови для рядків

Рядки порівнюють операторами `==` і `!=`. Для чисел і рядків допустимі `and`, `or`, `not`.

```python
answer = input("Continue? (yes/no): ")

if answer == "yes":
    print("Continuing")
elif answer == "no":
    print("Stopping")
else:
    print("Unknown answer")
```

Результати:

| Ввід | Вивід |
| ---- | ----- |
| `yes` | `Continuing` |
| `no` | `Stopping` |
| `Yes` | `Unknown answer` |

**Пояснення.** Рядок `"Yes"` не дорівнює `"yes"`, бо регістр різний. У завданнях цієї роботи вважайте, що слова вводяться саме так, як зазначено в умові варіанта (малими літерами).

## 2.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- вхідні дані зчитуються через `input()`, кожне значення — окремим запитом, і перетворюються на потрібний тип;
- результати виводяться з підписами, наведеними в умові; дійсні числа — з двома знаками після крапки;
- вказані повідомлення про помилку виводяться **дослівно** (англійською), після чого програма завершується без інших виводів, якщо в умові не сказано інше;
- використовуються лише конструкції з робіт №1–2: цикли, списки, словники, власні функції **не** використовуються;
- в усіх тестових прикладах слова вводяться малими літерами, як у таблиці.

### Варіант 1. Трикутник за трьома сторонами

**Умова.** Програма зчитує довжини трьох сторін `a`, `b`, `c` (дійсні числа). Трикутник існує, якщо всі сторони додатні та сума будь-яких двох сторін **строго більша** за третю. Якщо трикутник існує, програма виводить його тип (`equilateral` — усі сторони рівні, `isosceles` — рівно дві сторони рівні, `scalene` — усі різні) і периметр.

**Формат виводу.** Якщо трикутник існує:

```text
Triangle exists
Type: ...
Perimeter: ...
```

Якщо ні:

```text
Triangle does not exist
```

**Тести.**

| a | b | c | Результат |
| - | - | - | --------- |
| 3 | 4 | 5 | exists, scalene, 12.00 |
| 2 | 2 | 2 | exists, equilateral, 6.00 |
| 2 | 2 | 3 | exists, isosceles, 7.00 |
| 5 | 5 | 8 | exists, isosceles, 18.00 |
| 1 | 2 | 3 | does not exist (сума двох сторін дорівнює третій) |
| 1 | 2 | 4 | does not exist |
| 0 | 2 | 2 | does not exist (нульова сторона) |

---

### Варіант 2. Високосний рік і кількість днів у місяці

**Умова.** Програма зчитує рік (`int`) і номер місяця (`int`). Рік високосний, якщо він ділиться на 4 і не ділиться на 100, **або** ділиться на 400. Програма виводить, чи рік високосний, а також кількість днів у вказаному місяці (у лютому — 28 або 29 залежно від року). Місяці 4, 6, 9, 11 мають 30 днів, решта — 31. Якщо номер місяця не належить проміжку 1–12, замість кількості днів виводиться повідомлення про помилку (рядок про високосний рік виводиться завжди).

**Формат виводу.**

```text
Leap year: yes
Days in month: 29
```

або `Leap year: no`; для некоректного місяця:

```text
Leap year: no
Error: month must be from 1 to 12
```

**Тести.**

| Рік | Місяць | Leap year | Друга лінія |
| --- | ------ | --------- | ----------- |
| 2024 | 2 | yes | Days in month: 29 |
| 2023 | 2 | no | Days in month: 28 |
| 1900 | 2 | no | Days in month: 28 |
| 2000 | 2 | yes | Days in month: 29 |
| 2026 | 4 | no | Days in month: 30 |
| 2026 | 12 | no | Days in month: 31 |
| 2026 | 13 | no | Error: month must be from 1 to 12 |

---

### Варіант 3. Оцінка за шкалою ECTS

**Умова.** Програма зчитує кількість балів (`int`) від 0 до 100 і визначає оцінку за шкалою ECTS та її словесний опис.

| Бали | Оцінка | Опис (`Description`) |
| ---- | ------ | -------------------- |
| 90–100 | A | Excellent |
| 82–89 | B | Very good |
| 74–81 | C | Good |
| 64–73 | D | Satisfactory |
| 60–63 | E | Sufficient |
| 35–59 | FX | Fail, retake allowed |
| 0–34 | F | Fail, repeat the course |

Якщо кількість балів менша за 0 або більша за 100, виводиться лише `Error: score must be from 0 to 100`.

**Формат виводу.**

```text
Grade: B
Description: Very good
```

**Тести (границі).**

| Бали | Grade | Бали | Grade |
| ---- | ----- | ---- | ----- |
| 100 | A | 63 | E |
| 90 | A | 60 | E |
| 89 | B | 59 | FX |
| 82 | B | 35 | FX |
| 81 | C | 34 | F |
| 74 | C | 0 | F |
| 73 | D | 101 | Error |
| 64 | D | -5 | Error |

### Варіант 4. Вартість доставки посилки

**Умова.** Програма зчитує масу посилки в кілограмах (`float`) та тип доставки (`str`): `standard` або `express`. Базова вартість залежить від маси:

| Маса | Базова вартість |

### Варіант 5. Квадратне рівняння

**Умова.** Програма зчитує коефіцієнти `a`, `b`, `c` (дійсні числа) рівняння `a·x² + b·x + c = 0` та розв'язує його.

- Якщо `a ≠ 0`: виводиться дискримінант `D = b² − 4ac`. При `D > 0` — два корені `x1 = (−b + √D) / (2a)` і `x2 = (−b − √D) / (2a)`; при `D = 0` — один корінь `x = −b / (2a)`; при `D < 0` — повідомлення про відсутність дійсних коренів.
- Якщо `a = 0`, рівняння лінійне `b·x + c = 0`: при `b ≠ 0` виводиться `x = −c / b`; при `b = 0` і `c = 0` — нескінченна кількість розв'язків; при `b = 0` і `c ≠ 0` — розв'язків немає.

**Формат виводу.**

```text
Discriminant: 1.00
Two roots: x1 = 2.00, x2 = 1.00
```

Інші варіанти останнього рядка: `One root: x = ...`, `No real roots`, `Linear equation: x = ...`, `Infinite number of solutions`, `No solutions`. Рядок `Discriminant` виводиться лише при `a ≠ 0`.

**Тести.**

| a | b | c | Вивід |
| - | - | - | ----- |
| 1 | -3 | 2 | `Discriminant: 1.00` / `Two roots: x1 = 2.00, x2 = 1.00` |
| 2 | -4 | -6 | `Discriminant: 64.00` / `Two roots: x1 = 3.00, x2 = -1.00` |
| 1 | 2 | 1 | `Discriminant: 0.00` / `One root: x = -1.00` |
| 1 | 1 | 1 | `Discriminant: -3.00` / `No real roots` |
| 0 | 2 | -4 | `Linear equation: x = 2.00` |
| 0 | 0 | 5 | `No solutions` |
| 0 | 0 | 0 | `Infinite number of solutions` |

## 2.12. Типові помилки, яких варто уникати

1. Використання `=` замість `==` в умові (`SyntaxError`).
2. Пропущена двокрапка після `if`, `elif`, `else`.
3. Неправильні або непослідовні відступи (`IndentationError`).
4. Неправильний порядок гілок `elif` (див. приклад із оцінками): умова з вужчим діапазоном має стояти раніше.
5. Плутанина `<` і `<=` на межах діапазонів.
6. Запис `x == 1 or 2` замість `x == 1 or x == 2`.
7. Порівняння рядка з числом (`input()` повертає рядок: `if age > 18` без `int()` викликає `TypeError`).
8. Порівняння дійсних результатів обчислень на точну рівність (наприклад, `0.1 + 0.2 == 0.3`).
