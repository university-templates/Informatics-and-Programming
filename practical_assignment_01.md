### 1.4. Теоретичний мінімум

#### 1.4.1. Що таке програма і як її запустити

**Програма** — це послідовність команд, які комп'ютер виконує по черзі, зверху вниз. **Python** — мова програмування, програми якою зберігаються у файлах із розширенням `.py`.

**Як запустити програму.** Створіть файл `hello.py` з одним рядком:

```python
print("Hello, Python!")
```

Запуск із терміналу (у папці з файлом):

```text
python hello.py
```

(У деяких системах команда називається `python3`.) У середовищах IDLE, VS Code, PyCharm використовуйте кнопку запуску (Run).

Очікуваний результат:

```text
Hello, Python!
```

**Основні правила запису програм.**

- Команди виконуються по одній у кожному рядку, зверху вниз.
- Python розрізняє великі та малі літери: `Price` і `price` — різні імена.
- Коментар починається зі знака `#`; усе, що після нього в рядку, Python ігнорує:

```python
# This line is a comment
print("Hello")  # this is also a comment
```

- Ім'я змінної складається з латинських літер, цифр і знака `_`, не починається з цифри. Прийнято писати малими літерами з підкресленнями: `total_cost`.
- Рядок програми не можна починати з пробілів без потреби (в одних випадках це помилка, у наступних роботах відступи матимуть особливий зміст).

#### 1.4.2. Функція `print()`

**Означення.** `print()` — вбудована функція, яка виводить дані на екран.

**Синтаксис.** `print(значення1, значення2, ...)`

**Навіщо.** Щоб програма показувала результат користувачеві.

**Приклад.** Виведення тексту та чисел.

```python
print("Hello")
print(2 + 3)
print("Sum:", 2 + 3)
```

Очікуваний результат:

```text
Hello
5
Sum: 5
```

**Пояснення.** Текст завжди беруть у лапки (подвійні `"` або одинарні `'`). Вираз `2 + 3` без лапок спочатку обчислюється, потім виводиться. Якщо в `print()` кілька значень через кому, вони виводяться через пропуск. Кожен виклик `print()` починає новий рядок.

**Типова помилка.** Забули закрити лапки: `print("Hello)` — Python повідомить `SyntaxError`.

#### 1.4.3. Змінні та присвоювання

**Означення.** **Змінна** — це ім'я, за яким у пам'яті зберігається значення. **Присвоювання** — команда, яка записує значення у змінну.

**Синтаксис.** `ім'я = значення` (знак `=` тут означає «записати», а не «дорівнює»).

**Навіщо.** Щоб зберігати вхідні дані й проміжні результати та використовувати їх далі.

**Приклад.** Обчислення суми.

```python
first_number = 12
second_number = 8

result = first_number + second_number

print(f"Result: {result}")
```

Очікуваний результат:

```text
Result: 20
```

**Пояснення.** У перших двох рядках у змінні записуються числа. У рядку `result = ...` спочатку обчислюється права частина (12 + 8), потім значення 20 записується у змінну `result`. Змінну можна перезаписати: після `result = 5` попереднє значення втрачається.

Присвоювання, в якому нове значення залежить від старого:

```python
counter = 10
counter = counter + 1
print(counter)
```

Очікуваний результат:

```text
11
```

#### 1.4.4. Типи даних `int`, `float`, `str`

| Тип | Що зберігає | Приклади |
| --- | ----------- | -------- |
| `int` | ціле число | `42`, `-7`, `0` |
| `float` | дійсне число (з дробовою частиною) | `3.14`, `-0.5`, `2.0` |
| `str` | рядок (текст) | `"Python"`, `"42"`, `""` |

**Важливо.** `42`, `42.0` і `"42"` — три різні значення різних типів. Дробову частину в Python відокремлюють **крапкою**: `3.14`, а не `3,14`.

Дізнатися тип значення можна функцією `type()`:

```python
print(type(42))
print(type(42.0))
print(type("42"))
```

Очікуваний результат:

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

**Операції з рядками.** Рядки можна **з'єднувати** знаком `+` (конкатенація) і **повторювати** знаком `*`. Довжину рядка (кількість символів, включно з пробілами) повертає функція `len()`:

```python
first = "Ada"
second = "Lovelace"

full_name = first + " " + second
line = "-" * 10

print(full_name)
print(line)
print(len(full_name))
```

Очікуваний результат:

```text
Ada Lovelace
----------
12
```

**Пояснення.** `first + " " + second` склеює три рядки в один; `"-" * 10` повторює дефіс 10 разів; у `"Ada Lovelace"` 3 + 1 + 8 = 12 символів.

**Типова помилка.** Спроба скласти рядок і число: `"Age: " + 20` викликає `TypeError`. Число потрібно або перетворити на рядок (див. нижче), або скористатися f-рядком.

#### 1.4.5. Арифметичні оператори

| Оператор | Дія | Приклад | Результат |
| -------- | --- | ------- | --------- |
| `+` | додавання | `7 + 2` | `9` |
| `-` | віднімання | `7 - 2` | `5` |
| `*` | множення | `7 * 2` | `14` |
| `/` | ділення (завжди дає `float`) | `7 / 2` | `3.5` |
| `//` | цілочисельне ділення (ціла частина частки) | `7 // 2` | `3` |
| `%` | остача від ділення | `7 % 2` | `1` |
| `**` | піднесення до степеня | `7 ** 2` | `49` |

**Порядок виконання** такий, як у математиці: спочатку `**`, потім `*`, `/`, `//`, `%`, потім `+`, `-`. Круглі дужки змінюють порядок.

**Приклад.** Переведення хвилин у години та хвилини.

```python
total_minutes = 135

hours = total_minutes // 60
minutes = total_minutes % 60

print(f"{hours} h {minutes} min")
```

Очікуваний результат:

```text
2 h 15 min
```

**Пояснення.** 135 ділимо на 60: ціла частина частки — 2 (години), остача — 15 (хвилини). Оператори `//` і `%` часто використовують разом.

**Типова помилка.** Записати `2x` або `a(b+c)` замість `2 * x` та `a * (b + c)`: знак множення в Python обов'язковий.

#### 1.4.6. Функція `input()` і перетворення типів

**Означення.** `input()` зчитує рядок, який користувач ввів із клавіатури й підтвердив клавішею Enter. **Увага: `input()` завжди повертає рядок (`str`)**, навіть якщо користувач ввів число.

**Синтаксис.** `змінна = input("Підказка: ")`

**Перетворення типів.**

| Функція | Дія | Приклад | Результат |
| ------- | --- | ------- | --------- |
| `int(x)` | перетворює на ціле число | `int("15")` | `15` |
| `float(x)` | перетворює на дійсне число | `float("2.5")` | `2.5` |
| `str(x)` | перетворює на рядок | `str(15)` | `"15"` |

Функція `int()` також відкидає дробову частину числа: `int(3.9)` дорівнює `3`.

**Приклад.** Подвоєння числа, яке ввів користувач.

```python
text = input("Enter a number: ")
number = float(text)

doubled = number * 2

print(f"Doubled: {doubled}")
```

Приклад запуску (користувач вводить `2.5`):

```text
Enter a number: 2.5
Doubled: 5.0
```

**Пояснення.** `input()` повернув рядок `"2.5"`. Функція `float()` перетворила його на число `2.5`, після чого можна виконувати арифметику. Часто обидві дії записують в один рядок: `number = float(input("Enter a number: "))`.

**Типові помилки.**

- Не перетворити результат `input()` на число. Тоді `input()` + `input()` з вводом `3` і `4` дасть `"34"`, а не `7`.
- Спробувати перетворити не число: `int("abc")` або `float("2,5")` (кома замість крапки) викликає `ValueError`. Для введення дробових чисел користуйтеся крапкою.
- Застосувати `int("2.5")` до рядка з дробовою частиною: спершу `float("2.5")`, потім за потреби `int(...)`.

#### 1.4.7. Форматування виводу: f-рядки

**Означення.** **f-рядок** — це рядок з буквою `f` перед лапками, усередині якого у фігурних дужках `{}` можна записувати змінні й вирази.

**Навіщо.** Щоб зручно підставляти значення в текст і керувати виглядом чисел.

**Синтаксис.** `f"Текст {вираз} текст"`, `f"{вираз:специфікація}"`.

| Запис | Значення | Приклад (`x = 3.14159`, `n = 7`) | Результат |
| ----- | -------- | -------------------------------- | --------- |
| `{x}` | як є | `f"{x}"` | `3.14159` |
| `{x:.2f}` | 2 знаки після крапки | `f"{x:.2f}"` | `3.14` |
| `{x:.0f}` | без дробової частини (округлення) | `f"{x:.0f}"` | `3` |
| `{n:02d}` | ціле, мінімум 2 цифри, ведучий нуль | `f"{n:02d}"` | `07` |

**Приклад.**

```python
price = 24.5
quantity = 3
total = price * quantity

print(f"Price: {price:.2f}")
print(f"Quantity: {quantity}")
print(f"Total: {total:.2f}")
```

Очікуваний результат:

```text
Price: 24.50
Quantity: 3
Total: 73.50
```

**Пояснення.** Формат `.2f` завжди виводить два знаки після крапки, тому `24.5` стає `24.50`. Форматування змінює лише **вигляд** виводу, а не саме значення змінної.

**Типова помилка.** Забути букву `f` перед лапками: `print("Total: {total:.2f}")` виведе текст буквально, без підстановки.

#### 1.4.8. Лінійний алгоритм

**Означення.** **Лінійний алгоритм** — це алгоритм, у якому всі дії виконуються послідовно, одна за одною, без пропусків і повторень.

Типова структура програми:

1. **Ввід** — зчитати вхідні дані й перетворити їх на потрібні типи.
2. **Обчислення** — виконати розрахунки, зберігаючи проміжні результати в змінних.
3. **Вивід** — показати результат у заданому форматі.

**Приклад.** Периметр і площа прямокутника.

```python
# Input
width = float(input("Width: "))
height = float(input("Height: "))

# Calculation
perimeter = 2 * (width + height)
area = width * height

# Output
print(f"Perimeter: {perimeter:.2f}")
print(f"Area: {area:.2f}")
```

Приклад запуску (вводимо `4` і `2.5`):

```text
Width: 4
Height: 2.5
Perimeter: 13.00
Area: 10.00
```

**Пояснення.** 2 · (4 + 2.5) = 13; 4 · 2.5 = 10. Програма виконує рівно ті команди, що записані, одну за одною.

#### 1.4.9. Модулі та команда `import`

**Означення.** **Модуль** — це файл із готовими інструментами (функціями, константами), які можна підключити до своєї програми. Підключення виконує команда `import`, яку зазвичай пишуть на початку файлу.

**Синтаксис.** `import назва_модуля`, використання — `назва_модуля.інструмент`.

**Модуль `math`** — математичні функції та константи.

| Інструмент | Значення | Приклад | Результат |
| ---------- | -------- | ------- | --------- |
| `math.pi` | число π | `math.pi` | `3.141592653589793` |
| `math.sqrt(x)` | квадратний корінь | `math.sqrt(49)` | `7.0` |
| `math.ceil(x)` | округлення вгору до цілого | `math.ceil(2.1)` | `3` |
| `math.floor(x)` | округлення вниз до цілого | `math.floor(2.9)` | `2` |

```python
import math

radius = 5
area = math.pi * radius ** 2
side = math.sqrt(144)

print(f"Circle area: {area:.2f}")
print(f"Side: {side}")
```

Очікуваний результат:

```text
Circle area: 78.54
Side: 12.0
```

**Модуль `random`** — випадкові числа.

| Інструмент | Значення | Приклад |
| ---------- | -------- | ------- |
| `random.randint(a, b)` | випадкове **ціле** від `a` до `b` включно | `random.randint(1, 6)` |
| `random.random()` | випадкове дійсне число від 0 до 1 | `random.random()` |
| `random.uniform(a, b)` | випадкове дійсне число від `a` до `b` | `random.uniform(1.5, 2.5)` |

```python
import random

die = random.randint(1, 6)
print(f"Die: {die}")
```

Можливий результат (при кожному запуску може бути інший):

```text
Die: 4
```

**Пояснення.** Результат випадковий, тому тестувати такі програми треба за **властивостями** (наприклад, «число завжди від 1 до 6»), а не за конкретним значенням. Програму слід запустити кілька разів.

**Модуль `time`** — робота з часом.

| Інструмент | Значення |
| ---------- | -------- |
| `time.time()` | кількість секунд (`float`), що минули з 1 січня 1970 року |
| `time.strftime("%d.%m.%Y")` | поточна дата у вигляді рядка; `%d` — день, `%m` — місяць, `%Y` — рік; `%H:%M` — години й хвилини |
| `time.localtime().tm_year` | поточний рік (ціле число) |

```python
import time

today = time.strftime("%d.%m.%Y")
year = time.localtime().tm_year

print(f"Today: {today}")
print(f"Year: {year}")
```

Можливий результат (залежить від дня запуску):

```text
Today: 09.10.2026
Year: 2026
```

**Типова помилка.** Забути `import math` і написати `math.sqrt(4)`: буде `NameError: name 'math' is not defined`. Також не називайте власний файл `math.py`, `random.py` чи `time.py`: він «затьмарить» однойменний модуль.

### 1.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- вхідні дані зчитуються за допомогою `input()` (кожне значення — окремим запитом);
- дробові числа вводяться з **крапкою**;
- результати виводяться саме з тими підписами, які зазначено в умові, а дійсні числа — з двома знаками після крапки (якщо не сказано інше);
- програма не перевіряє коректність введення (перевірка введення вивчається пізніше), тому під час тестування вводьте лише дані потрібного типу;
- дозволено використовувати лише змінні, `int`, `float`, `str`, арифметику, `print()`, `input()`, f-рядки та модулі, зазначені в умові.

---

#### Варіант 1. Вартість покупки зі знижкою

**Умова.** Програма зчитує ціну одного товару (`float`), кількість одиниць (`int`) та розмір знижки у відсотках (`float`). Вона обчислює вартість без знижки, суму знижки та підсумкову вартість.

**Формули.** `base = price * quantity`; `discount_amount = base * discount_percent / 100`; `total = base - discount_amount`.

**Формат виводу.**

```text
Base cost: ...
Discount: ...
Total: ...
```

**Тести.**

| Ціна | Кількість | Знижка, % | Base cost | Discount | Total |
| ---- | --------- | --------- | --------- | -------- | ----- |
| 24.50 | 3 | 10 | 73.50 | 7.35 | 66.15 |
| 120.00 | 4 | 25 | 480.00 | 120.00 | 360.00 |
| 100 | 5 | 0 | 500.00 | 0.00 | 500.00 |

---

#### Варіант 2. Відстань між двома точками та середина відрізка

**Умова.** Програма зчитує координати двох точок на площині: `x1`, `y1`, `x2`, `y2` (дійсні числа). Вона обчислює відстань між точками (модуль `math`) та координати середини відрізка.

**Формули.** `distance = sqrt((x2 - x1)² + (y2 - y1)²)`; `mid_x = (x1 + x2) / 2`; `mid_y = (y1 + y2) / 2`.

**Формат виводу.**

```text
Distance: ...
Midpoint: (..., ...)
```

**Тести.**

| x1 | y1 | x2 | y2 | Distance | Midpoint |
| -- | -- | -- | -- | -------- | -------- |
| 1 | 2 | 4 | 6 | 5.00 | (2.50, 4.00) |
| -2 | 5 | 3 | 1 | 6.40 | (0.50, 3.00) |
