### 6.4. Теоретичний мінімум

#### 6.4.1. Вхідні та вихідні файли програми

Програма, що обробляє дані, зазвичай має **вхідний файл** (звідки читає) та **вихідний файл** (куди пише результат). Їхні імена задано в умові варіанта. Правила такі самі, як у роботах №4–5:

- програма й файли лежать в одній папці, програма запускається з цієї папки (`python lab06_variant01.py`);
- вхідний файл відкривається в режимі `"r"`, вихідний — у режимі `"w"` (раніше створений вміст стирається);
- завжди вказується `encoding="utf-8"`;
- усі файли відкриваються через `with open(...)`;
- вхідний файл не змінюється програмою.

#### 6.4.2. Методи рядків

Рядки в Python **незмінні**: метод не змінює рядок, а повертає **новий** рядок, тому результат потрібно записати в змінну.

| Метод | Дія | Приклад | Результат |
| ----- | --- | ------- | --------- |
| `s.strip()` | видаляє пропуски та `\n` на початку й у кінці | `"  Anna\n".strip()` | `"Anna"` |
| `s.split(роздільник)` | розбиває рядок на **список** частин | `"a;b;c".split(";")` | `["a", "b", "c"]` |
| `sep.join(список)` | з'єднує **список рядків** в один рядок через `sep` | `", ".join(["a", "b"])` | `"a, b"` |
| `s.replace(старе, нове)` | замінює всі входження підрядка | `"2,5".replace(",", ".")` | `"2.5"` |
| `s.isdigit()` | `True`, якщо рядок непорожній і складається лише з цифр | `"123".isdigit()` | `True` |

**Приклад.**

```python
line = "  Anna;85;90\n"

clean = line.strip()
parts = clean.split(";")
print(parts)
print(len(parts))
print(parts[0], int(parts[1]) + int(parts[2]))

names = ["Anna", "Ivan", "Olena"]
print(", ".join(names))

price = "2,5"
print(float(price.replace(",", ".")))
```

Очікуваний результат:

```text
['Anna', '85', '90']
3
Anna 175
Anna, Ivan, Olena
2.5
```

**Пояснення.** `strip()` прибирає зайві пропуски й `\n`; `split(";")` перетворює рядок на список із трьох рядків; елементи списку доступні за індексом. Метод `join()` викликають **у роздільника**, а аргументом передають список **рядків** (числа спершу перетворіть: `str(x)`). Метод `replace()` дозволяє замінити десяткову кому на крапку перед `float()`.

**Типові помилки.**

- Викликати `strip()` і не записати результат: `line.strip()` без присвоювання нічого не змінює.
- `", ".join([1, 2])` — `TypeError`, бо елементи не рядки.
- `split()` без аргументів розбиває за пропусками; для іншого роздільника його потрібно вказати.

#### 6.4.3. Перетворення рядків на числа та перевірка коректності

Функції `int()` і `float()` викликають помилку `ValueError`, якщо рядок не є числом. Оскільки в цьому курсі обробка винятків не розглядається, **коректність перевіряють заздалегідь**:

| Що перевіряємо | Умова | `True` для | `False` для |
| -------------- | ----- | ---------- | ----------- |
| невід'ємне ціле | `text.isdigit()` | `"15"`, `"0"` | `"-3"`, `"2.5"`, `"abc"`, `""` |
| невід'ємне дійсне | `text.replace(".", "", 1).isdigit()` | `"15"`, `"2.5"` | `"2.5.1"`, `"abc"`, `""`, `"-2"` |
| поле не порожнє | `text != ""` | `"Anna"` | `""` |
| кількість полів | `len(row) == 4` | рядок із чотирма полями | рядки з меншою чи більшою кількістю |

**Як працює перевірка дійсного числа.** `replace(".", "", 1)` видаляє **одну** крапку (третій аргумент — максимальна кількість замін), і якщо після цього залишилися лише цифри, значення — коректне невід'ємне число. Рядок `"2.5.1"` після видалення першої крапки дає `"25.1"`, де ще лишається крапка, тому `isdigit()` повертає `False`.

```python
values = ["15", "2.5", "-3", "abc", "", "2.5.1"]

for text in values:
    ok = text.replace(".", "", 1).isdigit()
    print(f"{text!r}: {ok}")
```

Очікуваний результат:

```text
'15': True
'2.5': True
'-3': False
'abc': False
'': False
'2.5.1': False
```

**Пояснення.** Запис `{text!r}` у f-рядку виводить значення у лапках (як `repr`), щоб було видно порожній рядок. Негативні числа цією перевіркою відхиляються; у завданнях цієї роботи від'ємних значень немає, а рядок із знаком мінус вважається некоректним.

**Рекомендований порядок перевірок** — від простих до складних: спершу кількість полів, потім непорожність, потім числовий формат, потім змістові обмеження (діапазони, співвідношення). Тільки після успішних перевірок викликайте `int()`/`float()`.

#### 6.4.4. Читання структурованого тексту по рядках

Припустимо, файл `scores.txt` має формат «ім'я;бал;бал» (роздільник — крапка з комою):

```text
Anna;85;90
Ivan;72;abc
Olena;91;95
```

```python
line_number = 0

with open("scores.txt", "r", encoding="utf-8") as file:
    for line in file:
        line_number += 1
        parts = line.strip().split(";")
        if len(parts) == 3 and parts[1].isdigit() and parts[2].isdigit():
            total = int(parts[1]) + int(parts[2])
            print(f"{parts[0]}: {total}")
        else:
            print(f"Line {line_number}: invalid")
```

Очікуваний результат:

```text
Anna: 175
Line 2: invalid
Olena: 186
```

**Пояснення.** Лічильник `line_number` нумерує рядки файлу з 1. Кожен рядок очищується, розбивається на частини й перевіряється; некоректні рядки пропускаються з повідомленням.

#### 6.4.5. Формат CSV та модуль `csv`

**Означення.** **CSV** (Comma-Separated Values) — текстовий формат таблиці: кожен рядок файлу — рядок таблиці, значення розділені комою. Перший рядок найчастіше містить **заголовок** — назви стовпців.

Приклад файлу `scores.csv`:

```text
name,math,physics
Anna,85,90
Ivan,72,abc
Olena,91,95
```

**Чому недостатньо `split(",")`.** Значення може саме містити кому; тоді його беруть у лапки: `"Groceries, market"`. Метод `split(",")` розірве такий рядок неправильно, а модуль `csv` правильно обробляє лапки.

**Модуль `csv`** входить до стандартної бібліотеки; його підключають командою `import csv`.

**Читання.** Функція `csv.reader(file)` створює об'єкт, який у циклі `for` повертає кожен рядок файлу як **список рядків**. Файл для csv відкривають із параметром `newline=""`. Функція `next(reader)` забирає наступний (тут — перший) рядок, її використовують, щоб пропустити заголовок.

```python
import csv

line_number = 1
valid_count = 0
invalid_lines = []

with open("scores.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.reader(file)
    header = next(reader)

    for row in reader:
        line_number += 1
        if len(row) == 3 and row[1].isdigit() and row[2].isdigit():
            valid_count += 1
        else:
            invalid_lines.append(line_number)

print(f"Header: {header}")
print(f"Valid rows: {valid_count}")
print(f"Invalid lines: {invalid_lines}")
```

Очікуваний результат:

```text
Header: ['name', 'math', 'physics']
Valid rows: 2
Invalid lines: [3]
```

**Пояснення.** Заголовок займає рядок 1, тому `line_number` починається з 1 і збільшується на початку кожної ітерації: перший рядок даних має номер 2. Кожен `row` — список із полями, до яких звертаються за індексами. Номери некоректних рядків накопичуються в списку.

**Інший роздільник.** Для файлів із роздільником `;` або табуляцією передають параметр `delimiter`:

```python
reader = csv.reader(file, delimiter=";")
```

**Запис.** Функція `csv.writer(file)` створює об'єкт, метод `writerow(список)` записує один рядок (значення з лапками, якщо потрібно, екранує сам модуль). Файл відкривають у режимі `"w"` також із `newline=""`.

```python
import csv

results = [["Anna", 87.5], ["Olena", 93.0]]

with open("result.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "average"])
    for item in results:
        writer.writerow([item[0], f"{item[1]:.2f}"])
```

Вміст `result.csv`:

```text
name,average
Anna,87.50
Olena,93.00
```

**Типові помилки.**

- Забути `newline=""` при відкритті файлу для `csv`: у вихідному файлі можуть з'явитися зайві порожні рядки.
- Не пропустити заголовок: `int("math")` або `"math".isdigit()` стають джерелом помилки/хибних результатів.
- Забути, що **всі** поля з `csv.reader` — рядки; числа треба перетворювати.
- Звертатися до `row[3]` без перевірки `len(row)`: для короткого рядка — `IndexError`.

#### 6.4.6. Типовий шаблон програми обробки файлу

1. Відкрити вхідний файл, пропустити заголовок.
2. Для кожного рядка: перевірити кількість полів, непорожність і формат чисел. Якщо рядок некоректний — запам'ятати його номер і перейти до наступного. Якщо коректний — перетворити поля й додати їх до підсумків (лічильників, сум, словників).
3. Після циклу обчислити підсумкові показники (середні, мінімуми, найкращі).
4. Записати результати у вихідний файл та/або вивести на екран.

**Некоректні рядки не призводять до завершення програми**: вони пропускаються й обліковуються. Якщо коректних рядків немає, програма виводить `No valid data` і не виконує обчислень (щоб уникнути ділення на нуль).

**Формування рядка з номерами некоректних рядків.** Номери зберігають у списку цілих чисел; щоб з'єднати їх методом `join()`, їх спершу перетворюють на рядки:

```python
invalid_lines = [5, 7, 10]
texts = []
for number in invalid_lines:
    texts.append(str(number))

print(f"Invalid rows: {len(invalid_lines)} (lines: {', '.join(texts)})")
```

Очікуваний результат:

```text
Invalid rows: 3 (lines: 5, 7, 10)
```

### 6.5. Індивідуальні завдання

Номер варіанта визначає викладач. Для кожного варіанта нижче наведено **повний приклад вхідного файлу з реалістичними даними** та очікуваний результат.

#### Загальні правила для всіх варіантів

- Перший рядок файлу — **заголовок** (рядок 1). Рядки даних нумеруються з 2.
- Файли розташовано в одній папці з програмою; вхідний файл відкривається з `encoding="utf-8"`, для CSV — додатково `newline=""`; вихідні файли також відкриваються з `encoding="utf-8"`.
- Для варіантів 1–11 вхідний файл читається модулем `csv` (`csv.reader`), для варіанта 12 — `csv.reader` з параметром `delimiter=";"`.
- Рядок даних **некоректний**, якщо кількість його полів не дорівнює кількості полів заголовка, будь-яке поле порожнє, або числове поле не відповідає опису в умові (використовуйте перевірки з розділу 6.4.3, `isdigit()` для цілих і `replace(".", "", 1).isdigit()` для дійсних). Додаткові обмеження зазначено в умові варіанта.
- Некоректні рядки не впливають на підсумки. Кількість та номери некоректних рядків виводяться у форматі `Invalid rows: k (lines: a, b, c)`; якщо таких рядків немає — `Invalid rows: 0`.
- Якщо коректних рядків немає (наприклад, у файлі лише заголовок), програма виводить `No valid data` замість підсумків (для варіантів із вихідним CSV-файлом у ньому записується лише заголовок).
- Дійсні числа у виводі — з двома знаками після крапки, якщо не зазначено інше.
- Використовуються лише конструкції з робіт №1–6; власні функції, класи, генератори, `try/except` не використовуються. Перевірки «чи число» — лише методами рядків.
- Для кожного варіанта наведено три тести: основний, «лише заголовок» і мінімальний файл.
- У варіанті 12 файл `errors.txt` «порожній» означає, що файл створено, але рядків у ньому немає.

Програма обчислює середню оцінку кожного студента `(math + physics + informatics) / 3`, записує її у файл `result.csv` (заголовок `student,average`, середнє з двома знаками) і виводить на екран кількість оброблених студентів, студента з найвищим середнім (за рівності — першого) та кількість «відмінників» (середнє не менше 90).

### 6.12. Типові помилки, яких варто уникати

1. Не пропущено заголовок CSV — програма намагається перетворити назви стовпців на числа.
2. Перетворення `int()`/`float()` виконується без попередньої перевірки (`ValueError` на некоректному рядку).
3. Звернення до `row[3]` без перевірки `len(row)` (`IndexError` на короткому рядку).
4. Забутий `newline=""` у `open()` для `csv` (зайві порожні рядки у вихідному файлі).
5. Результат методу рядка не збережено (`s.strip()` без присвоювання).
6. Використання `split(",")` для рядків, що містять коми в лапках, замість `csv.reader`.
7. Неправильна нумерація рядків: заголовок не враховано як рядок 1 або лічильник збільшується не на кожній ітерації.
8. Ділення на кількість коректних рядків, коли вона дорівнює нулю (`ZeroDivisionError`).
9. Забутий `encoding="utf-8"` або `"\n"` у кінці рядків вихідного текстового файлу.
10. Порушення порядку виведення (за першою появою ключа), використання нестандартного формату чисел або підписів, відмінних від умови.
