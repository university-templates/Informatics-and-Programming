## Практична робота №5. Словники та структуровані дані

**Максимум: 10 балів.**
**Орієнтовний час виконання: 2–3 години.**

### 5.1. Мета роботи

Навчитися зберігати дані у вигляді пар «ключ — значення» у словниках, поєднувати словники зі списками для опису об'єктів предметної області, а також зберігати такі дані у текстових файлах і читати їх звідти.

### 5.2. Навчальні результати

Після виконання роботи студент вміє:

1. Пояснити різницю між списком і словником і вибрати доцільну структуру.
2. Створювати словники, читати та змінювати значення, додавати й видаляти записи.
3. Використовувати методи `keys()`, `values()`, `items()`, `get()` та оператор `in` для ключів.
4. Перебирати словники в циклах, застосовувати шаблон «лічильник за ключем».
5. Описувати об'єкти предметної області словниками, зберігати їх у списках, а списки — як значення в словниках.
6. Зберігати дані словника у файлі й відновлювати їх із файлу.

### 5.3. Необхідні знання і навички

З робіт №1–4: змінні й типи, `input()`, `print()`, f-рядки, `if/elif/else`, цикли `while` і `for`, `range()` (зокрема з кроком), списки та їхні методи, функції `len()`, `sum()`, `min()`, `max()`, оператор `in`, читання та запис текстових файлів (`with open`, `read()`, `readlines()`, `write()`, `encoding="utf-8"`).

### 5.4. Теоретичний мінімум

#### 5.4.1. Що таке словник і чим він відрізняється від списку

**Означення.** **Словник** (`dict`) — це набір пар «**ключ** → **значення**». За ключем можна швидко знайти відповідне значення, як слово в тлумачному словнику чи прізвище в телефонній книзі.

| Властивість | Список | Словник |
| ----------- | ------ | ------- |
| Звернення до елемента | за номером (індексом): `a[2]` | за ключем: `d["Anna"]` |
| Для чого | впорядкований набір однотипних значень | зіставлення «назва → дані» |
| Дублікати | елементи можуть повторюватися | ключі **унікальні** |
| Приклад | оцінки: `[85, 72, 91]` | оцінки за іменами: `{"Anna": 85, "Ivan": 72}` |

**Коли що обирати.** Якщо головне — порядок і номер значення (виміри за днями), доцільний список. Якщо значення потрібно знаходити за назвою чи кодом (оцінка за прізвищем, ціна за назвою товару, кількість за словом) — словник.

Ключем може бути рядок або число (`int`). Значенням — що завгодно, зокрема список чи інший словник.

#### 5.4.2. Створення словника, читання та зміна значень

**Синтаксис.** Пари `ключ: значення` записують у фігурних дужках через кому.

```python
prices = {"bread": 25.0, "milk": 38.5, "eggs": 65.0}
empty = {}

print(prices["milk"])
prices["milk"] = 40.0
prices["apple"] = 30.0
print(prices)
print(len(prices))
```

Очікуваний результат:

```text
38.5
{'bread': 25.0, 'milk': 40.0, 'eggs': 65.0, 'apple': 30.0}
4
```

**Пояснення.** `prices["milk"]` читає значення за ключем. Присвоювання `prices["milk"] = 40.0` змінює значення наявного ключа; присвоювання з **новим** ключем (`"apple"`) додає запис. Функція `len()` повертає кількість пар. Порядок записів збігається з порядком їх додавання.

**Типова помилка.** Звернення до неіснуючого ключа (`prices["juice"]`) викликає `KeyError: 'juice'`. Перед зверненням перевіряють ключ оператором `in` або користуються методом `get()`.

#### 5.4.3. Перевірка ключа, метод `get()`, видалення записів

**Оператор `in`** для словника перевіряє наявність **ключа**.

```python
prices = {"bread": 25.0, "milk": 38.5}

print("milk" in prices)
print("juice" in prices)
print(prices.get("milk"))
print(prices.get("juice"))
print(prices.get("juice", 0))
```

Очікуваний результат:

```text
True
False
38.5
None
0
```

**Пояснення.** `d.get(ключ)` повертає значення або спеціальне значення `None` («нічого»), якщо ключа немає, і **не викликає помилки**. Другий аргумент `d.get(ключ, значення)` задає значення за замовчуванням.

**Видалення.**

| Запис | Дія |
| ----- | --- |
| `del d[ключ]` | видаляє запис; якщо ключа немає — `KeyError` |
| `d.pop(ключ)` | видаляє запис і повертає його значення |

```python
stock = {"apple": 10, "pear": 5}

removed = stock.pop("pear")
del stock["apple"]

print(removed)
print(stock)
```

Очікуваний результат:

```text
5
{}
```

#### 5.4.4. Методи `keys()`, `values()`, `items()` та перебір словника

| Метод | Що повертає |
| ----- | ----------- |
| `d.keys()` | усі ключі |
| `d.values()` | усі значення |
| `d.items()` | пари «ключ, значення» |

Їх використовують у циклах і з функціями `len()`, `sum()`, `min()`, `max()`.

```python
marks = {"Anna": 85, "Ivan": 72, "Olena": 91}

for name in marks:
    print(name)

for name, mark in marks.items():
    print(f"{name}: {mark}")

print(sum(marks.values()))
print(max(marks.values()))
```

Очікуваний результат:

```text
Anna
Ivan
Olena
Anna: 85
Ivan: 72
Olena: 91
248
91
```

**Пояснення.** Цикл `for name in marks` обходить **ключі**. Цикл `for name, mark in marks.items()` на кожній ітерації дає ключ і значення в двох змінних одночасно. Функції `sum()` та `max()` застосовано до значень.

**Пошук ключа з найбільшим значенням** виконують у циклі, подібно до пошуку максимуму в роботі №3:

```python
best_name = ""
best_mark = -1
for name, mark in marks.items():
    if mark > best_mark:
        best_name = name
        best_mark = mark

print(best_name, best_mark)
```

Для словника `marks` вище виведе `Olena 91`. Через строге порівняння `>` при рівних значеннях залишається ключ, що зустрівся першим.

**Типова помилка.** Змінювати словник (додавати чи видаляти ключі) під час перебору цього ж словника. Щоб відібрати записи, створюйте новий словник або список.

#### 5.4.5. Шаблон «лічильник за ключем»

Часта задача: порахувати, скільки разів зустрівся кожен елемент, або підсумувати значення за групами. Метод `get()` з нульовим значенням за замовчуванням робить це в один рядок:

```python
votes = ["red", "blue", "red", "green", "red", "blue"]
counts = {}

for color in votes:
    counts[color] = counts.get(color, 0) + 1

print(counts)
```

Очікуваний результат:

```text
{'red': 3, 'blue': 2, 'green': 1}
```

**Пояснення.** Якщо кольору ще немає в словнику, `get()` повертає `0`, і записується `0 + 1`; якщо вже є — значення збільшується на 1. Аналогічно підсумовують суми за категоріями:

```python
totals[category] = totals.get(category, 0) + amount
```

#### 5.4.6. Поєднання списків і словників

**Словник як опис об'єкта.** Один об'єкт предметної області (книга, студент, товар) зручно описувати словником, де ключі — назви властивостей:

```python
book = {"title": "Kobzar", "author": "Taras Shevchenko", "year": 1840}
print(book["title"])
print(f"{book['title']} ({book['year']})")
```

Очікуваний результат:

```text
Kobzar
Kobzar (1840)
```

**Зверніть увагу:** усередині f-рядка, обмеженого подвійними лапками, ключі словника записують в **одинарних** лапках (`book['title']`), інакше рядок завершиться передчасно.

**Список словників** зберігає набір однотипних об'єктів:

```python
books = []
books.append({"title": "Kobzar", "year": 1840})
books.append({"title": "Moses", "year": 1905})

for book in books:
    print(book["title"], book["year"])
```

Очікуваний результат:

```text
Kobzar 1840
Moses 1905
```

**Словник зі списками як значеннями** групує кілька значень під одним ключем:

```python
cities = ["Kyiv", "Lviv", "Kyiv"]
temps = [5.0, 3.5, 7.0]
readings = {}

for i in range(len(cities)):
    city = cities[i]
    if city not in readings:
        readings[city] = []
    readings[city].append(temps[i])

print(readings)
print(sum(readings["Kyiv"]) / len(readings["Kyiv"]))
```

Очікуваний результат:

```text
{'Kyiv': [5.0, 7.0], 'Lviv': [3.5]}
6.0
```

**Пояснення.** Для кожного міста, що зустрілося вперше, створюється порожній список; потім до нього додається температура. Вираз `readings["Kyiv"]` повертає список, до якого можна застосувати `sum()` і `len()`.

#### 5.4.7. Метод рядка `strip()`

Під час читання файлу кожен рядок завершується символом `"\n"`. Для чисел це не заважає (`int("85\n")` дорівнює `85`), але **рядок**, який використовується як ключ словника або виводиться, потрібно очистити. Метод `strip()` видаляє пропуски та символ переходу на новий рядок на початку й у кінці рядка:

```python
line = "Anna\n"
name = line.strip()

print(repr(line))
print(repr(name))
```

Очікуваний результат:

```text
'Anna\n'
'Anna'
```

**Типова помилка.** Забути `strip()`: тоді ключ `"Anna\n"` не дорівнює ключу `"Anna"`, який користувач ввів із клавіатури, і пошук у словнику не знаходить запису. Докладніше про методи рядків — у роботі №6.

#### 5.4.8. Зберігання словника у файлі та читання з файлу

У цій роботі використовується простий формат: **кожен запис займає кілька послідовних рядків** файлу. Для словника «ім'я → оцінка» це два рядки на запис: у першому — ключ, у другому — значення.

Приклад файлу `input.txt`:

```text
Anna
85
Ivan
72
Olena
91
```

**Читання.** Усі рядки зчитують у список методом `readlines()` і обходять із кроком 2:

```python
marks = {}

with open("input.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

for i in range(0, len(lines), 2):
    name = lines[i].strip()
    mark = int(lines[i + 1])
    marks[name] = mark

print(marks)
```

Очікуваний результат:

```text
{'Anna': 85, 'Ivan': 72, 'Olena': 91}
```

**Пояснення.** `range(0, len(lines), 2)` дає індекси `0, 2, 4`, тобто рядки з іменами; значення лежить у наступному рядку (`i + 1`). Ім'я очищається методом `strip()`, число перетворюється функцією `int()`. Повторне ім'я у файлі **перезапише** значення в словнику, бо ключі унікальні.

**Запис.**

```python
with open("output.txt", "w", encoding="utf-8") as file:
    for name, mark in marks.items():
        file.write(f"{name}\n")
        file.write(f"{mark}\n")
```

Файл `output.txt` матиме той самий формат, що й `input.txt`. Завдяки цьому результат однієї програми може бути вхідними даними для іншої.

**Типові помилки.**

- Непарна кількість рядків у файлі: `lines[i + 1]` викликає `IndexError`.
- Порожній рядок у кінці файлу: `int("\n")` викликає `ValueError`.
- Відсутній `"\n"` у `write()`: пари зливаються в один рядок.

#### 5.4.9. Типові помилки зі словниками

1. `KeyError` — звернення до відсутнього ключа через `d[key]`; використовуйте `in` чи `get()`.
2. Дублювання ключів: другий запис із тим самим ключем **замінює** перший, а не додається.
3. Ключем не можна зробити список (`d[[1, 2]] = 5` — помилка); використовуйте рядок або число.
4. Плутанина між ключем і значенням при переборі: `for x in d` дає ключі, а не значення.
5. Забутий `strip()` у ключах, прочитаних із файлу.
6. Зміна розміру словника під час перебору.

### 5.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах (крім зазначених в умові):

- вхідні дані читаються з файлу `input.txt`, результати записуються у файл `output.txt`; файли розташовано в одній папці з програмою;
- у файлах **кожен запис займає один або кілька послідовних рядків** — формат зазначено в умові; порожніх рядків немає, файл завершується переходом на новий рядок;
- файли відкриваються через `with open(...)` з `encoding="utf-8"`;
- дійсні числа у вихідних даних — з двома знаками після крапки, якщо не зазначено інше; підписи — англійською, як у прикладах;
- використовуються лише конструкції з робіт №1–5 та `strip()`; методи `split()`, `join()`, `replace()`, модуль `csv` і власні функції **не** використовуються;
- словники застосовуються як основна структура даних (де це вказано — разом зі списками);
- для кожного тесту вказано вміст вхідного файлу та очікуваний результат.

Запис тестових даних: у блоках «`input.txt`» кожен елемент через кому — це окремий рядок файлу, якщо не показано блок коду з рядками.

#### Варіант 1. Оцінки студентів

**Умова.** Файл `input.txt` складається з пар рядків: ім'я студента та його оцінка (ціле число). Програма зберігає дані у словнику «ім'я → оцінка» (якщо ім'я повторюється, зберігається **остання** оцінка) і записує в `output.txt`: кількість студентів, середню оцінку, студента з найвищою оцінкою (за рівності — першого за порядком у словнику) та імена студентів, чия оцінка **нижча за середню** (у порядку словника; якщо таких немає — `none`).

**Формат `output.txt`.**

```text
Students: ...
Average: ...
Best: ... (...)
Below average:
(імена по одному в рядку або none)
```

**Тест 1.** `input.txt`: `Anna`, `85`, `Ivan`, `72`, `Olena`, `91`, `Petro`, `60`, `Maria`, `78`.

```text
Students: 5
Average: 77.20
Best: Olena (91)
Below average:
Ivan
Petro
```

**Тест 2.** `input.txt`: `Anna`, `85`.

```text
Students: 1
Average: 85.00
Best: Anna (85)
Below average:
none
```

**Тест 3 (повторне ім’я).** `input.txt`: `Anna`, `50`, `Ivan`, `70`, `Anna`, `90`.

```text
Students: 2
Average: 80.00
Best: Anna (90)
Below average:
Ivan
```

#### Варіант 2. Частота значень

**Умова.** Файл `input.txt` містить цілі числа, по одному в рядку. Програма за допомогою словника «число → кількість появ» підраховує, скільки разів зустрілося кожне значення, і записує в `output.txt` рядки `число: кількість` у порядку першої появи числа, а також найчастіше значення (за однакової частоти — те, що з'явилося першим).

**Формат `output.txt`.**

```text
(значення: кількість)
Most frequent: ... (... times)
```

**Тест 1.** `input.txt`: `3`, `5`, `3`, `2`, `5`, `3`.

```text
3: 3
5: 2
2: 1
Most frequent: 3 (3 times)
```

**Тест 2.** `input.txt`: `4`, `4`, `7`, `7`.

```text
4: 2
7: 2
Most frequent: 4 (2 times)
```

**Тест 3.** `input.txt`: `9`.

```text
9: 1
Most frequent: 9 (1 times)
```

#### Варіант 3. Складські залишки та замовлення

**Умова.** Файл `input.txt` складається з пар рядків: назва товару та кількість на складі (ціле число). Якщо товар повторюється, його кількості **додаються**. Програма зберігає залишки у словнику, а потім у циклі приймає замовлення з клавіатури: запитує назву товару (`Product:`), а якщо введено `end` — завершує приймання; інакше запитує кількість (`Amount:`, ціле число). Обробка замовлення:

- товару немає в словнику — виводиться `Unknown product`;
- замовлено більше, ніж є, — виводиться `Not enough: available N` (де `N` — залишок), залишок не змінюється;
- інакше залишок зменшується на замовлену кількість; якщо він став рівним 0, запис **видаляється** зі словника.

Наприкінці програма записує в `output.txt` залишки у форматі `товар: кількість` (у порядку словника).

**Тест 1.** `input.txt`: `apple`, `10`, `pear`, `5`, `plum`, `8`, `apple`, `5` (залишок яблук — 15). Замовлення: `apple` — `15`; `pear` — `7`; `kiwi` — `1`; `plum` — `3`; `end`.

На екрані:

```text
Not enough: available 5
Unknown product
```

`output.txt`:

```text
pear: 5
plum: 5
```

**Тест 2.** `input.txt`: `apple`, `4`. Замовлення: одразу `end`.

`output.txt`:

```text
apple: 4
```

**Тест 3.** `input.txt`: `apple`, `2`. Замовлення: `apple` — `2`; `end`. Запис про яблука видалено, `output.txt` **порожній**.

#### Варіант 4. Облік витрат за категоріями

**Умова.** Файл `input.txt` складається з пар рядків: категорія витрат та сума (дійсне число). ### 5.12. Типові помилки, яких варто уникати

1. Звернення до відсутнього ключа через `d[key]` (`KeyError`) замість перевірки `in` або `get()`.
2. Забутий `strip()` у ключах, прочитаних із файлу: ключ зберігається з символом `"\n"`.
3. Плутанина ключа та значення; перебір `for x in d` замість `for key, value in d.items()`, коли потрібні обидва.
4. Зміна словника під час перебору.
5. Очікування, що повторний ключ додасть другий запис (насправді він перезапише перший).
6. Пошук найкращого значення з початковим значенням `0`, коли значення можуть бути від'ємними чи меншими за початкове; неврахування порожнього словника.
7. Забутий `encoding="utf-8"` при роботі з кириличними даними (варіант 10).
8. Відкриття файлу для запису в циклі.
9. Ділення на кількість елементів без перевірки на порожній список/словник.
10. Використання складних структур там, де достатньо простого списку, або навпаки — зберігання пар «назва — значення» у двох паралельних списках замість словника.
