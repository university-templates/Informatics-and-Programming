### 4.4. Теоретичний мінімум

#### 4.4.1. Поняття послідовності та список

**Означення.** **Послідовність** — це впорядкований набір значень, у якому кожне значення має свій номер (індекс). Рядок `str` уже є послідовністю символів. **Список** (`list`) — це змінювана послідовність довільних значень.

**Навіщо.** Раніше для кожного значення потрібна була окрема змінна, а в роботі №3 ми обробляли значення по одному й «забували» їх. Список дозволяє зберегти багато значень під одним іменем і повертатися до них: обчислити середнє, а потім знайти числа, більші за середнє.

**Синтаксис.** Значення записують у квадратних дужках через кому.

```python
temperatures = [12.5, 14.0, 9.5]
names = ["Anna", "Ivan", "Olena"]
empty = []
```

Список може містити значення різних типів, але на практиці зазвичай зберігають однотипні значення.

#### 4.4.2. Індексація та зміна елементів

**Індекс** — номер елемента. Нумерація починається з **нуля**. Від'ємні індекси рахують з кінця: `-1` — останній елемент.

**Приклад.**

```python
marks = [85, 52, 60, 97]

print(marks[0])
print(marks[3])
print(marks[-1])

marks[1] = 55
print(marks)
print(len(marks))
```

Очікуваний результат:

```text
85
97
97
[85, 55, 60, 97]
4
```

**Пояснення.** `marks[0]` — перший елемент, `marks[-1]` — останній. Присвоювання `marks[1] = 55` замінює другий елемент. Функція `len()` повертає кількість елементів. Допустимі індекси — від `0` до `len(marks) - 1`.

**Типова помилка.** Звернення за неіснуючим індексом (`marks[4]` для списку з 4 елементів) викликає `IndexError: list index out of range`.

#### 4.4.3. Додавання та видалення елементів

| Метод | Дія | Приклад |
| ----- | --- | ------- |
| `a.append(x)` | додає `x` в **кінець** списку | `a.append(5)` |
| `a.insert(i, x)` | вставляє `x` на позицію `i`, зсуваючи решту | `a.insert(0, 5)` |
| `a.remove(x)` | видаляє **перше** входження значення `x` | `a.remove(5)` |
| `a.pop()` | видаляє й повертає **останній** елемент | `last = a.pop()` |
| `a.pop(i)` | видаляє й повертає елемент з індексом `i` | `first = a.pop(0)` |

**Приклад.**

```python
a = [10, 20, 30]

a.append(40)
a.insert(1, 15)
a.remove(30)
last = a.pop()

print(a)
print(last)
```

Очікуваний результат:

```text
[10, 15, 20]
40
```

**Пояснення.** Після `append(40)`: `[10, 20, 30, 40]`. Після `insert(1, 15)`: `[10, 15, 20, 30, 40]`. `remove(30)` видаляє значення 30: `[10, 15, 20, 40]`. `pop()` забирає останній елемент `40` і повертає його в змінну `last`; у списку залишається `[10, 15, 20]`.

**Типові помилки.**

- `a.remove(x)` для значення, якого немає в списку, викликає `ValueError`. Перед видаленням перевіряйте наявність за допомогою оператора `in`.
- `a.pop()` для порожнього списку викликає `IndexError`.

**Оператор `in`.** Вираз `x in a` дає `True`, якщо значення `x` є в списку, інакше `False`; `x not in a` — навпаки.

```python
fruits = ["apple", "pear"]

print("pear" in fruits)
print("plum" in fruits)
print("plum" not in fruits)
```

Очікуваний результат:

```text
True
False
True
```

#### 4.4.4. Функції `len()`, `min()`, `max()`, `sum()`

| Функція | Значення |
| ------- | -------- |
| `len(a)` | кількість елементів |
| `min(a)` | найменший елемент (список не порожній) |
| `max(a)` | найбільший елемент (список не порожній) |
| `sum(a)` | сума елементів (для порожнього списку — `0`) |

```python
values = [4, 9, 1, 6]

print(len(values), min(values), max(values), sum(values))
average = sum(values) / len(values)
print(f"Average: {average:.2f}")
```

Очікуваний результат:

```text
4 1 9 20
Average: 5.00
```

**Типова помилка.** `min([])`, `max([])` викликають `ValueError`, а `sum(a) / len(a)` для порожнього списку дає ділення на нуль. Якщо список може бути порожнім, спершу перевірте `if len(a) == 0:`.

#### 4.4.5. Обхід списків за допомогою циклів

**За елементами:**

```python
prices = [10.0, 25.5, 4.0]
total = 0

for price in prices:
    total += price

print(f"Total: {total:.2f}")
```

Очікуваний результат:

```text
Total: 39.50
```

**За індексами** (потрібні, коли важливий номер елемента):

```python
marks = [85, 52, 60, 97]

for i in range(len(marks)):
    print(f"Mark {i + 1}: {marks[i]}")
```

Очікуваний результат:

```text
Mark 1: 85
Mark 2: 52
Mark 3: 60
Mark 4: 97
```

**Пояснення.** `range(len(marks))` дає індекси `0, 1, 2, 3`. Для людей нумерацію зручніше показувати з 1, тому виводимо `i + 1`.

**Створення нового списку з відібраних елементів.** Спочатку створюють порожній список, а потім у циклі додають у нього потрібні елементи:

```python
marks = [85, 52, 60, 97, 59]
passed = []

for mark in marks:
    if mark >= 60:
        passed.append(mark)

print(passed)
```

Очікуваний результат:

```text
[85, 60, 97]
```

**Типова помилка.** Не видаляйте й не додавайте елементи до списку **під час** обходу цього самого списку: цикл поведе себе непередбачувано. Створюйте новий список, як у прикладі вище.

**Зворотний обхід** виконується через `range` із від'ємним кроком:

```python
a = [3, 8, 1]
for i in range(len(a) - 1, -1, -1):
    print(a[i])
```

Очікуваний результат:

```text
1
8
3
```

#### 4.4.6. Файли: відкриття та режими

**Означення.** **Текстовий файл** зберігає символи. Програма може читати з файлу дані, підготовлені заздалегідь, і записувати в файл результати.

**Де шукається файл.** Якщо вказано лише ім'я (`"input.txt"`), Python шукає файл у **поточній папці** — тій, з якої запущено програму. Тому розташуйте програму та файли в одній папці й запускайте програму з неї:

```text
cd шлях/до/вашої/папки
python lab04_variant01.py
```

**Синтаксис.**

```text
with open("ім'я_файлу", "режим", encoding="utf-8") as file:
    команди роботи з файлом
```

**Режими відкриття.**

| Режим | Призначення | Якщо файл існує | Якщо файлу немає |
| ----- | ----------- | --------------- | ---------------- |
| `"r"` | читання | читається | помилка `FileNotFoundError` |
| `"w"` | запис | **вміст стирається** | файл створюється |
| `"a"` | дописування в кінець | вміст зберігається | файл створюється |

**Навіщо `with`.** Конструкція `with open(...) as file:` автоматично закриває файл, коли блок завершується (навіть якщо виникла помилка). Закритий файл гарантовано збережений. Завжди користуйтеся саме `with`.

**Навіщо `encoding="utf-8"`.** `UTF-8` — стандартне кодування, яке підтримує українські літери та інші символи. Якщо не вказати кодування, на деяких комп'ютерах (особливо Windows) файл може прочитатися або записатися некоректно. Тому вказуйте `encoding="utf-8"` завжди.

#### 4.4.7. Запис у файл

Метод `file.write(текст)` записує рядок. **Перехід на новий рядок не додається автоматично** — його потрібно дописати символом `"\n"`.

**Приклад.**

```python
numbers = [3, 8, 5]

with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Numbers:\n")
    for number in numbers:
        file.write(f"{number}\n")
    file.write(f"Sum: {sum(numbers)}\n")
```

Вміст файлу `output.txt` після виконання:

```text
Numbers:
3
8
5
Sum: 16
```

**Пояснення.** Режим `"w"` створює файл (або стирає старий вміст). Кожен виклик `write()` дописує текст; символ `\n` завершує рядок. Метод `write()` приймає лише рядок: числа перетворюють через f-рядок або `str()`.

**Дописування.** Якщо відкрити той самий файл у режимі `"a"` і записати `file.write("End\n")`, рядок `End` з'явиться після існуючого вмісту.

**Типова помилка.** Забути `"\n"` — усі значення опиняться в одному рядку (`"first"` + `"second"` дає `firstsecond`). Інша помилка — відкрити файл для запису в режимі `"w"` у циклі: на кожній ітерації вміст стиратиметься. Відкривайте файл один раз до циклу.

#### 4.4.8. Читання файлу: цілком і по рядках

Припустимо, є файл `data.txt`:

```text
10
20
30
```

(кожне число в окремому рядку, після останнього рядка — перехід на новий рядок).

**Спосіб 1. Прочитати весь файл як один рядок — `read()`.**

```python
with open("data.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(len(text))
print(repr(text))
```

Очікуваний результат:

```text
9
'10\n20\n30\n'
```

**Пояснення.** `read()` повертає весь вміст як один рядок, у якому є символи переходу на новий рядок `\n`. Усього 9 символів: `1`, `0`, `\n`, `2`, `0`, `\n`, `3`, `0`, `\n`. Функція `repr()` показує рядок у «службовому» вигляді, щоб бачити `\n`.

**Спосіб 2. Читати по рядках — цикл `for line in file`.**

```python
numbers = []

with open("data.txt", "r", encoding="utf-8") as file:
    for line in file:
        numbers.append(int(line))

print(numbers)
print(sum(numbers))
```

Очікуваний результат:

```text
[10, 20, 30]
60
```

**Пояснення.** Цикл по файлу на кожній ітерації дає один рядок разом із завершальним `\n` (тобто `"10\n"`). Функції `int()` та `float()` ігнорують пропуски й переходи на новий рядок по краях, тому `int("10\n")` дорівнює `10`. Таким чином файл «один елемент на рядок» перетворюється на список чисел.

**Спосіб 3. Метод `readlines()`** повертає **список** усіх рядків файлу (разом із `\n`):

```python
with open("data.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

print(lines)
print(len(lines))
```

Очікуваний результат:

```text
['10\n', '20\n', '30\n']
3
```

**Коли що використовувати.**

- `read()` — коли потрібен весь текст цілком (наприклад, порахувати символи).
- Цикл `for line in file` — коли потрібно обробляти дані по рядках (найчастіший випадок, не завантажує файл у пам'ять повністю).
- `readlines()` — коли потрібні всі рядки відразу у вигляді списку (кількість рядків, доступ за індексом).

**Виведення рядка файлу.** Якщо вивести рядок через `print(line)`, між рядками з'являться порожні рядки (бо `print` додає свій `\n` до вже наявного). Щоб цього уникнути, пишіть `print(line, end="")`.

**Порожні рядки.** Порожній рядок у файлі при читанні дає `"\n"`. Тому `int("\n")` викликає `ValueError`. Файли з числами не повинні містити порожніх рядків (також і в кінці).

**Типові помилки.**

- Неправильне ім'я файлу або запуск з іншої папки: `FileNotFoundError`.
- Читання з файлу, відкритого в режимі `"w"`, і запис у файл, відкритий у режимі `"r"`.
- Використання змінної `file` за межами блоку `with`: файл уже закрито.
- Забули перетворити рядок на число: `"10\n" + "20\n"` склеює текст.

#### 4.4.9. Шаблон програми «файл → список → обробка → файл»

```python
# Read numbers from input file into a list
numbers = []
with open("input.txt", "r", encoding="utf-8") as file:
    for line in file:
        numbers.append(float(line))

# Process data
count = len(numbers)
total = sum(numbers)

# Write results to output file
with open("output.txt", "w", encoding="utf-8") as file:
    file.write(f"Count: {count}\n")
    file.write(f"Sum: {total:.2f}\n")
```

Для `input.txt` із вмістом `2.5`, `4`, `1.5` (по одному в рядку) файл `output.txt` міститиме:

```text
Count: 3
Sum: 8.00
```

### 4.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах (крім зазначених в умові):

- вхідні дані читаються з файлу `input.txt`, результати записуються у файл `output.txt`; обидва файли розташовані в одній папці з програмою;
- у файлі `input.txt` **одне значення в рядку**, без порожніх рядків; файл завершується переходом на новий рядок;
- файли відкриваються через `with open(...)` із `encoding="utf-8"`;
- дійсні числа записуються у вихідний файл із двома знаками після крапки (якщо не зазначено інше), підписи — англійською, як у прикладах;
- використовуються лише списки, цикли, умови та конструкції з робіт №1–4; словники, функції `split()`, `strip()` та інші методи рядків не використовуються;
- для кожного тесту вказано вміст `input.txt` та очікуваний вміст `output.txt`.

#### Варіант 1. Добові температури

**Умова.** У файлі `input.txt` записано добові температури (дійсні числа). Програма читає їх у список і записує в `output.txt`: кількість днів, найменшу й найбільшу температуру, середню температуру та кількість днів, температура яких **вища за середню**. Якщо файл порожній, у `output.txt` записується єдиний рядок `No data`.

**Формат `output.txt`.**

```text
Days: ...
Min: ...
Max: ...
Average: ...
Days above average: ...
```

**Тест 1.** `input.txt` (7 рядків): `12.5`, `14.0`, `9.5`, `11.0`, `15.5`, `13.0`, `8.0`.

```text
Days: 7
Min: 8.00
Max: 15.50
Average: 11.93
Days above average: 4
```

**Тест 2.** `input.txt`: один рядок `5`.

```text
Days: 1
Min: 5.00
Max: 5.00
Average: 5.00
Days above average: 0
```

**Тест 3.** `input.txt` порожній.

```text
No data
```

#### Варіант 2. Оцінки з предмета

**Формат `output.txt`.**


#### Варіант 3. Знижка на дорогі товари

**Умова.** У файлі `input.txt` записано ціни товарів (дійсні числа). На товари, ціна яких **строго більша за 100**, діє знижка 10 %. Програма записує в `output.txt` нові ціни (у тому самому порядку, по одній у рядку, з двома знаками), а потім загальну вартість усіх товарів до знижки та після неї.

**Формат `output.txt`.**

```text
(нові ціни по одній у рядку)
Total before: ...
```

### 4.11. Критерії оцінювання (максимум 10 балів)

| Критерій | Максимум балів | Вимоги для отримання балів |
| -------- | -------------- | -------------------------- |

### 4.12. Типові помилки, яких варто уникати

1. Звернення до елемента за індексом, що виходить за межі списку (`a[len(a)]`); плутанина нумерації з 0 та з 1.
2. Видалення або додавання елементів у список під час обходу цього самого списку.
3. Виклик `remove()` без перевірки наявності елемента (`ValueError`), `min()`, `max()`, `pop()` для порожнього списку.
4. Ділення на `len(a)` для порожнього списку (ділення на нуль).
5. Відкриття файлу для запису в режимі `"w"` усередині циклу: на кожній ітерації вміст стирається.
6. Забутий `"\n"` у `write()`: усе записується в один рядок.
7. Відсутність `encoding="utf-8"` у `open()`.
8. Спроба записати в `write()` число без перетворення на рядок (`TypeError`).
9. Використання змінної файлу після виходу з блоку `with`; запуск програми з іншої папки (`FileNotFoundError`).
10. Порожній рядок (зокрема в кінці) у файлі з числами: `int("\n")` і `float("\n")` викликають `ValueError`.
