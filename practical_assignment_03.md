### 3.4. Теоретичний мінімум

#### 3.4.1. Навіщо потрібні цикли

**Означення.** **Цикл** — це конструкція, яка багаторазово виконує один і той самий блок команд. Одне виконання блоку називається **ітерацією**.

Без циклів, щоб вивести числа від 1 до 100, довелося б написати 100 команд `print()`. Цикл робить це кількома рядками. У Python є два цикли: `while` (виконується, поки істинна умова) та `for` (виконується задану кількість разів або для кожного значення з набору).

#### 3.4.2. Цикл `while`

**Означення.** Цикл `while` повторює блок команд, **поки умова істинна**. Умова перевіряється **перед кожною ітерацією**.

**Синтаксис.**

```text
while умова:
    команди (тіло циклу)
```

Тіло циклу записується з відступом, як і блок `if`.

**Приклад.** Зворотний відлік.

```python
count = 3

while count > 0:
    print(count)
    count = count - 1

print("Start!")
```

Очікуваний результат:

```text
3
2
1
Start!
```

**Пояснення.** Спочатку `count` дорівнює 3, умова `count > 0` істинна — виводиться 3 і `count` зменшується до 2. Так повторюється, поки `count` не стане 0. Тоді умова хибна, цикл завершується, і виконується рядок після циклу.

**Три обов'язкові частини циклу `while`:**

1. **Початкове значення** змінної, яка входить в умову (`count = 3`).
2. **Умова** продовження (`count > 0`).
3. **Зміна** змінної в тілі циклу (`count = count - 1`). Без неї цикл ніколи не завершиться.

**Скорочений запис.** Замість `count = count - 1` можна писати `count -= 1`. Аналогічно: `x += 5` означає `x = x + 5`; також є `*=`, `//=` та інші.

**Типові помилки.**

- Не змінюється змінна умови — виникає **нескінченний цикл** (див. 3.4.10).
- Умова хибна з самого початку — тіло циклу не виконається жодного разу (це не помилка, але про це треба пам'ятати).

#### 3.4.3. Лічильники та накопичувачі

**Лічильник** — змінна, яка збільшується на фіксоване значення (зазвичай на 1) і рахує кількість подій.

**Накопичувач** — змінна, у яку на кожній ітерації додається (або множиться) нове значення, щоб отримати суму чи добуток.

**Початкові значення.** Для суми накопичувач починають з `0`, для добутку — з `1`, для лічильника — з `0`.

**Приклад.** Сума й кількість чисел від 1 до 5, що вводяться з клавіатури.

```python
count = 0
total = 0

while count < 5:
    value = float(input("Enter a number: "))
    total += value
    count += 1

print(f"Count: {count}")
print(f"Sum: {total:.2f}")
```

Приклад запуску (вводимо `2`, `4.5`, `1`, `3`, `0.5`):

```text
Enter a number: 2
Enter a number: 4.5
Enter a number: 1
Enter a number: 3
Enter a number: 0.5
Count: 5
Sum: 11.00
```

**Пояснення.** `count` рахує введені числа й керує завершенням, `total` накопичує суму: 2 + 4.5 + 1 + 3 + 0.5 = 11. Числа обробляються **по одному**: їх не потрібно зберігати всі, достатньо поточного значення й накопичувача.

#### 3.4.4. Цикл `for` і функція `range()`

**Означення.** Цикл `for` виконує тіло для кожного значення з набору. Найчастіше набір створює функція `range()`.

**Синтаксис.**

```text
for змінна in range(...):
    команди
```

**Три форми `range()`:**

| Запис | Які значення проходить змінна |
| ----- | ----------------------------- |
| `range(n)` | `0, 1, …, n-1` |
| `range(a, b)` | `a, a+1, …, b-1` (число `b` **не входить**) |
| `range(a, b, step)` | від `a` з кроком `step`, поки не досягнуто `b` (`b` не входить); `step` може бути від'ємним |

**Приклад.**

```python
for i in range(3):
    print(i)

for i in range(1, 6):
    print(i, end=" ")
print()

for i in range(10, 0, -3):
    print(i, end=" ")
print()
```

Очікуваний результат:

```text
0
1
2
1 2 3 4 5 
10 7 4 1 
```

**Пояснення.** `range(3)` дає 0, 1, 2. `range(1, 6)` дає 1, 2, 3, 4, 5 (число 6 не входить). `range(10, 0, -3)` рухається від 10 вниз із кроком 3: 10, 7, 4, 1. Параметр `end=" "` у `print()` замінює перехід на новий рядок пропуском; порожній `print()` після циклу переводить виведення на новий рядок.

**Коли який цикл використовувати.**

- `for` — коли кількість повторень відома заздалегідь (n чисел, значення від 1 до n).
- `while` — коли кількість повторень залежить від умови (поки не введено 0, поки сума не перевищить поріг).

**Типова помилка.** Забути, що верхня межа `range` не входить: `range(1, 10)` дає числа до 9, а не до 10. Для чисел від 1 до `n` пишуть `range(1, n + 1)`.

Якщо змінна циклу не потрібна в тілі, за традицією її позначають `_`: `for _ in range(5):`.

#### 3.4.5. Суми та добутки

**Приклад.** Факторіал `n! = 1 · 2 · … · n`.

```python
n = int(input("n: "))

factorial = 1
for i in range(1, n + 1):
    factorial *= i

print(f"{n}! = {factorial}")
```

Результати:

| Ввід `n` | Вивід |
| -------- | ----- |
| `5` | `5! = 120` |
| `1` | `1! = 1` |
| `0` | `0! = 1` |

**Пояснення.** Добуток починається з 1. Для `n = 0` діапазон `range(1, 1)` порожній, цикл не виконується, і результат залишається 1 — це збігається з математичним означенням `0! = 1`. Початкове значення накопичувача важливе саме для таких «порожніх» випадків.

#### 3.4.6. Мінімум і максимум серед значень, що вводяться послідовно

Щоб знайти найбільше значення, не зберігаючи всі числа, використовують змінну-«рекордсмена»: у неї записують перше введене число, а потім порівнюють із кожним наступним.

**Приклад.** Найбільше з `n` введених чисел.

```python
n = int(input("How many numbers: "))

biggest = float(input("Number 1: "))
for i in range(2, n + 1):
    value = float(input(f"Number {i}: "))
    if value > biggest:
        biggest = value

print(f"Max: {biggest:.2f}")
```

Приклад запуску (`n = 4`, числа `3`, `-1`, `8`, `5`):

```text
How many numbers: 4
Number 1: 3
Number 2: -1
Number 3: 8
Number 4: 5
Max: 8.00
```

**Пояснення.** `biggest` починається з першого числа. На кожній ітерації, якщо нове число більше за поточного «рекордсмена», воно його замінює. Для мінімуму достатньо змінити знак порівняння на `<`.

**Типова помилка.** Починати «рекордсмена» з `0` — якщо всі числа від'ємні, результат буде неправильним (`0` залишиться «найбільшим»). Правильно починати з першого введеного значення.

**Запам'ятовування позиції.** Щоб знати, на якому кроці було знайдено максимум, додають змінну `position` і оновлюють її разом із `biggest`:

```python
if value > biggest:
    biggest = value
    position = i
```

Оскільки порівняння **строге** (`>`), при кількох однакових максимумах позиція залишається першою.

#### 3.4.7. Умови завершення циклу

Є три типові способи керувати завершенням циклу.

**1. За лічильником** — кількість відома (`for i in range(n)`).

**2. За умовою** — цикл триває, поки виконується умова, що залежить від обчислень:

```python
balance = 100.0
years = 0

while balance < 150:
    balance *= 1.1
    years += 1

print(f"Years: {years}")
print(f"Balance: {balance:.2f}")
```

Очікуваний результат:

```text
Years: 5
Balance: 161.05
```

**Пояснення.** Кожного року сума збільшується на 10 %: 110, 121, 133.1, 146.41, 161.05. Після п'ятого кроку сума перевищила 150 і цикл завершився.

**3. За «сторожовим» значенням** — спеціальне значення, яке означає «кінець введення» (наприклад, `0`). Спочатку читають перше значення, потім у циклі обробляють і читають наступне:

```python
count = 0
total = 0.0

value = float(input("Number (0 to stop): "))
while value != 0:
    total += value
    count += 1
    value = float(input("Number (0 to stop): "))

print(f"Count: {count}")
print(f"Sum: {total:.2f}")
```

Приклад запуску (вводимо `5`, `3`, `-2`, `0`):

```text
Number (0 to stop): 5
Number (0 to stop): 3
Number (0 to stop): -2
Number (0 to stop): 0
Count: 3
Sum: 6.00
```

**Пояснення.** «Сторож» `0` не додається до суми й не рахується. Зверніть увагу на **подвійне читання**: одне перед циклом, друге — в кінці тіла. Якщо користувач одразу введе `0`, цикл не виконається, `Count` буде 0.

**Типова помилка.** Забути друге читання `input()` в кінці тіла — значення не змінюється, і цикл стає нескінченним.

#### 3.4.8. Вкладені цикли

**Означення.** **Вкладений цикл** — це цикл усередині іншого циклу. Внутрішній цикл виконується повністю на кожній ітерації зовнішнього.

**Приклад.** Таблиця множення на 3 рядки та 4 стовпчики.

```python
for i in range(1, 4):
    for j in range(1, 5):
        print(f"{i * j:3d}", end="")
    print()
```

Очікуваний результат:

```text
  1  2  3  4
  2  4  6  8
  3  6  9 12
```

**Пояснення.** Зовнішній цикл вибирає рядок `i`, внутрішній проходить стовпчики `j` і виводить добуток без переходу на новий рядок (`end=""`). Формат `:3d` резервує під ціле число 3 позиції, вирівнюючи його праворуч. Після завершення внутрішнього циклу порожній `print()` переходить на новий рядок. Загальна кількість виконань внутрішнього тіла: 3 · 4 = 12.

**Типова помилка.** Неправильний відступ: якщо `print()` у кінці рядка записати з відступом внутрішнього циклу, перехід на новий рядок відбуватиметься після кожного числа.

#### 3.4.9. Дільники та цифри числа

Два прийоми, потрібні для кількох варіантів.

**Перевірка подільності:** `n % d == 0` означає, що `d` є дільником `n`.

**Розбір числа на цифри:** остача `n % 10` — остання цифра, а `n // 10` — число без останньої цифри.

```python
number = 4075
digit_sum = 0

while number > 0:
    digit = number % 10
    digit_sum += digit
    number //= 10

print(f"Digit sum: {digit_sum}")
```

Очікуваний результат:

```text
Digit sum: 16
```

**Пояснення.** Цифри відокремлюються по черзі: 5, 7, 0, 4. Сума 5 + 7 + 0 + 4 = 16. Коли `number` стає 0, цикл завершується.

#### 3.4.10. Нескінченні цикли та типові помилки

**Нескінченний цикл** — цикл, умова якого завжди істинна. Програма «зависає». Щоб примусово її зупинити, натисніть `Ctrl + C` у терміналі.

```python
n = 5
while n > 0:
    print(n)
# n never changes: infinite loop
```

**Як уникнути.**

1. Перед запуском переконайтеся, що в тілі циклу змінюється змінна з умови.
2. Переконайтеся, що зміна рухає значення **в бік** завершення (не `+= 1` для умови `n > 0`).
3. Перевірте цикл на найменших вхідних даних і на «порожньому» випадку.

**Інші типові помилки.**

- «Зсув на одиницю» (off-by-one): `range(n)` замість `range(1, n + 1)`.
- Накопичувач не обнулено перед циклом або обнулено всередині циклу.
- Початкове значення мінімуму/максимуму вибране довільно (наприклад, `0`).
- Неправильний відступ для команд, які мають виконуватися після циклу.

### 3.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- вхідні дані зчитуються через `input()` по одному, **без збереження всіх значень** (списки та інші колекції не використовуються);
- підказки для `input()` можуть бути довільними, але виведені результати мають збігатися за змістом і форматом з умовою (підписи англійською, дійсні числа — з двома знаками після крапки, якщо не зазначено інше);
- кількість введених чисел, де вона потрібна, вводиться першою;
- програма не перевіряє коректність введення, окрім випадків, зазначених в умові;
- використовуються лише конструкції з робіт №1–3.

---

#### Варіант 1. Сума та середнє значення до нуля

**Умова.** Користувач вводить дійсні числа по одному; введення завершується числом `0` (воно в обчисленнях не бере участі). Програма виводить кількість введених чисел, їхню суму та середнє арифметичне. Якщо жодного числа введено не було, виводиться лише `No numbers entered`.

**Формат виводу.**

```text
Count: ...
Sum: ...
Average: ...
```

**Тести.**

| Послідовність вводу | Вивід |
| ------------------- | ----- |
| `5`, `3`, `8`, `2`, `0` | Count: 4 / Sum: 18.00 / Average: 4.50 |
| `-2`, `4`, `0` | Count: 2 / Sum: 2.00 / Average: 1.00 |
| `0` | No numbers entered |
| `10`, `0` | Count: 1 / Sum: 10.00 / Average: 10.00 |

---

#### Варіант 2. Факторіал і сума квадратів

**Умова.** Програма зчитує ціле число `n` (`0 ≤ n ≤ 20`) і обчислює факторіал `n!` та суму квадратів `1² + 2² + … + n²`. Обидва значення обчислюються в одному циклі `for`.

**Формат виводу.**

```text
Factorial: ...
Sum of squares: ...
```

**Тести.**

| n | Factorial | Sum of squares |
| - | --------- | -------------- |
| 5 | 120 | 55 |
| 0 | 1 | 0 |
| 1 | 1 | 1 |
| 10 | 3628800 | 385 |

---

#### Варіант 3. Мінімум, максимум і їхні позиції

**Умова.** Спершу вводиться кількість чисел `n` (`n ≥ 1`), потім `n` дійсних чисел по одному. Програма виводить найменше й найбільше число та **номери** (починаючи з 1) їхніх **перших** появ.

**Формат виводу.**

```text
Min: ... (position ...)
Max: ... (position ...)
```

**Тести.**

| n | Числа | Вивід |
| - | ----- | ----- |
| 5 | `4`, `-2`, `9`, `9`, `0` | Min: -2.00 (position 2) / Max: 9.00 (position 3) |
| 1 | `7` | Min: 7.00 (position 1) / Max: 7.00 (position 1) |
| 4 | `-5`, `-1`, `-8`, `-3` | Min: -8.00 (position 3) / Max: -1.00 (position 2) |
| 3 | `2`, `2`, `2` | Min: 2.00 (position 1) / Max: 2.00 (position 1) |

---

#### Варіант 4. Цифри числа

**Умова.** Програма зчитує натуральне число `n` і, розбираючи його на цифри циклом `while`, обчислює кількість цифр, суму цифр та число, записане цифрами у зворотному порядку. Ведучі нулі результату відкидаються (число `1000` дає `1`).

**Формат виводу.**

```text
Digits: ...
Digit sum: ...
Reversed: ...
```

**Тести.**

| n | Digits | Digit sum | Reversed |
| - | ------ | --------- | -------- |
| 12345 | 5 | 15 | 54321 |
| 1000 | 4 | 1 | 1 |
| 7 | 1 | 7 | 7 |
| 9081 | 4 | 18 | 1809 |

---

#### Варіант 5. Таблиця добутків

**Умова.** Програма зчитує кількість рядків `n` і стовпчиків `m` (натуральні числа). За допомогою вкладених циклів вона виводить таблицю, в якій на перетині рядка `i` та стовпчика `j` стоїть добуток `i * j`; кожне число займає 4 позиції (формат `:4d`). Після таблиці виводиться сума всіх чисел таблиці.

**Формат виводу.**

| Правильність алгоритму циклу | 3 | **3** — алгоритм правильний, обрано доцільний тип циклу, лічильники й накопичувачі мають правильні початкові значення, цикл завершується, результати збігаються з очікуваними в усіх тестах. **2** — алгоритм загалом правильний, але є помилка в одному тесті (наприклад, на мінімальному випадку). **1** — алгоритм працює лише для частини тестів. **0** — алгоритм неправильний або програма «зависає». |

### 3.12. Типові помилки, яких варто уникати

1. Нескінченний цикл `while` через те, що змінна умови не змінюється або змінюється в «неправильний» бік.
2. Забуте повторне читання `input()` в кінці тіла циклу зі «сторожовим» значенням.
3. Помилка «на одиницю»: `range(n)` замість `range(1, n + 1)`; забули, що верхня межа `range` не входить.
4. Накопичувач не обнулено перед циклом або обнулено всередині циклу.
5. Початкове значення добутку `0` замість `1` (добуток завжди 0).
6. Мінімум/максимум ініціалізовано довільним числом (`0`, `100`) замість першого введеного значення.
7. Неправильні відступи: команда, яка має виконатись один раз після циклу, потрапила в тіло, або навпаки.
8. Зміна змінної, за якою йде `for` (`i`), всередині тіла циклу в надії вплинути на ітерації: це не працює так, як очікується.
9. Використання списку для зберігання всіх введених значень там, де достатньо обробляти їх по одному (в цій роботі колекції не дозволені).
10. Відсутність перевірки «порожнього» випадку (перше ж введене `0`, `n = 1`, `n = 0`) і ділення на нуль при обчисленні середнього.
