## 7.1. Мета роботи

Навчитися розбивати програму на логічні частини за допомогою власних функцій, передавати в них дані через параметри, повертати результати через `return`, документувати функції та перевіряти їх на прикладах.

## 7.2. Навчальні результати

Після виконання роботи студент вміє:

1. Оголошувати й викликати власні функції за допомогою `def`.
2. Використовувати параметри, аргументи (позиційні й іменовані) та значення параметрів за замовчуванням.
3. Повертати результат через `return` і пояснити різницю між `print()` та `return`.
4. Розрізняти локальні змінні та змінні головної частини програми.
5. Розбивати алгоритм на кілька логічних функцій, кожна з яких виконує одну задачу.
6. Давати функціям змістовні імена та документувати їх рядком документації.
7. Перевіряти функції на прикладах (виклик — очікуваний результат).

## 7.3. Необхідні знання і навички

З робіт №1–6: типи, `input()`, `print()`, f-рядки, умови, цикли, списки, словники, методи рядків (`split()`, `strip()`, `join()`, `replace()`, `isdigit()`), читання та запис файлів, модуль `math`.

## 7.4. Теоретичний мінімум

### 7.4.1. Навіщо потрібні функції

**Означення.** **Функція** — це іменований блок команд, який можна викликати за іменем у різних місцях програми. Ви вже користувалися готовими функціями: `print()`, `input()`, `len()`, `sum()`, `math.sqrt()`. Тепер ви навчитеся створювати власні.

**Навіщо.**

- **Повторне використання коду:** одна й та сама дія записується один раз, а викликається багаторазово.
- **Декомпозиція:** велику задачу розбивають на невеликі підзадачі, кожну з яких розв'язує окрема функція; так програму легше писати, читати й перевіряти.
- **Перевірка:** функцію можна перевірити окремо від решти програми.

### 7.4.2. Оголошення та виклик функції

**Синтаксис.**

```text
def ім'я_функції(параметри):
    команди (тіло функції)
```

Тіло записується з відступом (4 пробіли), як у `if` та циклах. **Оголошення функції саме по собі нічого не виконує** — функція виконується лише тоді, коли її **викликають**: `ім'я_функції(аргументи)`.

**Приклад.** Функція без параметрів.

```python
def print_line():
    print("-" * 20)

print_line()
print("Report")
print_line()
```

Очікуваний результат:

```text
--------------------
Report
--------------------
```

**Пояснення.** Рядок `def print_line():` оголошує функцію. Далі вона викликається двічі. Функцію потрібно оголосити **раніше**, ніж викликати: у файлі її `def` має стояти вище за перший виклик.

### 7.4.3. Параметри та аргументи

**Параметр** — це змінна в дужках при оголошенні функції; **аргумент** — це значення, яке передають при виклику.

```python
def print_rectangle_area(width, height):
    area = width * height
    print(f"Area: {area:.2f}")

print_rectangle_area(4, 2.5)
print_rectangle_area(10, 3)
```

Очікуваний результат:

```text
Area: 10.00
Area: 30.00
```

**Пояснення.** При першому виклику `width` отримує `4`, `height` — `2.5`. Аргументи передаються за **порядком** (позиційні). Можна також передавати за **іменем**: `print_rectangle_area(height=2.5, width=4)` — порядок тоді не важливий.

**Типова помилка.** Неправильна кількість аргументів: `print_rectangle_area(4)` викликає `TypeError: ... missing 1 required positional argument`.

### 7.4.4. Оператор `return`. Різниця між `print()` і `return`

**Оператор `return значення`** завершує виконання функції й **повертає** значення туди, де функцію було викликано. Результат можна записати у змінну, використати у виразі або передати в іншу функцію.

```python
def rectangle_area(width, height):
    return width * height

area = rectangle_area(4, 2.5)
double_area = rectangle_area(4, 2.5) * 2

print(area)
print(double_area)
```

Очікуваний результат:

```text
10.0
20.0
```

**Різниця між `print()` і `return`.**

| `print()` | `return` |
| --------- | -------- |
| показує значення **на екрані** людині | **передає** значення програмі (у місце виклику) |
| після нього значення «втрачається» — його не можна використати далі | значення можна зберегти й використовувати далі |
| функція, що лише виводить, повертає `None` | функція повертає обчислений результат |

```python
def area_print(width, height):
    print(width * height)

def area_return(width, height):
    return width * height

a = area_print(4, 2.5)
b = area_return(4, 2.5)

print(a)
print(b)
```

Очікуваний результат:

```text
10.0
None
10.0
```

**Пояснення.** Рядок `a = area_print(4, 2.5)` виводить `10.0` (цей вивід зробила сама функція), але у змінну `a` потрапляє `None` — спеціальне значення «нічого», бо функція нічого не повертає. Змінна `b` отримала `10.0`.

**Правило.** Функції, які **обчислюють**, повертають результат через `return`; виводити результат на екран має **головна частина** програми (або окрема функція, призначена для виведення). Це дозволяє використовувати такі функції повторно й перевіряти їх.

**Особливості `return`.**

- Після виконання `return` функція негайно завершується; наступні рядки не виконуються.
- Функція може мати кілька `return` в різних гілках умови.
- Якщо виконання дійшло до кінця функції без `return`, повертається `None`.

```python
def is_even(number):
    if number % 2 == 0:
        return True
    return False

print(is_even(10))
print(is_even(7))
```

Очікуваний результат:

```text
True
False
```

**Типові помилки.** Написати `print()` замість `return` і потім використати результат (отримати `None`); забути `return` у гілці `else`; використати `return` усередині циклу так, що функція завершується на першій ітерації, хоча мала пройти весь цикл.

### 7.4.5. Локальні змінні

Змінні, створені всередині функції (включно з параметрами), — **локальні**: вони існують лише під час виконання функції й недоступні ззовні.

```python
def double(number):
    result = number * 2
    return result

print(double(21))
print(result)
```

Перший `print` виводить `42`, а другий викликає `NameError: name 'result' is not defined`, бо `result` існує лише всередині `double()`.

**Правило.** Щоб функція отримала дані — передавайте їх через **параметри**; щоб передати результат назовні — **повертайте** його через `return`. Не покладайтеся на змінні головної частини програми всередині функцій.

**Списки й словники як аргументи.** Функція може отримувати й повертати списки та словники. Якщо функція **змінює** список, переданий як аргумент (наприклад, `append()`), змінюється й сам список у місці виклику. Тому функції, що відбирають дані, краще створювати **новий** список і повертати його:

```python
def only_positive(numbers):
    result = []
    for number in numbers:
        if number > 0:
            result.append(number)
    return result

data = [3, -1, 0, 8, -5]
print(only_positive(data))
print(data)
```

Очікуваний результат:

```text
[3, 8]
[3, -1, 0, 8, -5]
```

### 7.4.6. Значення параметрів за замовчуванням

Параметру можна задати значення, яке використовується, якщо аргумент не передали:

```python
def add_tax(amount, rate=20):
    return amount * (1 + rate / 100)

print(add_tax(100))
print(add_tax(100, 10))
```

Очікуваний результат:

```text
120.0
110.00000000000001
```

**Пояснення.** У першому виклику `rate` бере значення за замовчуванням (`20`), у другому — передане `10`. Результат `110.00000000000001` — звичайна неточність обчислень із дійсними числами; для порівняння використовуйте округлення (див. 7.4.8), а для виводу — формат `:.2f`.

**Правило.** Параметри зі значеннями за замовчуванням записують **після** параметрів без значень: `def f(a, b=5)` — правильно, `def f(a=5, b)` — помилка.

### 7.4.7. Декомпозиція, імена й документування

**Декомпозиція** — розбиття задачі на підзадачі. Наприклад, програма «звіт про оцінки студентів» складається з дій: прочитати файл → обчислити середнє → визначити літеру оцінки → записати звіт. Кожній дії відповідає окрема функція.

**Принципи іменування функцій.**

- Ім'я описує **дію** і складається з малих літер із підкресленнями: `read_numbers`, `calculate_average`, `is_valid_date`.
- Функції, що повертають `bool`, зазвичай починають зі слів `is_`, `has_`, `can_` (`is_prime`, `has_digit`).
- Одна функція — одна задача. Якщо у функції доводиться писати «і ще…» — розділіть її на дві.
- Імена параметрів також змістовні: `numbers`, `filename`, а не `a1`, `x2`.

**Документування.** Одразу після рядка `def` записують **рядок документації** (docstring) у потрійних лапках: що робить функція, що приймає та що повертає.

```python
def average(numbers):
    """Return the average of a list of numbers, or 0.0 for an empty list."""
    if len(numbers) == 0:
        return 0.0
    return sum(numbers) / len(numbers)
```

Рядок документації англійською, коротко (1–2 речення).

**Структура програми.**

1. Імпорти (`import math`).
2. Оголошення функцій.
3. Головна частина: функція `main()` і її виклик в кінці файлу.

```python
def read_number(prompt):
    """Ask the user for a number and return it as float."""
    return float(input(prompt))

def square(number):
    """Return the square of a number."""
    return number * number

def main():
    value = read_number("Number: ")
    print(f"Square: {square(value):.2f}")

main()
```

Приклад запуску (вводимо `1.5`):

```text
Number: 1.5
Square: 2.25
```

**Пояснення.** Введення, обчислення й виведення розділено: `read_number` лише читає, `square` лише обчислює, `main` керує послідовністю й виводить. Так кожну частину можна змінювати й перевіряти окремо.

### 7.4.8. Базова перевірка функцій на прикладах

Щоб упевнитися, що функція працює правильно, її викликають із відомими даними й порівнюють результат з очікуваним. Для цього зручно написати допоміжну функцію `check()`:

```python
def check(description, actual, expected):
    """Print OK if actual equals expected, otherwise FAIL with details."""
    if actual == expected:
        print(f"OK   {description}")
    else:
        print(f"FAIL {description}: got {actual!r}, expected {expected!r}")

def average(numbers):
    """Return the average of a list of numbers, or 0.0 for an empty list."""
    if len(numbers) == 0:
        return 0.0
    return sum(numbers) / len(numbers)

check("average of 2, 4, 6", average([2, 4, 6]), 4.0)
check("average of empty list", average([]), 0.0)
check("average of 1, 2", average([1, 2]), 2)
```

Очікуваний результат:

```text
OK   average of 2, 4, 6
OK   average of empty list
FAIL average of 1, 2: got 1.5, expected 2
```

**Пояснення.** Третя перевірка навмисно хибна: середнє `[1, 2]` дорівнює `1.5`, а не `2`. Запис `{actual!r}` виводить значення у «службовому» вигляді (рядки в лапках).

**Дійсні числа.** Через неточність обчислень `0.1 + 0.2 == 0.3` дає `False`. Для порівняння дійсних результатів округліть їх функцією `round(число, кількість_знаків)`:

```python
print(round(110.00000000000001, 2))
print(round(2.20462, 2))
print(round(26.2187, 1))
```

Очікуваний результат:

```text
110.0
2.2
26.2
```

Тоді перевірка має вигляд `check("add_tax(100, 10)", round(add_tax(100, 10), 2), 110.0)`.

**Порядок роботи.** Блок перевірок розміщують після оголошення функцій і **до** (або замість) інтерактивної частини; перед здачею він має виводити тільки `OK`.

### 7.4.9. Додаткові засоби, потрібні для варіантів

- `round(x, n)` — округлення дійсного числа до `n` знаків.
- Формат `{amount:,.2f}` — число з розділювачем тисяч (`1,234,567.89`).
- Метод символу `ch.isalpha()` — `True`, якщо символ є літерою (аналог `isdigit()`).
- Перевірка підрядка оператором `in`: `ch in "aeiou"` — `True`, якщо символ `ch` є серед літер рядка.
- Порівняння з `None`: `if result is None:`.

```python
vowels = "aeiou"

print("a" in vowels)
print("z" in vowels)
print("7".isdigit(), "x".isalpha(), "7".isalpha())
print(f"{1234567.891:,.2f}")

result = None
print(result is None)
```

Очікуваний результат:

```text
True
False
True True False
1,234,567.89
True
```

### 7.4.10. Типові помилки з функціями

1. `print()` замість `return` — результат неможливо використати далі (отримуємо `None`).
2. Забутий `return` в одній із гілок умови.
3. Виклик функції до її оголошення (`NameError`).
4. Неправильна кількість аргументів (`TypeError`).
5. Використання локальної змінної поза функцією (`NameError`).
6. `return` усередині циклу, що завершує функцію на першій ітерації.
7. Функція «робить усе»: читає, обчислює, виводить — її неможливо перевірити й повторно використати.
8. Параметр зі значенням за замовчуванням записано перед параметром без значення.
9. Забута дужка під час виклику: `average` замість `average(numbers)` — отримуємо сам об'єкт функції, а не результат.

## 7.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- програма складається з **кількох функцій**, перелічених у таблиці варіанта; **імена функцій і порядок параметрів збігаються з таблицею**, інакше автоматична й візуальна перевірка неможливі;
- функції-обчислення повертають результат через `return`; виведення на екран виконує головна частина (функція `main()`);
- кожна функція має рядок документації (англійською);
- у програмі є блок перевірок за допомогою `check()` (або аналогічного способу), що відтворює таблицю «виклик — очікуваний результат» вашого варіанта;
- формат виводу в головній частині збігається з прикладами запуску;

## 7.11. Критерії оцінювання (максимум 10 балів)

| Правильність функцій і результатів | 3 | **3** — усі функції повертають правильні значення на всіх тестах таблиці та граничних випадках; приклади запуску збігаються з очікуваними. **2** — помилка в одній функції або одному граничному випадку. **1** — працює лише частина функцій. **0** — результати неправильні або програма не запускається. |
| Перевірка функцій на прикладах | 2 | **2** — у програмі є блок перевірок усіх тестів таблиці та щонайменше двох власних тестів; у звіті наведено його вивід, усі перевірки `OK`. **1** — перевірено лише частину тестів або немає власних тестів. **0** — перевірка функцій відсутня. |
| Документування, іменування та оформлення | 2 | **2** — кожна функція має рядок документації, імена змістовні, відступи правильні, структура програми «імпорти — функції — головна частина», немає дублювання коду. **1** — документація є не в усіх функціях або є окремі недоліки імен/оформлення. **0** — документації немає, імена беззмістовні, код нечитабельний. |
| **Разом** | **10** | |

Перевірка суми: 3 + 3 + 2 + 2 = 10.

## 7.12. Типові помилки, яких варто уникати

1. `print()` замість `return` у функції-обчисленні; використання результату такої функції далі (отримуємо `None`).
2. Забутий `return` в одній із гілок умови: функція повертає `None` для деяких вхідних даних.
3. `return` усередині циклу на неправильному рівні відступу — функція завершується на першій ітерації.
4. Виклик функції до її оголошення (`NameError`).
5. Неправильна кількість або порядок аргументів (`TypeError` або тихо неправильний результат).
6. Читання змінних головної частини всередині функції замість передачі їх параметрами.
7. Функція «робить усе»: читає дані, обчислює й виводить; її неможливо перевірити окремо.
8. Дублювання коду замість виклику вже написаної функції.
9. Порівняння дійсних результатів без округлення в перевірках (`FAIL` через `110.00000000000001`).
10. Забутий рядок документації або беззмістовні імена функцій (`f1`, `func`, `calc`).
