## 8.4. Теоретичний мінімум

### 8.4.1. Як працювати над проєктом

Проєкт — це програма, більша за попередні практичні роботи, тому писати її «з першого рядка до останнього» не варто. Рекомендований порядок:

1. **Зрозуміти задачу.** Прочитайте умову варіанта й випишіть: які дані зберігаються (поля), які операції потрібні (пункти меню), що виводиться.
2. **Спроєктувати дані.** Визначте, як один запис зберігається в програмі (словник), як усі записи зберігаються (список словників) і як вони відображаються у файлі (рядок CSV).
3. **Розбити на функції.** Для кожної окремої дії — своя функція (див. 8.4.2).
4. **Писати поетапно.** Спершу завантаження й виведення даних, потім збереження, далі — додавання з перевіркою, пошук, видалення, статистика, особлива операція, меню. Після кожного етапу запускайте програму.
5. **Тестувати за сценаріями.** Для кожного пункту меню перевірте сценарій з умови варіанта й власні граничні випадки.
6. **Прибрати зайве й оформити.** Видаліть тимчасові `print()`, перевірте імена, коментарі й документацію функцій.

### 8.4.2. Декомпозиція: шари програми

Поділіть програму на шари, кожен із яких має свою відповідальність:

| Шар | Відповідальність | Приклади функцій |
| --- | ---------------- | ---------------- |
| Дані | читання й запис файлу, перетворення рядка CSV у запис | `load_records`, `save_records`, `parse_record` |
| Введення | запит значення в користувача з перевіркою | `read_int`, `read_float`, `read_choice`, `read_text` |
| Логіка | обчислення, пошук, зміна даних; **не** виводять на екран, а повертають результат | `find_by_category`, `delete_record`, `calculate_statistics` |
| Виведення | показ даних і повідомлень | `show_records`, `show_menu` |
| Керування | меню та цикл виконання команд | `main` |

**Правила.**

- Функції логіки отримують дані через параметри й повертають результат; глобальні змінні з даними не використовуються. Список записів `records` створюється в `main()` і передається у функції.
- Константи (ім'я файлу, допустимі значення категорій) оголошують **на початку файлу** великими літерами: `DATA_FILE`, `CATEGORIES`.
- Одна функція — одна задача. Якщо функція не вміщується на екран, розділіть її.

### 8.4.3. Модель даних: список словників і CSV

Один запис — **словник**, усі записи — **список словників**:

```python
records = [
    {"id": 1, "name": "Oak", "kind": "tree", "height": 2500},
    {"id": 2, "name": "Rose", "kind": "flower", "height": 90},
]
print(records[1]["name"])
```

Очікуваний результат:

```text
Rose
```

У CSV-файлі той самий набір має вигляд:

```text
id,name,kind,height
1,Oak,tree,2500
2,Rose,flower,90
```

Під час завантаження **усі поля, прочитані з файлу, — рядки**, тому числові поля перетворюють на `int`/`float` після перевірки. Під час збереження числа записуються назад як текст (дійсні — у форматі `:.2f`).

### 8.4.4. Обробка типових помилок: `try/except`

**Означення.** Коли в програмі виникає помилка (**виняток**), вона зазвичай завершується з повідомленням (`Traceback`). Конструкція `try/except` дозволяє перехопити виняток і виконати власну реакцію замість аварійного завершення.

**Синтаксис.**

```text
try:
    команди, у яких може виникнути помилка
except ТипПомилки:
    команди, що виконуються у разі цієї помилки
```

**Приклад 1.** Файл може не існувати.

```python
try:
    with open("missing.txt", "r", encoding="utf-8") as file:
        text = file.read()
    print("File read")
except FileNotFoundError:
    print("File not found")
```

Очікуваний результат, якщо файлу `missing.txt` немає:

```text
File not found
```

**Приклад 2.** Перетворення рядка на число.

```python
text = "abc"
try:
    value = int(text)
    print(f"Number: {value}")
except ValueError:
    print("Not an integer")
```

Очікуваний результат:

```text
Not an integer
```

**Пояснення.** Команди блоку `try` виконуються по порядку. Якщо виникла помилка вказаного типу — виконання **негайно** переходить до блоку `except`; команди `try` після місця помилки пропускаються. Якщо помилки немає — блок `except` пропускається.

**Типи помилок, потрібні в проєкті.**

| Тип | Коли виникає |
| --- | ------------ |
| `FileNotFoundError` | відкриття на читання файлу, якого немає |
| `OSError` | загальна помилка файлової системи (наприклад, немає права запису); `FileNotFoundError` є її різновидом |
| `ValueError` | `int("abc")`, `float("2,5")` |

**Правила.**

1. Перехоплюйте **конкретний** тип помилки (`except ValueError:`), а не будь-яку (`except:`) — інакше ви приховаєте справжні помилки в програмі.
2. Блок `try` має бути **коротким** — лише команди, у яких очікується помилка.
3. Перевірку введених користувачем значень у проєкті виконуйте **заздалегідь** методами рядків (`isdigit()`, `replace(".", "", 1).isdigit()`), як у роботі №6: тоді повідомлення про помилки однакові для всіх студентів. `try/except` у проєкті обов'язковий для **роботи з файлами**: завантаження (`FileNotFoundError`) і збереження (`OSError`).
4. `try/except` не замінює правильну логіку: не використовуйте його, щоб «замовчати» помилку, причину якої ви не розумієте.

### 8.4.5. Текстове меню та цикл команд

Меню — це цикл, у якому програма показує пункти, зчитує вибір і викликає відповідну функцію, доки користувач не вибере вихід. Оператор `break` не потрібен: умова циклу перевіряє значення вибору.

```python
choice = ""
while choice != "0":
    print("1. Show  0. Exit")
    choice = input("Choice: ")
    if choice == "1":
        print("Records...")
    elif choice != "0":
        print("Unknown menu item")
print("Bye")
```

Приклад запуску (вводимо `1`, `7`, `0`):

```text
1. Show  0. Exit
Choice: 1
Records...
1. Show  0. Exit
Choice: 7
Unknown menu item
1. Show  0. Exit
Choice: 0
Bye
```

**Пояснення.** Початкове значення `choice = ""` гарантує вхід у цикл. Некоректний пункт не завершує програму, а виводить повідомлення й показує меню знову.

### 8.4.6. Повторний запит значення до отримання коректного

Функція введення повторює запит, доки значення некоректне, і лише тоді повертає результат:

```python
def read_int(prompt, field, min_value):
    """Ask until the user enters an integer not less than min_value."""
    while True:
        text = input(prompt)
        if not text.isdigit():
            print(f"Error: {field} must be an integer")
        elif int(text) < min_value:
            print(f"Error: {field} must be at least {min_value}")
        else:
            return int(text)
```

Цикл `while True` завершується оператором `return` (він негайно виходить із функції разом із циклом), тому окремий `break` не потрібен. Приклад роботи `read_int("Quantity: ", "quantity", 1)` для вводу `abc`, `0`, `5`:

```text
Quantity: abc
Error: quantity must be an integer
Quantity: 0
Error: quantity must be at least 1
Quantity: 5
```

Функція повертає `5`.

### 8.4.7. Приклад каркаса проєкту

Нижче наведено працездатний каркас програми для предметної області «Рослини», **яка не входить до варіантів**. Він демонструє шари програми, завантаження й збереження CSV, обробку `FileNotFoundError` і `OSError`, меню та статистику. У вашому проєкті потрібно реалізувати **усі** пункти меню з розділу 8.5.1.

Вхідний файл `plants.csv` (рядок 5 некоректний — повторний `id`):

```text
id,name,kind,height
1,Oak,tree,2500
2,Rose,flower,90
3,Basil,herb,40
2,Tulip,flower,30
```

Програма:

```python
import csv

DATA_FILE = "plants.csv"
KINDS = ["tree", "flower", "herb"]


def parse_record(row, existing):
    """Return a record dict for a valid CSV row, or None if the row is invalid."""
    if len(row) != 4:
        return None
    if not row[0].isdigit() or int(row[0]) < 1:
        return None
    for record in existing:
        if record["id"] == int(row[0]):
            return None
    if row[1] == "" or row[2] not in KINDS or not row[3].isdigit():
        return None
    return {"id": int(row[0]), "name": row[1], "kind": row[2], "height": int(row[3])}


def load_records(filename):
    """Load records from a CSV file; skip invalid rows; return a list of dicts."""
    records = []
    try:
        with open(filename, "r", encoding="utf-8", newline="") as file:
            reader = csv.reader(file)
            next(reader, None)
            line_number = 1
            for row in reader:
                line_number += 1
                record = parse_record(row, records)
                if record is None:
                    print(f"Skipped invalid row at line {line_number}")
                else:
                    records.append(record)
    except FileNotFoundError:
        print(f"File not found: {filename}. Starting with empty data")
    return records


def save_records(filename, records):
    """Save records to a CSV file; return True on success."""
    try:
        with open(filename, "w", encoding="utf-8", newline="") as file:
            writer = csv.writer(file)
            writer.writerow(["id", "name", "kind", "height"])
            for r in records:
                writer.writerow([r["id"], r["name"], r["kind"], r["height"]])
    except OSError:
        print(f"Cannot save file: {filename}")
        return False
    return True


def show_records(records):
    """Print all records, one per line."""
    if len(records) == 0:
        print("No records")
    for r in records:
        print(f"{r['id']} | {r['name']} | {r['kind']} | {r['height']}")


def read_int(prompt, field, min_value):
    """Ask until the user enters an integer not less than min_value."""
    while True:
        text = input(prompt)
        if not text.isdigit():
            print(f"Error: {field} must be an integer")
        elif int(text) < min_value:
            print(f"Error: {field} must be at least {min_value}")
        else:
            return int(text)


def calculate_statistics(records):
    """Return statistics as a list of text lines."""
    if len(records) == 0:
        return ["No data"]
    total = 0
    for r in records:
        total += r["height"]
    return [f"Plants: {len(records)}", f"Average height: {total / len(records):.2f}"]


def main():
    records = load_records(DATA_FILE)
    choice = ""
    while choice != "0":
        print("1. Show  5. Statistics  0. Save and exit")
        choice = input("Choice: ")
        if choice == "1":
            show_records(records)
        elif choice == "5":
            for line in calculate_statistics(records):
                print(line)
        elif choice != "0":
            print("Unknown menu item")
    if save_records(DATA_FILE, records):
        print("Data saved")


main()
```

Приклад сеансу (вводимо `1`, `5`, `7`, `0`):

```text
Skipped invalid row at line 5
1. Show  5. Statistics  0. Save and exit
Choice: 1
1 | Oak | tree | 2500
2 | Rose | flower | 90
3 | Basil | herb | 40
1. Show  5. Statistics  0. Save and exit
Choice: 5
Plants: 3
Average height: 876.67
1. Show  5. Statistics  0. Save and exit
Choice: 7
Unknown menu item
1. Show  5. Statistics  0. Save and exit
Choice: 0
Data saved
```

**Якщо файлу `plants.csv` немає**, під час старту виводиться `File not found: plants.csv. Starting with empty data`, пункт 5 виводить `No data`, а після виходу створюється файл лише із заголовком.

**Зверніть увагу:**

- функція `parse_record()` лише перевіряє рядок і повертає запис або `None`; рішення про повідомлення приймає `load_records()`;
- `calculate_statistics()` **повертає** список рядків, а виводить їх `main()`;
- `next(reader, None)` пропускає заголовок, а при порожньому файлі не викликає помилки;
- `main()` викликається один раз у кінці файлу.

### 8.4.8. Тестування проєкту

1. Підготуйте **тестові файли**: файл із прикладу варіанта, файл лише із заголовком та відсутній файл.
2. Виконайте **сценарії з умови варіанта** по порядку й порівняйте вивід (рядок за рядком) і вміст файлів.
3. Додайте **власні сценарії**: некоректні дані при додаванні, видалення неіснуючого запису, межові значення полів, повторний запуск програми після збереження (дані мають збереглися).
4. Для функцій логіки використайте блок `check()` з роботи №7: викличте функцію на невеликому списку записів і порівняйте з очікуваним результатом. Блок перевірок можна тимчасово запускати замість `main()`.
5. Після кожного виправлення повторюйте весь набір сценаріїв (виправлення одного місця може зламати інше).

### 8.4.9. Читабельність коду

- Імена змінних і функцій — англійські, змістовні (`low_stock_items`, `read_float`).
- Рядок документації кожної функції — одне-два речення англійською.
- Коментарі пояснюють **навіщо**, а не повторюють код: «skip header row», «ids must be unique».
- Не дублюйте код: якщо один і той самий фрагмент потрібен у двох місцях — винесіть його у функцію.
- Не залишайте закоментований старий код і тимчасові `print()` для налагодження.
- Довжина функції — до ~25 рядків; вкладеність умов і циклів — не більше трьох рівнів.

Номер варіанта визначає викладач. Усі 12 варіантів мають **однакові базові вимоги** (8.5.1) і відрізняються предметною областю, полями записів, статистикою й особливою операцією (пункт меню 6).

### 8.5.1. Базові вимоги, однакові для всіх варіантів

**Файли.**

- Дані зберігаються у CSV-файлі, ім'я якого вказано у варіанті (константа `DATA_FILE` на початку програми). Файл розташовано в одній папці з програмою; усі файли відкриваються через `with open(...)` з `encoding="utf-8"` (для CSV — також `newline=""`).
- Звіт зберігається у файлі `report.txt`.
- Першим рядком CSV є заголовок з іменами полів, вказаними у варіанті.

**Меню.** Програма в циклі показує меню (текст пунктів — дослівно, пункт 6 має назву зі свого варіанта) та виконує вибрану команду, доки не буде обрано `0`:

```text
1. Show all records
2. Add record
3. Search by category
4. Delete record by id
5. Statistics
6. <назва особливої операції варіанта>
7. Save report to report.txt
0. Save and exit
```

Некоректний пункт меню дає повідомлення `Unknown menu item`.

**Поведінка пунктів меню.**

| Пункт | Дія | Повідомлення |
| ----- | --- | ------------ |
| 1 | вивести всі записи у порядку зберігання, по одному в рядку: значення полів через ` \| ` (пробіл, вертикальна риска, пробіл), дійсні числа — з двома знаками | якщо записів немає — `No records` |
| 2 | запитати всі поля по черзі, повторюючи запит поля до коректного значення; додати запис у кінець списку | `Record added` |
| 3 | запитати значення категорії (поле з обмеженим набором значень, указане у варіанті; запит повторюється, доки введено допустиме значення) і вивести записи з цією категорією у форматі пункту 1 | якщо записів немає — `No records found` |
| 4 | запитати `id` (ціле число, запит повторюється, доки введено ціле число) і видалити запис із таким `id` | `Record deleted` або `Record not found` |
| 5 | вивести статистику варіанта | якщо даних немає — `No data` |
| 6 | особлива операція варіанта | за умовою варіанта |
| 7 | записати рядки статистики (ті самі, що в пункті 5) у `report.txt`, по одному в рядку | `Report saved` |
| 0 | записати всі записи у CSV-файл (заголовок + записи, дійсні числа — з двома знаками) і завершити програму | `Data saved`; якщо файл не можна записати — `Cannot save file: ім'я` |

**Завантаження даних.** Під час старту програма читає CSV-файл. Кожен рядок перевіряється; некоректний рядок пропускається з повідомленням `Skipped invalid row at line N` (заголовок — рядок 1). Якщо файлу немає, виводиться `File not found: ім'я. Starting with empty data`, і програма починає з порожнім списком.

**Рядок CSV некоректний,** якщо кількість полів не збігається з кількістю полів у заголовку або будь-яке поле не відповідає вимогам до значення, указаним у таблиці полів варіанта (зокрема дублюється `id`).

**Правила перевірки полів і повідомлення про помилки** (використовуються і під час завантаження — без повідомлення, і під час введення — з повідомленням):

| Тип вимоги | Помилка введення | Повідомлення |
| ---------- | ---------------- | ------------ |
| `id` | не ціле число ≥ 1 | `Error: id must be a positive integer` |
| `id` | уже існує | `Error: id already exists` |
| непорожній рядок | порожній рядок | `Error: поле must not be empty` |
| одне зі значень | значення не зі списку | `Error: поле must be one of: v1, v2, v3` |
| ціле число | текст не складається з цифр (у т. ч. від'ємні числа) | `Error: поле must be an integer` |
| ціле число | за межами діапазону | `Error: поле must be at least A` або `Error: поле must be between A and B` |
| число > 0 / у діапазоні | не число (допускається одна крапка, без знака) | `Error: поле must be a number` |
| число > 0 | значення не більше 0 | `Error: поле must be greater than 0` |
| число в діапазоні | за межами діапазону | `Error: поле must be between A and B` |

Перевірку виконуйте методами рядків: `isdigit()` для цілих, `replace(".", "", 1).isdigit()` для дійсних.

**Обов'язкові функції.** Імена й параметри функцій однакові в усіх варіантах (функції особливої операції мають ім'я з варіанта):

| Функція | Призначення |
| ------- | ----------- |
| `parse_record(row, existing)` | перевіряє рядок CSV, повертає словник запису або `None` |
| `load_records(filename)` | завантажує записи, виводить повідомлення про пропущені рядки та про відсутній файл (`try/except FileNotFoundError`), повертає список |
| `save_records(filename, records)` | записує CSV (`try/except OSError`), повертає `True`/`False` |
| `show_records(records)` | виводить записи або `No records` |
| `read_text(prompt, field)`, `read_choice(prompt, field, allowed)`, `read_int(prompt, field, min_value, max_value)`, `read_float(prompt, field, min_value, max_value)`, `read_new_id(prompt, records)` | введення значення з повторним запитом до коректного (`max_value` може бути `None`) |
| `add_record(records)` | запитує всі поля й додає запис |
| `find_by_category(records, category)` | повертає список записів із категорією |
| `delete_record(records, record_id)` | видаляє запис, повертає `True`/`False` |
| `calculate_statistics(records)` | повертає список рядків статистики |
| функція особливої операції | реалізує пункт 6 і повертає список рядків для виведення (або змінює дані, якщо цього вимагає варіант) |
| `save_report(filename, lines)` | записує рядки у файл |
| `show_menu()`, `main()` | меню й головний цикл |

У полі `seats_sold` варіанта 10 верхня межа дорівнює введеному значенню `seats_total` цього ж запису: під час введення `read_int` отримує його як `max_value`, під час завантаження перевіряється `parse_record`.

**Структура програми:** імпорти, константи, функції (за шарами з 8.4.2), виклик `main()`.

### Варіант 3. Облік особистих витрат

**Предметна область і проблема.** Користувач веде облік особистих витрат. Потрібна програма, яка зберігає записи про витрати, підсумовує їх за категоріями та місяцями та попереджає про перевищення місячних лімітів за категоріями.

**Вхідні дані.** Файл `expenses.csv` (CSV із заголовком). Кожен запис має поля:

| Поле | Тип | Вимоги до значення |

| `description` | `str` | непорожній рядок |
| `category` | `str` | одне зі значень: `food`, `transport`, `housing`, `fun`, `health` |
