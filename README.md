## 3. Загальна система оцінювання на 100 балів

| Вид роботи | Максимальна кількість балів |
| ---------- | --------------------------- |
| Практична робота №1 | 5 |
| Практична робота №2 | 5 |
| Практична робота №3 | 10 |
| Практична робота №4 | 10 |
| Практична робота №5 | 10 |
| Практична робота №6 | 10 |
| Практична робота №7 | 10 |
| Практична робота №8 | 15 |
| Контрольна робота із систем числення | 5 |
| Активність на лекціях протягом семестру | 5 |
| Підсумковий тест наприкінці семестру | 15 |
| **Разом** | **100** |

**Перевірка арифметики.** Практичні роботи: 5 + 5 + 10 + 10 + 10 + 10 + 10 + 15 = **75 балів**. Інші види контролю: 5 + 5 + 15 = **25 балів**. Разом: 75 + 25 = **100 балів**.

**Важливо.**

- Бали за практичну роботу нараховуються лише за критеріями, наведеними в самій роботі, і не можуть перевищувати її максимум.
- Контрольні запитання в кінці кожної роботи призначені для самоперевірки та усного захисту. Окремих балів за них у практичних роботах немає, якщо викладач не визначить інше.
- Контрольна робота із систем числення, активність на лекціях і підсумковий тест оцінюються окремо й не впливають на бали за практичні роботи.

## 4. Правила виконання та подання практичних робіт

### 4.1. Порядок виконання

1. Прочитайте мету роботи та перелік необхідних знань. Якщо якусь тему з попередніх робіт ви забули, поверніться до неї.
2. Вивчіть теоретичний мінімум, **самостійно запустіть** усі приклади коду та порівняйте результат із наведеним.
3. Знайдіть свій індивідуальний варіант (номер варіанта визначає викладач).
4. Спершу продумайте алгоритм: що вводиться, що обчислюється, що виводиться. Запишіть це кількома реченнями.
5. Напишіть програму невеликими кроками, запускаючи її після кожного кроку.

### 4.2. Загальні вимоги до коду

- Ім'я файлу програми: латиницею, малими літерами, з підкресленнями, наприклад `lab01_variant05.py`.

- Імена змінних мають бути змістовними: `price`, `total_cost`, а не `a1`, `x2`, `qwe`.
- Перед кожним логічним блоком — короткий коментар (що робить цей блок).
- Програма має виводити результати в тому форматі, який описано в умові варіанта.
- Використовуйте **лише** конструкції, вивчені в поточній і попередніх роботах.

### 4.3. Академічна доброчесність

Кожен студент виконує **власний індивідуальний варіант**. Під час захисту роботи:

### 1.2. Навчальні результати

3. Використовувати змінні та оператор присвоювання.
4. Розрізняти типи `int`, `float`, `str` і перетворювати їх один в одний.
5. Використовувати арифметичні оператори `+`, `-`, `*`, `/`, `//`, `%`, `**`.
6. Форматувати вивід за допомогою f-рядків (зокрема, виводити число з двома знаками після крапки).
7. Підключати модулі `math`, `random`, `time` і використовувати кілька їхніх можливостей.
8. Будувати лінійний алгоритм «ввід → обчислення → вивід».

### 1.3. Необхідні знання і навички

Попередніх знань програмування не потрібно. Достатньо вміти:

- створювати й зберігати текстовий файл;
- запускати програму з терміналу або середовища розробки;
- виконувати арифметичні дії та знати формули з шкільного курсу математики й фізики (площа круга, відстань між точками тощо).

### 1.4. Теоретичний мінімум

#### 1.4.1. Що таке програма і як її запустити

**Програма** — це послідовність команд, які комп'ютер виконує по черзі, зверху вниз. **Python** — мова програмування, програми якою зберігаються у файлах із розширенням `.py`.

**Як запустити програму.** Створіть файл `hello.py` з одним рядком:

```python
print("Hello, Python!")
```

Запуск із терміналу (у папці з файлом):

```text
python hello.py
```

(У деяких системах команда називається `python3`.) У середовищах IDLE, VS Code, PyCharm використовуйте кнопку запуску (Run).

Очікуваний результат:

```text
Hello, Python!
```

**Основні правила запису програм.**

- Команди виконуються по одній у кожному рядку, зверху вниз.
- Python розрізняє великі та малі літери: `Price` і `price` — різні імена.
- Коментар починається зі знака `#`; усе, що після нього в рядку, Python ігнорує:

```python
# This line is a comment
print("Hello")  # this is also a comment
```

- Ім'я змінної складається з латинських літер, цифр і знака `_`, не починається з цифри. Прийнято писати малими літерами з підкресленнями: `total_cost`.
- Рядок програми не можна починати з пробілів без потреби (в одних випадках це помилка, у наступних роботах відступи матимуть особливий зміст).

#### 1.4.2. Функція `print()`

**Означення.** `print()` — вбудована функція, яка виводить дані на екран.

**Синтаксис.** `print(значення1, значення2, ...)`

**Навіщо.** Щоб програма показувала результат користувачеві.

**Приклад.** Виведення тексту та чисел.

```python
print("Hello")
print(2 + 3)
print("Sum:", 2 + 3)
```

Очікуваний результат:

```text
Hello
5
Sum: 5
```

**Пояснення.** Текст завжди беруть у лапки (подвійні `"` або одинарні `'`). Вираз `2 + 3` без лапок спочатку обчислюється, потім виводиться. Якщо в `print()` кілька значень через кому, вони виводяться через пропуск. Кожен виклик `print()` починає новий рядок.

**Типова помилка.** Забули закрити лапки: `print("Hello)` — Python повідомить `SyntaxError`.

#### 1.4.3. Змінні та присвоювання

**Означення.** **Змінна** — це ім'я, за яким у пам'яті зберігається значення. **Присвоювання** — команда, яка записує значення у змінну.

**Синтаксис.** `ім'я = значення` (знак `=` тут означає «записати», а не «дорівнює»).

**Навіщо.** Щоб зберігати вхідні дані й проміжні результати та використовувати їх далі.

**Приклад.** Обчислення суми.

```python
first_number = 12
second_number = 8

result = first_number + second_number

print(f"Result: {result}")
```

Очікуваний результат:

```text
Result: 20
```

**Пояснення.** У перших двох рядках у змінні записуються числа. У рядку `result = ...` спочатку обчислюється права частина (12 + 8), потім значення 20 записується у змінну `result`. Змінну можна перезаписати: після `result = 5` попереднє значення втрачається.

Присвоювання, в якому нове значення залежить від старого:

```python
counter = 10
counter = counter + 1
print(counter)
```

Очікуваний результат:

```text
11
```

#### 1.4.4. Типи даних `int`, `float`, `str`

| Тип | Що зберігає | Приклади |
| --- | ----------- | -------- |
| `int` | ціле число | `42`, `-7`, `0` |
| `float` | дійсне число (з дробовою частиною) | `3.14`, `-0.5`, `2.0` |
| `str` | рядок (текст) | `"Python"`, `"42"`, `""` |

**Важливо.** `42`, `42.0` і `"42"` — три різні значення різних типів. Дробову частину в Python відокремлюють **крапкою**: `3.14`, а не `3,14`.

Дізнатися тип значення можна функцією `type()`:

```python
print(type(42))
print(type(42.0))
print(type("42"))
```

Очікуваний результат:

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

**Операції з рядками.** Рядки можна **з'єднувати** знаком `+` (конкатенація) і **повторювати** знаком `*`. Довжину рядка (кількість символів, включно з пробілами) повертає функція `len()`:

```python
first = "Ada"
second = "Lovelace"

full_name = first + " " + second
line = "-" * 10

print(full_name)
print(line)
print(len(full_name))
```

Очікуваний результат:

```text
Ada Lovelace
----------
12
```

**Пояснення.** `first + " " + second` склеює три рядки в один; `"-" * 10` повторює дефіс 10 разів; у `"Ada Lovelace"` 3 + 1 + 8 = 12 символів.

**Типова помилка.** Спроба скласти рядок і число: `"Age: " + 20` викликає `TypeError`. Число потрібно або перетворити на рядок (див. нижче), або скористатися f-рядком.

#### 1.4.5. Арифметичні оператори

| Оператор | Дія | Приклад | Результат |
| -------- | --- | ------- | --------- |
| `+` | додавання | `7 + 2` | `9` |
| `-` | віднімання | `7 - 2` | `5` |
| `*` | множення | `7 * 2` | `14` |
| `/` | ділення (завжди дає `float`) | `7 / 2` | `3.5` |
| `//` | цілочисельне ділення (ціла частина частки) | `7 // 2` | `3` |
| `%` | остача від ділення | `7 % 2` | `1` |
| `**` | піднесення до степеня | `7 ** 2` | `49` |

**Порядок виконання** такий, як у математиці: спочатку `**`, потім `*`, `/`, `//`, `%`, потім `+`, `-`. Круглі дужки змінюють порядок.

**Приклад.** Переведення хвилин у години та хвилини.

```python
total_minutes = 135

hours = total_minutes // 60
minutes = total_minutes % 60

print(f"{hours} h {minutes} min")
```

Очікуваний результат:

```text
2 h 15 min
```

**Пояснення.** 135 ділимо на 60: ціла частина частки — 2 (години), остача — 15 (хвилини). Оператори `//` і `%` часто використовують разом.

**Типова помилка.** Записати `2x` або `a(b+c)` замість `2 * x` та `a * (b + c)`: знак множення в Python обов'язковий.

#### 1.4.6. Функція `input()` і перетворення типів

**Означення.** `input()` зчитує рядок, який користувач ввів із клавіатури й підтвердив клавішею Enter. **Увага: `input()` завжди повертає рядок (`str`)**, навіть якщо користувач ввів число.

**Синтаксис.** `змінна = input("Підказка: ")`

**Перетворення типів.**

| Функція | Дія | Приклад | Результат |
| ------- | --- | ------- | --------- |
| `int(x)` | перетворює на ціле число | `int("15")` | `15` |
| `float(x)` | перетворює на дійсне число | `float("2.5")` | `2.5` |
| `str(x)` | перетворює на рядок | `str(15)` | `"15"` |

Функція `int()` також відкидає дробову частину числа: `int(3.9)` дорівнює `3`.

**Приклад.** Подвоєння числа, яке ввів користувач.

```python
text = input("Enter a number: ")
number = float(text)

doubled = number * 2

print(f"Doubled: {doubled}")
```

Приклад запуску (користувач вводить `2.5`):

```text
Enter a number: 2.5
Doubled: 5.0
```

**Пояснення.** `input()` повернув рядок `"2.5"`. Функція `float()` перетворила його на число `2.5`, після чого можна виконувати арифметику. Часто обидві дії записують в один рядок: `number = float(input("Enter a number: "))`.

**Типові помилки.**

- Не перетворити результат `input()` на число. Тоді `input()` + `input()` з вводом `3` і `4` дасть `"34"`, а не `7`.
- Спробувати перетворити не число: `int("abc")` або `float("2,5")` (кома замість крапки) викликає `ValueError`. Для введення дробових чисел користуйтеся крапкою.
- Застосувати `int("2.5")` до рядка з дробовою частиною: спершу `float("2.5")`, потім за потреби `int(...)`.

#### 1.4.7. Форматування виводу: f-рядки

**Означення.** **f-рядок** — це рядок з буквою `f` перед лапками, усередині якого у фігурних дужках `{}` можна записувати змінні й вирази.

**Навіщо.** Щоб зручно підставляти значення в текст і керувати виглядом чисел.

**Синтаксис.** `f"Текст {вираз} текст"`, `f"{вираз:специфікація}"`.

| Запис | Значення | Приклад (`x = 3.14159`, `n = 7`) | Результат |
| ----- | -------- | -------------------------------- | --------- |
| `{x}` | як є | `f"{x}"` | `3.14159` |
| `{x:.2f}` | 2 знаки після крапки | `f"{x:.2f}"` | `3.14` |
| `{x:.0f}` | без дробової частини (округлення) | `f"{x:.0f}"` | `3` |
| `{n:02d}` | ціле, мінімум 2 цифри, ведучий нуль | `f"{n:02d}"` | `07` |

**Приклад.**

```python
price = 24.5
quantity = 3
total = price * quantity

print(f"Price: {price:.2f}")
print(f"Quantity: {quantity}")
print(f"Total: {total:.2f}")
```

Очікуваний результат:

```text
Price: 24.50
Quantity: 3
Total: 73.50
```

**Пояснення.** Формат `.2f` завжди виводить два знаки після крапки, тому `24.5` стає `24.50`. Форматування змінює лише **вигляд** виводу, а не саме значення змінної.

**Типова помилка.** Забути букву `f` перед лапками: `print("Total: {total:.2f}")` виведе текст буквально, без підстановки.

#### 1.4.8. Лінійний алгоритм

**Означення.** **Лінійний алгоритм** — це алгоритм, у якому всі дії виконуються послідовно, одна за одною, без пропусків і повторень.

Типова структура програми:

1. **Ввід** — зчитати вхідні дані й перетворити їх на потрібні типи.
2. **Обчислення** — виконати розрахунки, зберігаючи проміжні результати в змінних.
3. **Вивід** — показати результат у заданому форматі.

**Приклад.** Периметр і площа прямокутника.

```python
# Input
width = float(input("Width: "))
height = float(input("Height: "))

# Calculation
perimeter = 2 * (width + height)
area = width * height

# Output
print(f"Perimeter: {perimeter:.2f}")
print(f"Area: {area:.2f}")
```

Приклад запуску (вводимо `4` і `2.5`):

```text
Width: 4
Height: 2.5
Perimeter: 13.00
Area: 10.00
```

**Пояснення.** 2 · (4 + 2.5) = 13; 4 · 2.5 = 10. Програма виконує рівно ті команди, що записані, одну за одною.

#### 1.4.9. Модулі та команда `import`

**Означення.** **Модуль** — це файл із готовими інструментами (функціями, константами), які можна підключити до своєї програми. Підключення виконує команда `import`, яку зазвичай пишуть на початку файлу.

**Синтаксис.** `import назва_модуля`, використання — `назва_модуля.інструмент`.

**Модуль `math`** — математичні функції та константи.

| Інструмент | Значення | Приклад | Результат |
| ---------- | -------- | ------- | --------- |
| `math.pi` | число π | `math.pi` | `3.141592653589793` |
| `math.sqrt(x)` | квадратний корінь | `math.sqrt(49)` | `7.0` |
| `math.ceil(x)` | округлення вгору до цілого | `math.ceil(2.1)` | `3` |
| `math.floor(x)` | округлення вниз до цілого | `math.floor(2.9)` | `2` |

```python
import math

radius = 5
area = math.pi * radius ** 2
side = math.sqrt(144)

print(f"Circle area: {area:.2f}")
print(f"Side: {side}")
```

Очікуваний результат:

```text
Circle area: 78.54
Side: 12.0
```

**Модуль `random`** — випадкові числа.

| Інструмент | Значення | Приклад |
| ---------- | -------- | ------- |
| `random.randint(a, b)` | випадкове **ціле** від `a` до `b` включно | `random.randint(1, 6)` |
| `random.random()` | випадкове дійсне число від 0 до 1 | `random.random()` |
| `random.uniform(a, b)` | випадкове дійсне число від `a` до `b` | `random.uniform(1.5, 2.5)` |

```python
import random

die = random.randint(1, 6)
print(f"Die: {die}")
```

Можливий результат (при кожному запуску може бути інший):

```text
Die: 4
```

**Пояснення.** Результат випадковий, тому тестувати такі програми треба за **властивостями** (наприклад, «число завжди від 1 до 6»), а не за конкретним значенням. Програму слід запустити кілька разів.

**Модуль `time`** — робота з часом.

| Інструмент | Значення |
| ---------- | -------- |
| `time.time()` | кількість секунд (`float`), що минули з 1 січня 1970 року |
| `time.strftime("%d.%m.%Y")` | поточна дата у вигляді рядка; `%d` — день, `%m` — місяць, `%Y` — рік; `%H:%M` — години й хвилини |
| `time.localtime().tm_year` | поточний рік (ціле число) |

```python
import time

today = time.strftime("%d.%m.%Y")
year = time.localtime().tm_year

print(f"Today: {today}")
print(f"Year: {year}")
```

Можливий результат (залежить від дня запуску):

```text
Today: 09.10.2026
Year: 2026
```

**Типова помилка.** Забути `import math` і написати `math.sqrt(4)`: буде `NameError: name 'math' is not defined`. Також не називайте власний файл `math.py`, `random.py` чи `time.py`: він «затьмарить» однойменний модуль.

### 1.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- вхідні дані зчитуються за допомогою `input()` (кожне значення — окремим запитом);
- дробові числа вводяться з **крапкою**;
- результати виводяться саме з тими підписами, які зазначено в умові, а дійсні числа — з двома знаками після крапки (якщо не сказано інше);
- програма не перевіряє коректність введення (перевірка введення вивчається пізніше), тому під час тестування вводьте лише дані потрібного типу;
- дозволено використовувати лише змінні, `int`, `float`, `str`, арифметику, `print()`, `input()`, f-рядки та модулі, зазначені в умові.

### 2.4. Теоретичний мінімум

#### 2.4.1. Логічні значення та оператори порівняння

**Означення.** **Логічне значення** (тип `bool`) може бути лише `True` («істина») або `False` («хибність»). Воно виникає як результат **порівняння**.

| Оператор | Значення | Приклад | Результат |
| -------- | -------- | ------- | --------- |
| `==` | дорівнює | `5 == 5` | `True` |
| `!=` | не дорівнює | `5 != 5` | `False` |
| `>` | більше | `7 > 3` | `True` |
| `<` | менше | `7 < 3` | `False` |
| `>=` | більше або дорівнює | `4 >= 4` | `True` |
| `<=` | менше або дорівнює | `4 <= 3` | `False` |

**Приклад.**

```python
age = 18

print(age >= 18)
print(age == 17)
print("abc" == "abc")
print("abc" == "ABC")
```

Очікуваний результат:

```text
True
False
True
False
```

**Пояснення.** Кожне порівняння обчислюється й дає `True` або `False`. Рядки порівнюються символ за символом **з урахуванням регістру**, тому `"abc"` і `"ABC"` — різні рядки.

**Важливо.**

- Знак `=` — це **присвоювання**, а `==` — **порівняння**. Це різні операції.
- Рядок можна порівнювати з рядком, число — з числом. Порівняння `"5" == 5` дає `False` (різні типи), а `"5" > 3` викликає `TypeError`.
- Дійсні числа зберігаються наближено: `0.1 + 0.2 == 0.3` дає `False`. Тому точне порівняння на рівність для дробових результатів обчислень може давати несподіваний результат; для введених користувачем «круглих» значень (наприклад, `3.0 == 3.0`) воно працює.

**Подвійне порівняння.** У Python можна записати «число лежить у проміжку» без `and`:

```python
x = 15
print(10 <= x <= 20)
```

Очікуваний результат:

```text
True
```

#### 2.4.2. Логічні оператори `and`, `or`, `not`

| Оператор | Значення | `True`, коли… |
| -------- | -------- | ------------- |
| `A and B` | «і» | істинні **обидві** умови |
| `A or B` | «або» | істинна **хоча б одна** умова |
| `not A` | «не» | умова `A` хибна |

**Приклад.**

```python
age = 20
has_ticket = True

print(age >= 18 and has_ticket)
print(age < 18 or not has_ticket)
print(not (age > 30))
```

Очікуваний результат:

```text
True
False
True
```

**Пояснення.** Перший рядок: обидві умови істинні. Другий: `age < 18` — `False`, `not has_ticket` — `False`, тож `or` дає `False`. Третій: `age > 30` — `False`, `not` перетворює його на `True`.

**Порядок виконання:** спочатку порівняння, потім `not`, потім `and`, потім `or`. Щоб уникнути плутанини, використовуйте круглі дужки.

**Типова помилка.** Запис `x == 1 or 2` не означає «x дорівнює 1 або 2». Правильно: `x == 1 or x == 2`.

#### 2.4.3. Конструкція `if`

**Означення.** Умовна конструкція `if` виконує блок команд лише тоді, коли умова істинна.

**Синтаксис.**

```text
if умова:
    команди, які виконуються, якщо умова істинна
```

**Правила запису.**

- Після умови обов'язково ставиться двокрапка `:`.
- Команди, що належать блоку, записуються з **відступом** (рекомендовано 4 пробіли). Відступ показує, які рядки належать блоку.
- Рядок без відступу вже не належить блоку й виконується завжди.

**Приклад.**

```python
temperature = float(input("Temperature: "))

if temperature < 0:
    print("Freezing")

print("Done")
```

Приклад запуску (вводимо `-5`):

```text
Temperature: -5
Freezing
Done
```

Приклад запуску (вводимо `10`):

```text
Temperature: 10
Done
```

**Пояснення.** Рядок `print("Freezing")` має відступ, тому належить блоку `if` і виконується лише при `temperature < 0`. Рядок `print("Done")` стоїть без відступу й виконується завжди.

**Типові помилки.** Забута двокрапка після умови (`SyntaxError`); відсутній відступ у блоці (`IndentationError`); різна кількість пробілів у рядках одного блоку.

#### 2.4.4. Конструкція `if–else`

**Синтаксис.**

```text
if умова:
    команди, якщо умова істинна
else:
    команди, якщо умова хибна
```

**Приклад.** Парність числа.

```python
number = int(input("Number: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
```

Приклад запуску (вводимо `7`):

```text
Number: 7
Odd
```

**Пояснення.** Остача від ділення на 2 дорівнює нулю для парних чисел. Виконується рівно одна з двох гілок: або `if`, або `else`.

#### 2.4.5. Конструкція `if–elif–else`

**Означення.** Коли варіантів більше двох, додають гілки `elif` («інакше якщо»).

**Синтаксис.**

```text
if умова1:
    команди 1
elif умова2:
    команди 2
elif умова3:
    команди 3
else:
    команди, якщо жодна умова не виконалася
```

**Як це працює.** Умови перевіряються **зверху вниз**. Виконується блок **першої** істинної умови, після цього решта гілок пропускається. Блок `else` необов'язковий і виконується, якщо жодна умова не була істинною.

**Приклад.** Категорія температури.

```python
temperature = float(input("Temperature: "))

if temperature < 0:
    category = "freezing"
elif temperature < 15:
    category = "cold"
elif temperature < 25:
    category = "warm"
else:
    category = "hot"

print(f"Category: {category}")
```

Результати для різних вхідних даних:

| Ввід | Вивід |
| ---- | ----- |
| `-3` | `Category: freezing` |
| `0` | `Category: cold` |
| `14.9` | `Category: cold` |
| `15` | `Category: warm` |
| `25` | `Category: hot` |

**Пояснення.** Значення `0` не менше за 0, тому перша гілка пропускається; друга умова (`< 15`) істинна. Значення `15` потрапляє в третю гілку, а `25` — у `else`. Завдяки перевірці зверху вниз не потрібно записувати нижню межу в кожній умові.

**Типова помилка — неправильний порядок гілок.**

```python
score = 75

if score >= 60:
    print("Pass")
elif score >= 90:
    print("Excellent")
```

Фрагмент завжди виведе тільки `Pass`: умова `score >= 90` ніколи не перевіряється для чисел, що не менші за 60. Гілки слід розташовувати від найвужчої умови до найширшої (тут: спершу `>= 90`, потім `>= 60`).

**Різниця між `elif` і кількома `if`.**

```python
n = 10

if n > 5:
    print("big")
if n > 8:
    print("very big")
```

Очікуваний результат:

```text
big
very big
```

Окремі `if` перевіряються **незалежно**, тому спрацювали обидва. Якщо записати другу умову як `elif`, виведеться лише `big`.

#### 2.4.6. Вкладені умовні конструкції

**Означення.** Усередині блоку `if`, `elif` або `else` можна записати інший `if`. Його блок має ще один рівень відступу.

**Приклад.** Перевірка допустимості значення та вибір відповіді.

```python
hour = int(input("Hour (0-23): "))

if 0 <= hour <= 23:
    if hour < 12:
        print("Before noon")
    else:
        print("After noon")
else:
    print("Error: hour must be from 0 to 23")
```

Результати:

| Ввід | Вивід |
| ---- | ----- |
| `9` | `Before noon` |
| `12` | `After noon` |
| `25` | `Error: hour must be from 0 to 23` |

**Пояснення.** Зовнішній `if` перевіряє, чи число допустиме. Лише якщо так, виконується внутрішня перевірка. Такий підхід дозволяє спершу відсіяти некоректні дані, а потім виконувати основні дії.

**Порада.** Якщо вкладеність перевищує два-три рівні, спробуйте об'єднати умови через `and` або перепишіть алгоритм з `elif`.

#### 2.4.7. Граничні значення

**Означення.** **Граничні значення** — це значення на межі між двома гілками алгоритму. Саме тут найчастіше трапляються помилки через плутанину `<` і `<=`.

**Правило тестування.** Для умови `x < 15` перевіряйте значення `14.9`, `15`, `15.1`; для проміжків `0 ≤ x ≤ 100` — значення `-1`, `0`, `100`, `101`. Кожне значення, що змінює результат умови, має бути у вашому тестовому наборі.

**Приклад.** Кордони проміжку 60–100.

```python
score = int(input("Score: "))

if 60 <= score <= 100:
    print("Pass")
else:
    print("Not pass")
```

| Ввід | Вивід |
| ---- | ----- |
| `59` | `Not pass` |
| `60` | `Pass` |
| `100` | `Pass` |
| `101` | `Not pass` |

#### 2.4.8. Умови для рядків

Рядки порівнюють операторами `==` і `!=`. Для чисел і рядків допустимі `and`, `or`, `not`.

```python
answer = input("Continue? (yes/no): ")

if answer == "yes":
    print("Continuing")
elif answer == "no":
    print("Stopping")
else:
    print("Unknown answer")
```

Результати:

| Ввід | Вивід |
| ---- | ----- |
| `yes` | `Continuing` |
| `no` | `Stopping` |
| `Yes` | `Unknown answer` |

**Пояснення.** Рядок `"Yes"` не дорівнює `"yes"`, бо регістр різний. У завданнях цієї роботи вважайте, що слова вводяться саме так, як зазначено в умові варіанта (малими літерами).

### 2.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- вхідні дані зчитуються через `input()`, кожне значення — окремим запитом, і перетворюються на потрібний тип;
- результати виводяться з підписами, наведеними в умові; дійсні числа — з двома знаками після крапки;
- вказані повідомлення про помилку виводяться **дослівно** (англійською), після чого програма завершується без інших виводів, якщо в умові не сказано інше;
- використовуються лише конструкції з робіт №1–2: цикли, списки, словники, власні функції **не** використовуються;
- в усіх тестових прикладах слова вводяться малими літерами, як у таблиці.

#### Варіант 5. Квадратне рівняння

**Умова.** Програма зчитує коефіцієнти `a`, `b`, `c` (дійсні числа) рівняння `a·x² + b·x + c = 0` та розв'язує його.

- Якщо `a ≠ 0`: виводиться дискримінант `D = b² − 4ac`. При `D > 0` — два корені `x1 = (−b + √D) / (2a)` і `x2 = (−b − √D) / (2a)`; при `D = 0` — один корінь `x = −b / (2a)`; при `D < 0` — повідомлення про відсутність дійсних коренів.
- Якщо `a = 0`, рівняння лінійне `b·x + c = 0`: при `b ≠ 0` виводиться `x = −c / b`; при `b = 0` і `c = 0` — нескінченна кількість розв'язків; при `b = 0` і `c ≠ 0` — розв'язків немає.

**Формат виводу.**

```text
Discriminant: 1.00
Two roots: x1 = 2.00, x2 = 1.00
```

Інші варіанти останнього рядка: `One root: x = ...`, `No real roots`, `Linear equation: x = ...`, `Infinite number of solutions`, `No solutions`. Рядок `Discriminant` виводиться лише при `a ≠ 0`.

**Тести.**

| a | b | c | Вивід |
| - | - | - | ----- |
| 1 | -3 | 2 | `Discriminant: 1.00` / `Two roots: x1 = 2.00, x2 = 1.00` |
| 2 | -4 | -6 | `Discriminant: 64.00` / `Two roots: x1 = 3.00, x2 = -1.00` |
| 1 | 2 | 1 | `Discriminant: 0.00` / `One root: x = -1.00` |
| 1 | 1 | 1 | `Discriminant: -3.00` / `No real roots` |
| 0 | 2 | -4 | `Linear equation: x = 2.00` |
| 0 | 0 | 5 | `No solutions` |
| 0 | 0 | 0 | `Infinite number of solutions` |

### 2.6. Вимоги до реалізації програми

1. Програма зчитує всі вхідні дані, потім перевіряє умови, потім виводить результат.
2. Умови записуються правильними операторами порівняння; для проміжків використовуються `and` або подвійне порівняння.
3. Використовується `if`, `elif`, `else` там, де гілки взаємовиключні (не замінюйте їх набором незалежних `if`, якщо виконуватися має лише одна гілка).
4. Перевірка коректності вхідних даних, якщо вона є в умові варіанта, виконується **до** основних обчислень.
5. Повідомлення про помилки виводяться дослівно, як у варіанті.
6. Перед основними блоками — короткі коментарі англійською, змістовні імена змінних.
7. Не використовуються цикли, списки, словники, множини, кортежі, власні функції та обробка винятків.

### 2.8. Вимоги до перевірки та тестування програми

1. Запустіть програму для **всіх** тестів свого варіанта: кожен рядок таблиці — окремий запуск.
2. Особливу увагу приділіть граничним значенням (значення, при яких змінюється гілка алгоритму): перевірте, чи правильно застосовано `<` та `<=`.
3. Переконайтеся, що кожна гілка вашої програми виконувалась принаймні в одному тесті. Якщо гілка жодного разу не спрацювала, додайте власний тестовий приклад.
4. Якщо результат не збігається, виведіть проміжні значення, з'ясуйте, яка умова спрацювала, і виправте її.

### 2.12. Типові помилки, яких варто уникати

1. Використання `=` замість `==` в умові (`SyntaxError`).
2. Пропущена двокрапка після `if`, `elif`, `else`.
3. Неправильні або непослідовні відступи (`IndentationError`).
4. Неправильний порядок гілок `elif` (див. приклад із оцінками): умова з вужчим діапазоном має стояти раніше.
5. Плутанина `<` і `<=` на межах діапазонів.
6. Запис `x == 1 or 2` замість `x == 1 or x == 2`.
7. Порівняння рядка з числом (`input()` повертає рядок: `if age > 18` без `int()` викликає `TypeError`).
8. Порівняння дійсних результатів обчислень на точну рівність (наприклад, `0.1 + 0.2 == 0.3`).
9. Використання окремих `if` замість `elif`, через що спрацьовує кілька гілок.
10. Відсутність гілки `else` або перевірки некоректних даних, якщо вона передбачена умовою; невраховане регістрове розрізнення рядків (`"Yes"` та `"yes"`).

### 3.4. Теоретичний мінімум

#### 3.4.1. Навіщо потрібні цикли

**Означення.** **Цикл** — це конструкція, яка багаторазово виконує один і той самий блок команд. Одне виконання блоку називається **ітерацією**.

Без циклів, щоб вивести числа від 1 до 100, довелося б написати 100 команд `print()`. Цикл робить це кількома рядками. У Python є два цикли: `while` (виконується, поки істинна умова) та `for` (виконується задану кількість разів або для кожного значення з набору).

#### 3.4.2. Цикл `while`

**Означення.** Цикл `while` повторює блок команд, **поки умова істинна**. Умова перевіряється **перед кожною ітерацією**.

**Синтаксис.**

```text
while умова:
    команди (тіло циклу)
```

Тіло циклу записується з відступом, як і блок `if`.

**Приклад.** Зворотний відлік.

```python
count = 3

while count > 0:
    print(count)
    count = count - 1

print("Start!")
```

Очікуваний результат:

```text
3
2
1
Start!
```

**Пояснення.** Спочатку `count` дорівнює 3, умова `count > 0` істинна — виводиться 3 і `count` зменшується до 2. Так повторюється, поки `count` не стане 0. Тоді умова хибна, цикл завершується, і виконується рядок після циклу.

**Три обов'язкові частини циклу `while`:**

1. **Початкове значення** змінної, яка входить в умову (`count = 3`).
2. **Умова** продовження (`count > 0`).
3. **Зміна** змінної в тілі циклу (`count = count - 1`). Без неї цикл ніколи не завершиться.

**Скорочений запис.** Замість `count = count - 1` можна писати `count -= 1`. Аналогічно: `x += 5` означає `x = x + 5`; також є `*=`, `//=` та інші.

**Типові помилки.**

- Не змінюється змінна умови — виникає **нескінченний цикл** (див. 3.4.10).
- Умова хибна з самого початку — тіло циклу не виконається жодного разу (це не помилка, але про це треба пам'ятати).

#### 3.4.3. Лічильники та накопичувачі

**Лічильник** — змінна, яка збільшується на фіксоване значення (зазвичай на 1) і рахує кількість подій.

**Накопичувач** — змінна, у яку на кожній ітерації додається (або множиться) нове значення, щоб отримати суму чи добуток.

**Початкові значення.** Для суми накопичувач починають з `0`, для добутку — з `1`, для лічильника — з `0`.

**Приклад.** Сума й кількість чисел від 1 до 5, що вводяться з клавіатури.

```python
count = 0
total = 0

while count < 5:
    value = float(input("Enter a number: "))
    total += value
    count += 1

print(f"Count: {count}")
print(f"Sum: {total:.2f}")
```

Приклад запуску (вводимо `2`, `4.5`, `1`, `3`, `0.5`):

```text
Enter a number: 2
Enter a number: 4.5
Enter a number: 1
Enter a number: 3
Enter a number: 0.5
Count: 5
Sum: 11.00
```

**Пояснення.** `count` рахує введені числа й керує завершенням, `total` накопичує суму: 2 + 4.5 + 1 + 3 + 0.5 = 11. Числа обробляються **по одному**: їх не потрібно зберігати всі, достатньо поточного значення й накопичувача.

#### 3.4.4. Цикл `for` і функція `range()`

**Означення.** Цикл `for` виконує тіло для кожного значення з набору. Найчастіше набір створює функція `range()`.

**Синтаксис.**

```text
for змінна in range(...):
    команди
```

**Три форми `range()`:**

| Запис | Які значення проходить змінна |
| ----- | ----------------------------- |
| `range(n)` | `0, 1, …, n-1` |
| `range(a, b)` | `a, a+1, …, b-1` (число `b` **не входить**) |
| `range(a, b, step)` | від `a` з кроком `step`, поки не досягнуто `b` (`b` не входить); `step` може бути від'ємним |

**Приклад.**

```python
for i in range(3):
    print(i)

for i in range(1, 6):
    print(i, end=" ")
print()

for i in range(10, 0, -3):
    print(i, end=" ")
print()
```

Очікуваний результат:

```text
0
1
2
1 2 3 4 5 
10 7 4 1 
```

**Пояснення.** `range(3)` дає 0, 1, 2. `range(1, 6)` дає 1, 2, 3, 4, 5 (число 6 не входить). `range(10, 0, -3)` рухається від 10 вниз із кроком 3: 10, 7, 4, 1. Параметр `end=" "` у `print()` замінює перехід на новий рядок пропуском; порожній `print()` після циклу переводить виведення на новий рядок.

**Коли який цикл використовувати.**

- `for` — коли кількість повторень відома заздалегідь (n чисел, значення від 1 до n).
- `while` — коли кількість повторень залежить від умови (поки не введено 0, поки сума не перевищить поріг).

**Типова помилка.** Забути, що верхня межа `range` не входить: `range(1, 10)` дає числа до 9, а не до 10. Для чисел від 1 до `n` пишуть `range(1, n + 1)`.

Якщо змінна циклу не потрібна в тілі, за традицією її позначають `_`: `for _ in range(5):`.

#### 3.4.5. Суми та добутки

**Приклад.** Факторіал `n! = 1 · 2 · … · n`.

```python
n = int(input("n: "))

factorial = 1
for i in range(1, n + 1):
    factorial *= i

print(f"{n}! = {factorial}")
```

Результати:

| Ввід `n` | Вивід |
| -------- | ----- |
| `5` | `5! = 120` |
| `1` | `1! = 1` |
| `0` | `0! = 1` |

**Пояснення.** Добуток починається з 1. Для `n = 0` діапазон `range(1, 1)` порожній, цикл не виконується, і результат залишається 1 — це збігається з математичним означенням `0! = 1`. Початкове значення накопичувача важливе саме для таких «порожніх» випадків.

#### 3.4.6. Мінімум і максимум серед значень, що вводяться послідовно

Щоб знайти найбільше значення, не зберігаючи всі числа, використовують змінну-«рекордсмена»: у неї записують перше введене число, а потім порівнюють із кожним наступним.

**Приклад.** Найбільше з `n` введених чисел.

```python
n = int(input("How many numbers: "))

biggest = float(input("Number 1: "))
for i in range(2, n + 1):
    value = float(input(f"Number {i}: "))
    if value > biggest:
        biggest = value

print(f"Max: {biggest:.2f}")
```

Приклад запуску (`n = 4`, числа `3`, `-1`, `8`, `5`):

```text
How many numbers: 4
Number 1: 3
Number 2: -1
Number 3: 8
Number 4: 5
Max: 8.00
```

**Пояснення.** `biggest` починається з першого числа. На кожній ітерації, якщо нове число більше за поточного «рекордсмена», воно його замінює. Для мінімуму достатньо змінити знак порівняння на `<`.

**Типова помилка.** Починати «рекордсмена» з `0` — якщо всі числа від'ємні, результат буде неправильним (`0` залишиться «найбільшим»). Правильно починати з першого введеного значення.

**Запам'ятовування позиції.** Щоб знати, на якому кроці було знайдено максимум, додають змінну `position` і оновлюють її разом із `biggest`:

```python
if value > biggest:
    biggest = value
    position = i
```

Оскільки порівняння **строге** (`>`), при кількох однакових максимумах позиція залишається першою.

#### 3.4.7. Умови завершення циклу

Є три типові способи керувати завершенням циклу.

**1. За лічильником** — кількість відома (`for i in range(n)`).

**2. За умовою** — цикл триває, поки виконується умова, що залежить від обчислень:

```python
balance = 100.0
years = 0

while balance < 150:
    balance *= 1.1
    years += 1

print(f"Years: {years}")
print(f"Balance: {balance:.2f}")
```

Очікуваний результат:

```text
Years: 5
Balance: 161.05
```

**Пояснення.** Кожного року сума збільшується на 10 %: 110, 121, 133.1, 146.41, 161.05. Після п'ятого кроку сума перевищила 150 і цикл завершився.

**3. За «сторожовим» значенням** — спеціальне значення, яке означає «кінець введення» (наприклад, `0`). Спочатку читають перше значення, потім у циклі обробляють і читають наступне:

```python
count = 0
total = 0.0

value = float(input("Number (0 to stop): "))
while value != 0:
    total += value
    count += 1
    value = float(input("Number (0 to stop): "))

print(f"Count: {count}")
print(f"Sum: {total:.2f}")
```

Приклад запуску (вводимо `5`, `3`, `-2`, `0`):

```text
Number (0 to stop): 5
Number (0 to stop): 3
Number (0 to stop): -2
Number (0 to stop): 0
Count: 3
Sum: 6.00
```

**Пояснення.** «Сторож» `0` не додається до суми й не рахується. Зверніть увагу на **подвійне читання**: одне перед циклом, друге — в кінці тіла. Якщо користувач одразу введе `0`, цикл не виконається, `Count` буде 0.

**Типова помилка.** Забути друге читання `input()` в кінці тіла — значення не змінюється, і цикл стає нескінченним.

#### 3.4.8. Вкладені цикли

**Означення.** **Вкладений цикл** — це цикл усередині іншого циклу. Внутрішній цикл виконується повністю на кожній ітерації зовнішнього.

**Приклад.** Таблиця множення на 3 рядки та 4 стовпчики.

```python
for i in range(1, 4):
    for j in range(1, 5):
        print(f"{i * j:3d}", end="")
    print()
```

Очікуваний результат:

```text
  1  2  3  4
  2  4  6  8
  3  6  9 12
```

**Пояснення.** Зовнішній цикл вибирає рядок `i`, внутрішній проходить стовпчики `j` і виводить добуток без переходу на новий рядок (`end=""`). Формат `:3d` резервує під ціле число 3 позиції, вирівнюючи його праворуч. Після завершення внутрішнього циклу порожній `print()` переходить на новий рядок. Загальна кількість виконань внутрішнього тіла: 3 · 4 = 12.

**Типова помилка.** Неправильний відступ: якщо `print()` у кінці рядка записати з відступом внутрішнього циклу, перехід на новий рядок відбуватиметься після кожного числа.

#### 3.4.9. Дільники та цифри числа

Два прийоми, потрібні для кількох варіантів.

**Перевірка подільності:** `n % d == 0` означає, що `d` є дільником `n`.

**Розбір числа на цифри:** остача `n % 10` — остання цифра, а `n // 10` — число без останньої цифри.

```python
number = 4075
digit_sum = 0

while number > 0:
    digit = number % 10
    digit_sum += digit
    number //= 10

print(f"Digit sum: {digit_sum}")
```

Очікуваний результат:

```text
Digit sum: 16
```

**Пояснення.** Цифри відокремлюються по черзі: 5, 7, 0, 4. Сума 5 + 7 + 0 + 4 = 16. Коли `number` стає 0, цикл завершується.

#### 3.4.10. Нескінченні цикли та типові помилки

**Нескінченний цикл** — цикл, умова якого завжди істинна. Програма «зависає». Щоб примусово її зупинити, натисніть `Ctrl + C` у терміналі.

```python
n = 5
while n > 0:
    print(n)
# n never changes: infinite loop
```

**Як уникнути.**

1. Перед запуском переконайтеся, що в тілі циклу змінюється змінна з умови.
2. Переконайтеся, що зміна рухає значення **в бік** завершення (не `+= 1` для умови `n > 0`).
3. Перевірте цикл на найменших вхідних даних і на «порожньому» випадку.

**Інші типові помилки.**

- «Зсув на одиницю» (off-by-one): `range(n)` замість `range(1, n + 1)`.
- Накопичувач не обнулено перед циклом або обнулено всередині циклу.
- Початкове значення мінімуму/максимуму вибране довільно (наприклад, `0`).
- Неправильний відступ для команд, які мають виконуватися після циклу.

### 3.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах:

- вхідні дані зчитуються через `input()` по одному, **без збереження всіх значень** (списки та інші колекції не використовуються);
- підказки для `input()` можуть бути довільними, але виведені результати мають збігатися за змістом і форматом з умовою (підписи англійською, дійсні числа — з двома знаками після крапки, якщо не зазначено інше);
- кількість введених чисел, де вона потрібна, вводиться першою;
- програма не перевіряє коректність введення, окрім випадків, зазначених в умові;
- використовуються лише конструкції з робіт №1–3.

### 3.6. Вимоги до реалізації програми

1. Використовується потрібний тип циклу: `for` — коли кількість повторень відома, `while` — коли завершення залежить від умови або значення.

6. Короткі коментарі англійською перед логічними блоками; змістовні імена змінних (`total`, `count`, `biggest`).

### 3.11. Критерії оцінювання (максимум 10 балів)

| Критерій | Максимум балів | Вимоги для отримання балів |
| -------- | -------------- | -------------------------- |
| Правильність алгоритму циклу | 3 | **3** — алгоритм правильний, обрано доцільний тип циклу, лічильники й накопичувачі мають правильні початкові значення, цикл завершується, результати збігаються з очікуваними в усіх тестах. **2** — алгоритм загалом правильний, але є помилка в одному тесті (наприклад, на мінімальному випадку). **1** — алгоритм працює лише для частини тестів. **0** — алгоритм неправильний або програма «зависає». |
| Реалізація вимог завдання | 2 | **2** — реалізовано всі вимоги варіанта (усі виведені величини, додаткові умови); дані обробляються по одному без колекцій. **1** — не виконано одну з вимог. **0** — виконано менше половини вимог або використано невивчені конструкції замість вимоги. |
| Введення та формат виводу | 1 | **1** — дані зчитуються й перетворюються на потрібні типи, вивід відповідає формату (підписи, точність). **0** — формат виводу не відповідає умові або типи не перетворені. |
| Перевірка програми | 2 | **2** — у звіті є таблиця перевірки на всіх тестах варіанта, зокрема на мінімальному («порожньому») випадку, результати «отримано» відповідають реальному запуску. **1** — перевірено лише частину тестів або немає мінімального випадку. **0** — тестування відсутнє. |
| Якість та оформлення коду | 2 | **2** — змістовні англійські імена, коментарі, правильні відступи, відсутність зайвих змінних і дублювання коду, використано `+=` і `range` доречно. **1** — є окремі недоліки (частина імен беззмістовна, мало коментарів). **0** — код нечитабельний або без коментарів і змістовних імен. |
| **Разом** | **10** | |

Перевірка суми: 3 + 2 + 1 + 2 + 2 = 10.

### 3.12. Типові помилки, яких варто уникати

1. Нескінченний цикл `while` через те, що змінна умови не змінюється або змінюється в «неправильний» бік.
2. Забуте повторне читання `input()` в кінці тіла циклу зі «сторожовим» значенням.
3. Помилка «на одиницю»: `range(n)` замість `range(1, n + 1)`; забули, що верхня межа `range` не входить.
4. Накопичувач не обнулено перед циклом або обнулено всередині циклу.
5. Початкове значення добутку `0` замість `1` (добуток завжди 0).
6. Мінімум/максимум ініціалізовано довільним числом (`0`, `100`) замість першого введеного значення.
7. Неправильні відступи: команда, яка має виконатись один раз після циклу, потрапила в тіло, або навпаки.
8. Зміна змінної, за якою йде `for` (`i`), всередині тіла циклу в надії вплинути на ітерації: це не працює так, як очікується.
9. Використання списку для зберігання всіх введених значень там, де достатньо обробляти їх по одному (в цій роботі колекції не дозволені).
10. Відсутність перевірки «порожнього» випадку (перше ж введене `0`, `n = 1`, `n = 0`) і ділення на нуль при обчисленні середнього.

### 4.4. Теоретичний мінімум

#### 4.4.1. Поняття послідовності та список

**Означення.** **Послідовність** — це впорядкований набір значень, у якому кожне значення має свій номер (індекс). Рядок `str` уже є послідовністю символів. **Список** (`list`) — це змінювана послідовність довільних значень.

**Навіщо.** Раніше для кожного значення потрібна була окрема змінна, а в роботі №3 ми обробляли значення по одному й «забували» їх. Список дозволяє зберегти багато значень під одним іменем і повертатися до них: обчислити середнє, а потім знайти числа, більші за середнє.

**Синтаксис.** Значення записують у квадратних дужках через кому.

```python
temperatures = [12.5, 14.0, 9.5]
names = ["Anna", "Ivan", "Olena"]
empty = []
```

Список може містити значення різних типів, але на практиці зазвичай зберігають однотипні значення.

#### 4.4.2. Індексація та зміна елементів

**Індекс** — номер елемента. Нумерація починається з **нуля**. Від'ємні індекси рахують з кінця: `-1` — останній елемент.

**Приклад.**

```python
marks = [85, 52, 60, 97]

print(marks[0])
print(marks[3])
print(marks[-1])

marks[1] = 55
print(marks)
print(len(marks))
```

Очікуваний результат:

```text
85
97
97
[85, 55, 60, 97]
4
```

**Пояснення.** `marks[0]` — перший елемент, `marks[-1]` — останній. Присвоювання `marks[1] = 55` замінює другий елемент. Функція `len()` повертає кількість елементів. Допустимі індекси — від `0` до `len(marks) - 1`.

**Типова помилка.** Звернення за неіснуючим індексом (`marks[4]` для списку з 4 елементів) викликає `IndexError: list index out of range`.

#### 4.4.3. Додавання та видалення елементів

| Метод | Дія | Приклад |
| ----- | --- | ------- |
| `a.append(x)` | додає `x` в **кінець** списку | `a.append(5)` |
| `a.insert(i, x)` | вставляє `x` на позицію `i`, зсуваючи решту | `a.insert(0, 5)` |
| `a.remove(x)` | видаляє **перше** входження значення `x` | `a.remove(5)` |
| `a.pop()` | видаляє й повертає **останній** елемент | `last = a.pop()` |
| `a.pop(i)` | видаляє й повертає елемент з індексом `i` | `first = a.pop(0)` |

**Приклад.**

```python
a = [10, 20, 30]

a.append(40)
a.insert(1, 15)
a.remove(30)
last = a.pop()

print(a)
print(last)
```

Очікуваний результат:

```text
[10, 15, 20]
40
```

**Пояснення.** Після `append(40)`: `[10, 20, 30, 40]`. Після `insert(1, 15)`: `[10, 15, 20, 30, 40]`. `remove(30)` видаляє значення 30: `[10, 15, 20, 40]`. `pop()` забирає останній елемент `40` і повертає його в змінну `last`; у списку залишається `[10, 15, 20]`.

**Типові помилки.**

- `a.remove(x)` для значення, якого немає в списку, викликає `ValueError`. Перед видаленням перевіряйте наявність за допомогою оператора `in`.
- `a.pop()` для порожнього списку викликає `IndexError`.

**Оператор `in`.** Вираз `x in a` дає `True`, якщо значення `x` є в списку, інакше `False`; `x not in a` — навпаки.

```python
fruits = ["apple", "pear"]

print("pear" in fruits)
print("plum" in fruits)
print("plum" not in fruits)
```

Очікуваний результат:

```text
True
False
True
```

#### 4.4.4. Функції `len()`, `min()`, `max()`, `sum()`

| Функція | Значення |
| ------- | -------- |
| `len(a)` | кількість елементів |
| `min(a)` | найменший елемент (список не порожній) |
| `max(a)` | найбільший елемент (список не порожній) |
| `sum(a)` | сума елементів (для порожнього списку — `0`) |

```python
values = [4, 9, 1, 6]

print(len(values), min(values), max(values), sum(values))
average = sum(values) / len(values)
print(f"Average: {average:.2f}")
```

Очікуваний результат:

```text
4 1 9 20
Average: 5.00
```

**Типова помилка.** `min([])`, `max([])` викликають `ValueError`, а `sum(a) / len(a)` для порожнього списку дає ділення на нуль. Якщо список може бути порожнім, спершу перевірте `if len(a) == 0:`.

#### 4.4.5. Обхід списків за допомогою циклів

**За елементами:**

```python
prices = [10.0, 25.5, 4.0]
total = 0

for price in prices:
    total += price

print(f"Total: {total:.2f}")
```

Очікуваний результат:

```text
Total: 39.50
```

**За індексами** (потрібні, коли важливий номер елемента):

```python
marks = [85, 52, 60, 97]

for i in range(len(marks)):
    print(f"Mark {i + 1}: {marks[i]}")
```

Очікуваний результат:

```text
Mark 1: 85
Mark 2: 52
Mark 3: 60
Mark 4: 97
```

**Пояснення.** `range(len(marks))` дає індекси `0, 1, 2, 3`. Для людей нумерацію зручніше показувати з 1, тому виводимо `i + 1`.

**Створення нового списку з відібраних елементів.** Спочатку створюють порожній список, а потім у циклі додають у нього потрібні елементи:

```python
marks = [85, 52, 60, 97, 59]
passed = []

for mark in marks:
    if mark >= 60:
        passed.append(mark)

print(passed)
```

Очікуваний результат:

```text
[85, 60, 97]
```

**Типова помилка.** Не видаляйте й не додавайте елементи до списку **під час** обходу цього самого списку: цикл поведе себе непередбачувано. Створюйте новий список, як у прикладі вище.

**Зворотний обхід** виконується через `range` із від'ємним кроком:

```python
a = [3, 8, 1]
for i in range(len(a) - 1, -1, -1):
    print(a[i])
```

Очікуваний результат:

```text
1
8
3
```

#### 4.4.6. Файли: відкриття та режими

**Означення.** **Текстовий файл** зберігає символи. Програма може читати з файлу дані, підготовлені заздалегідь, і записувати в файл результати.

**Де шукається файл.** Якщо вказано лише ім'я (`"input.txt"`), Python шукає файл у **поточній папці** — тій, з якої запущено програму. Тому розташуйте програму та файли в одній папці й запускайте програму з неї:

```text
cd шлях/до/вашої/папки
python lab04_variant01.py
```

**Синтаксис.**

```text
with open("ім'я_файлу", "режим", encoding="utf-8") as file:
    команди роботи з файлом
```

**Режими відкриття.**

| Режим | Призначення | Якщо файл існує | Якщо файлу немає |
| ----- | ----------- | --------------- | ---------------- |
| `"r"` | читання | читається | помилка `FileNotFoundError` |
| `"w"` | запис | **вміст стирається** | файл створюється |
| `"a"` | дописування в кінець | вміст зберігається | файл створюється |

**Навіщо `with`.** Конструкція `with open(...) as file:` автоматично закриває файл, коли блок завершується (навіть якщо виникла помилка). Закритий файл гарантовано збережений. Завжди користуйтеся саме `with`.

**Навіщо `encoding="utf-8"`.** `UTF-8` — стандартне кодування, яке підтримує українські літери та інші символи. Якщо не вказати кодування, на деяких комп'ютерах (особливо Windows) файл може прочитатися або записатися некоректно. Тому вказуйте `encoding="utf-8"` завжди.

#### 4.4.7. Запис у файл

Метод `file.write(текст)` записує рядок. **Перехід на новий рядок не додається автоматично** — його потрібно дописати символом `"\n"`.

**Приклад.**

```python
numbers = [3, 8, 5]

with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Numbers:\n")
    for number in numbers:
        file.write(f"{number}\n")
    file.write(f"Sum: {sum(numbers)}\n")
```

Вміст файлу `output.txt` після виконання:

```text
Numbers:
3
8
5
Sum: 16
```

**Пояснення.** Режим `"w"` створює файл (або стирає старий вміст). Кожен виклик `write()` дописує текст; символ `\n` завершує рядок. Метод `write()` приймає лише рядок: числа перетворюють через f-рядок або `str()`.

**Дописування.** Якщо відкрити той самий файл у режимі `"a"` і записати `file.write("End\n")`, рядок `End` з'явиться після існуючого вмісту.

**Типова помилка.** Забути `"\n"` — усі значення опиняться в одному рядку (`"first"` + `"second"` дає `firstsecond`). Інша помилка — відкрити файл для запису в режимі `"w"` у циклі: на кожній ітерації вміст стиратиметься. Відкривайте файл один раз до циклу.

#### 4.4.8. Читання файлу: цілком і по рядках

Припустимо, є файл `data.txt`:

```text
10
20
30
```

(кожне число в окремому рядку, після останнього рядка — перехід на новий рядок).

**Спосіб 1. Прочитати весь файл як один рядок — `read()`.**

```python
with open("data.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(len(text))
print(repr(text))
```

Очікуваний результат:

```text
9
'10\n20\n30\n'
```

**Пояснення.** `read()` повертає весь вміст як один рядок, у якому є символи переходу на новий рядок `\n`. Усього 9 символів: `1`, `0`, `\n`, `2`, `0`, `\n`, `3`, `0`, `\n`. Функція `repr()` показує рядок у «службовому» вигляді, щоб бачити `\n`.

**Спосіб 2. Читати по рядках — цикл `for line in file`.**

```python
numbers = []

with open("data.txt", "r", encoding="utf-8") as file:
    for line in file:
        numbers.append(int(line))

print(numbers)
print(sum(numbers))
```

Очікуваний результат:

```text
[10, 20, 30]
60
```

**Пояснення.** Цикл по файлу на кожній ітерації дає один рядок разом із завершальним `\n` (тобто `"10\n"`). Функції `int()` та `float()` ігнорують пропуски й переходи на новий рядок по краях, тому `int("10\n")` дорівнює `10`. Таким чином файл «один елемент на рядок» перетворюється на список чисел.

**Спосіб 3. Метод `readlines()`** повертає **список** усіх рядків файлу (разом із `\n`):

```python
with open("data.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

print(lines)
print(len(lines))
```

Очікуваний результат:

```text
['10\n', '20\n', '30\n']
3
```

**Коли що використовувати.**

- `read()` — коли потрібен весь текст цілком (наприклад, порахувати символи).
- Цикл `for line in file` — коли потрібно обробляти дані по рядках (найчастіший випадок, не завантажує файл у пам'ять повністю).
- `readlines()` — коли потрібні всі рядки відразу у вигляді списку (кількість рядків, доступ за індексом).

**Виведення рядка файлу.** Якщо вивести рядок через `print(line)`, між рядками з'являться порожні рядки (бо `print` додає свій `\n` до вже наявного). Щоб цього уникнути, пишіть `print(line, end="")`.

**Порожні рядки.** Порожній рядок у файлі при читанні дає `"\n"`. Тому `int("\n")` викликає `ValueError`. Файли з числами не повинні містити порожніх рядків (також і в кінці).

**Типові помилки.**

- Неправильне ім'я файлу або запуск з іншої папки: `FileNotFoundError`.
- Читання з файлу, відкритого в режимі `"w"`, і запис у файл, відкритий у режимі `"r"`.
- Використання змінної `file` за межами блоку `with`: файл уже закрито.
- Забули перетворити рядок на число: `"10\n" + "20\n"` склеює текст.

#### 4.4.9. Шаблон програми «файл → список → обробка → файл»

```python
# Read numbers from input file into a list
numbers = []
with open("input.txt", "r", encoding="utf-8") as file:
    for line in file:
        numbers.append(float(line))

# Process data
count = len(numbers)
total = sum(numbers)

# Write results to output file
with open("output.txt", "w", encoding="utf-8") as file:
    file.write(f"Count: {count}\n")
    file.write(f"Sum: {total:.2f}\n")
```

Для `input.txt` із вмістом `2.5`, `4`, `1.5` (по одному в рядку) файл `output.txt` міститиме:

```text
Count: 3
Sum: 8.00
```

### 4.5. Індивідуальні завдання

Номер варіанта визначає викладач. У всіх варіантах (крім зазначених в умові):

- вхідні дані читаються з файлу `input.txt`, результати записуються у файл `output.txt`; обидва файли розташовані в одній папці з програмою;
- у файлі `input.txt` **одне значення в рядку**, без порожніх рядків; файл завершується переходом на новий рядок;
- файли відкриваються через `with open(...)` із `encoding="utf-8"`;
- дійсні числа записуються у вихідний файл із двома знаками після крапки (якщо не зазначено інше), підписи — англійською, як у прикладах;
- використовуються лише списки, цикли, умови та конструкції з робіт №1–4; словники, функції `split()`, `strip()` та інші методи рядків не використовуються;

### 4.12. Типові помилки, яких варто уникати

1. Звернення до елемента за індексом, що виходить за межі списку (`a[len(a)]`); плутанина нумерації з 0 та з 1.
2. Видалення або додавання елементів у список під час обходу цього самого списку.
3. Виклик `remove()` без перевірки наявності елемента (`ValueError`), `min()`, `max()`, `pop()` для порожнього списку.
4. Ділення на `len(a)` для порожнього списку (ділення на нуль).
5. Відкриття файлу для запису в режимі `"w"` усередині циклу: на кожній ітерації вміст стирається.
6. Забутий `"\n"` у `write()`: усе записується в один рядок.
7. Відсутність `encoding="utf-8"` у `open()`.
8. Спроба записати в `write()` число без перетворення на рядок (`TypeError`).
9. Використання змінної файлу після виходу з блоку `with`; запуск програми з іншої папки (`FileNotFoundError`).
10. Порожній рядок (зокрема в кінці) у файлі з числами: `int("\n")` і `float("\n")` викликають `ValueError`.

### 5.4. Теоретичний мінімум

#### 5.4.1. Що таке словник і чим він відрізняється від списку

**Означення.** **Словник** (`dict`) — це набір пар «**ключ** → **значення**». За ключем можна швидко знайти відповідне значення, як слово в тлумачному словнику чи прізвище в телефонній книзі.

| Властивість | Список | Словник |
| ----------- | ------ | ------- |
| Звернення до елемента | за номером (індексом): `a[2]` | за ключем: `d["Anna"]` |
| Для чого | впорядкований набір однотипних значень | зіставлення «назва → дані» |
| Дублікати | елементи можуть повторюватися | ключі **унікальні** |
| Приклад | оцінки: `[85, 72, 91]` | оцінки за іменами: `{"Anna": 85, "Ivan": 72}` |

**Коли що обирати.** Якщо головне — порядок і номер значення (виміри за днями), доцільний список. Якщо значення потрібно знаходити за назвою чи кодом (оцінка за прізвищем, ціна за назвою товару, кількість за словом) — словник.

Ключем може бути рядок або число (`int`). Значенням — що завгодно, зокрема список чи інший словник.

#### 5.4.2. Створення словника, читання та зміна значень

**Синтаксис.** Пари `ключ: значення` записують у фігурних дужках через кому.

```python
prices = {"bread": 25.0, "milk": 38.5, "eggs": 65.0}
empty = {}

print(prices["milk"])
prices["milk"] = 40.0
prices["apple"] = 30.0
print(prices)
print(len(prices))
```

Очікуваний результат:

```text
38.5
{'bread': 25.0, 'milk': 40.0, 'eggs': 65.0, 'apple': 30.0}
4
```

**Пояснення.** `prices["milk"]` читає значення за ключем. Присвоювання `prices["milk"] = 40.0` змінює значення наявного ключа; присвоювання з **новим** ключем (`"apple"`) додає запис. Функція `len()` повертає кількість пар. Порядок записів збігається з порядком їх додавання.

**Типова помилка.** Звернення до неіснуючого ключа (`prices["juice"]`) викликає `KeyError: 'juice'`. Перед зверненням перевіряють ключ оператором `in` або користуються методом `get()`.

#### 5.4.3. Перевірка ключа, метод `get()`, видалення записів

**Оператор `in`** для словника перевіряє наявність **ключа**.

```python
prices = {"bread": 25.0, "milk": 38.5}

print("milk" in prices)
print("juice" in prices)
print(prices.get("milk"))
print(prices.get("juice"))
print(prices.get("juice", 0))
```

Очікуваний результат:

```text
True
False
38.5
None
0
```

**Пояснення.** `d.get(ключ)` повертає значення або спеціальне значення `None` («нічого»), якщо ключа немає, і **не викликає помилки**. Другий аргумент `d.get(ключ, значення)` задає значення за замовчуванням.

**Видалення.**

| Запис | Дія |
| ----- | --- |
| `del d[ключ]` | видаляє запис; якщо ключа немає — `KeyError` |
| `d.pop(ключ)` | видаляє запис і повертає його значення |

```python
stock = {"apple": 10, "pear": 5}

removed = stock.pop("pear")
del stock["apple"]

print(removed)
print(stock)
```

Очікуваний результат:

```text
5
{}
```

#### 5.4.4. Методи `keys()`, `values()`, `items()` та перебір словника

| Метод | Що повертає |
| ----- | ----------- |
| `d.keys()` | усі ключі |
| `d.values()` | усі значення |
| `d.items()` | пари «ключ, значення» |

Їх використовують у циклах і з функціями `len()`, `sum()`, `min()`, `max()`.

```python
marks = {"Anna": 85, "Ivan": 72, "Olena": 91}

for name in marks:
    print(name)

for name, mark in marks.items():
    print(f"{name}: {mark}")

print(sum(marks.values()))
print(max(marks.values()))
```

Очікуваний результат:

```text
Anna
Ivan
Olena
Anna: 85
Ivan: 72
Olena: 91
248
91
```

**Пояснення.** Цикл `for name in marks` обходить **ключі**. Цикл `for name, mark in marks.items()` на кожній ітерації дає ключ і значення в двох змінних одночасно. Функції `sum()` та `max()` застосовано до значень.

**Пошук ключа з найбільшим значенням** виконують у циклі, подібно до пошуку максимуму в роботі №3:

```python
best_name = ""
best_mark = -1
for name, mark in marks.items():
    if mark > best_mark:
        best_name = name
        best_mark = mark

print(best_name, best_mark)
```

Для словника `marks` вище виведе `Olena 91`. Через строге порівняння `>` при рівних значеннях залишається ключ, що зустрівся першим.

**Типова помилка.** Змінювати словник (додавати чи видаляти ключі) під час перебору цього ж словника. Щоб відібрати записи, створюйте новий словник або список.

#### 5.4.5. Шаблон «лічильник за ключем»

Часта задача: порахувати, скільки разів зустрівся кожен елемент, або підсумувати значення за групами. Метод `get()` з нульовим значенням за замовчуванням робить це в один рядок:

```python
votes = ["red", "blue", "red", "green", "red", "blue"]
counts = {}

for color in votes:
    counts[color] = counts.get(color, 0) + 1

print(counts)
```

Очікуваний результат:

```text
{'red': 3, 'blue': 2, 'green': 1}
```

**Пояснення.** Якщо кольору ще немає в словнику, `get()` повертає `0`, і записується `0 + 1`; якщо вже є — значення збільшується на 1. Аналогічно підсумовують суми за категоріями:

```python
totals[category] = totals.get(category, 0) + amount
```

#### 5.4.6. Поєднання списків і словників

**Словник як опис об'єкта.** Один об'єкт предметної області (книга, студент, товар) зручно описувати словником, де ключі — назви властивостей:

```python
book = {"title": "Kobzar", "author": "Taras Shevchenko", "year": 1840}
print(book["title"])
print(f"{book['title']} ({book['year']})")
```

Очікуваний результат:

```text
Kobzar
Kobzar (1840)
```

**Зверніть увагу:** усередині f-рядка, обмеженого подвійними лапками, ключі словника записують в **одинарних** лапках (`book['title']`), інакше рядок завершиться передчасно.

**Список словників** зберігає набір однотипних об'єктів:

```python
books = []
books.append({"title": "Kobzar", "year": 1840})
books.append({"title": "Moses", "year": 1905})

for book in books:
    print(book["title"], book["year"])
```

Очікуваний результат:

```text
Kobzar 1840
Moses 1905
```

**Словник зі списками як значеннями** групує кілька значень під одним ключем:

```python
cities = ["Kyiv", "Lviv", "Kyiv"]
temps = [5.0, 3.5, 7.0]
readings = {}

for i in range(len(cities)):
    city = cities[i]
    if city not in readings:
        readings[city] = []
    readings[city].append(temps[i])

print(readings)
print(sum(readings["Kyiv"]) / len(readings["Kyiv"]))
```

Очікуваний результат:

```text
{'Kyiv': [5.0, 7.0], 'Lviv': [3.5]}
6.0
```

**Пояснення.** Для кожного міста, що зустрілося вперше, створюється порожній список; потім до нього додається температура. Вираз `readings["Kyiv"]` повертає список, до якого можна застосувати `sum()` і `len()`.

#### 5.4.7. Метод рядка `strip()`

Під час читання файлу кожен рядок завершується символом `"\n"`. Для чисел це не заважає (`int("85\n")` дорівнює `85`), але **рядок**, який використовується як ключ словника або виводиться, потрібно очистити. Метод `strip()` видаляє пропуски та символ переходу на новий рядок на початку й у кінці рядка:

```python
line = "Anna\n"
name = line.strip()

print(repr(line))
print(repr(name))
```

Очікуваний результат:

```text
'Anna\n'
'Anna'
```

**Типова помилка.** Забути `strip()`: тоді ключ `"Anna\n"` не дорівнює ключу `"Anna"`, який користувач ввів із клавіатури, і пошук у словнику не знаходить запису. Докладніше про методи рядків — у роботі №6.

#### 5.4.8. Зберігання словника у файлі та читання з файлу

У цій роботі використовується простий формат: **кожен запис займає кілька послідовних рядків** файлу. Для словника «ім'я → оцінка» це два рядки на запис: у першому — ключ, у другому — значення.

Приклад файлу `input.txt`:

```text
Anna
85
Ivan
72
Olena
91
```

**Читання.** Усі рядки зчитують у список методом `readlines()` і обходять із кроком 2:

```python
marks = {}

with open("input.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

for i in range(0, len(lines), 2):
    name = lines[i].strip()
    mark = int(lines[i + 1])
    marks[name] = mark

print(marks)
```

Очікуваний результат:

```text
{'Anna': 85, 'Ivan': 72, 'Olena': 91}
```

**Пояснення.** `range(0, len(lines), 2)` дає індекси `0, 2, 4`, тобто рядки з іменами; значення лежить у наступному рядку (`i + 1`). Ім'я очищається методом `strip()`, число перетворюється функцією `int()`. Повторне ім'я у файлі **перезапише** значення в словнику, бо ключі унікальні.

**Запис.**

```python
with open("output.txt", "w", encoding="utf-8") as file:
    for name, mark in marks.items():
        file.write(f"{name}\n")
        file.write(f"{mark}\n")
```

Файл `output.txt` матиме той самий формат, що й `input.txt`. Завдяки цьому результат однієї програми може бути вхідними даними для іншої.

**Типові помилки.**

- Непарна кількість рядків у файлі: `lines[i + 1]` викликає `IndexError`.
- Порожній рядок у кінці файлу: `int("\n")` викликає `ValueError`.
- Відсутній `"\n"` у `write()`: пари зливаються в один рядок.

#### 5.4.9. Типові помилки зі словниками

1. `KeyError` — звернення до відсутнього ключа через `d[key]`; використовуйте `in` чи `get()`.
2. Дублювання ключів: другий запис із тим самим ключем **замінює** перший, а не додається.
3. Ключем не можна зробити список (`d[[1, 2]] = 5` — помилка); використовуйте рядок або число.
4. Плутанина між ключем і значенням при переборі: `for x in d` дає ключі, а не значення.
5. Забутий `strip()` у ключах, прочитаних із файлу.
6. Зміна розміру словника під час перебору.

Номер варіанта визначає викладач. У всіх варіантах (крім зазначених в умові):

- вхідні дані читаються з файлу `input.txt`, результати записуються у файл `output.txt`; файли розташовано в одній папці з програмою;
- у файлах **кожен запис займає один або кілька послідовних рядків** — формат зазначено в умові; порожніх рядків немає, файл завершується переходом на новий рядок;
- файли відкриваються через `with open(...)` з `encoding="utf-8"`;
- дійсні числа у вихідних даних — з двома знаками після крапки, якщо не зазначено інше; підписи — англійською, як у прикладах;
- використовуються лише конструкції з робіт №1–5 та `strip()`; методи `split()`, `join()`, `replace()`, модуль `csv` і власні функції **не** використовуються;
- словники застосовуються як основна структура даних (де це вказано — разом зі списками);
- для кожного тесту вказано вміст вхідного файлу та очікуваний результат.

Запис тестових даних: у блоках «`input.txt`» кожен елемент через кому — це окремий рядок файлу, якщо не показано блок коду з рядками.

### 5.6. Вимоги до реалізації програми

1. Основні дані зберігаються у словнику (у варіантах 6, 9, 11 — у поєднанні зі списками).
2. Ключі, прочитані з файлу, очищаються методом `strip()`; числові значення перетворюються функціями `int()` або `float()`.
3. Для підрахунку й накопичення використовується `get()` (або перевірка `in`), без звернення до відсутніх ключів.
4. Файли відкриваються через `with open(...)` з `encoding="utf-8"`; файл для запису відкривається один раз.
5. Кожен рядок вихідного файлу завершується `"\n"`; формат відповідає умові.
6. Словник не змінюється під час перебору цього самого словника.
7. Граничні випадки (порожній файл, один запис, рівні значення) обробляються за умовою варіанта.
8. Коментарі англійською, змістовні імена змінних (`marks`, `counts`, `stock`); не використовуються `split()`, `csv`, власні функції.

#### 6.4.1. Вхідні та вихідні файли програми

Програма, що обробляє дані, зазвичай має **вхідний файл** (звідки читає) та **вихідний файл** (куди пише результат). Їхні імена задано в умові варіанта. Правила такі самі, як у роботах №4–5:

- програма й файли лежать в одній папці, програма запускається з цієї папки (`python lab06_variant01.py`);
- вхідний файл відкривається в режимі `"r"`, вихідний — у режимі `"w"` (раніше створений вміст стирається);
- завжди вказується `encoding="utf-8"`;
- усі файли відкриваються через `with open(...)`;
- вхідний файл не змінюється програмою.

#### 6.4.2. Методи рядків

Рядки в Python **незмінні**: метод не змінює рядок, а повертає **новий** рядок, тому результат потрібно записати в змінну.

| Метод | Дія | Приклад | Результат |
| ----- | --- | ------- | --------- |
| `s.strip()` | видаляє пропуски та `\n` на початку й у кінці | `"  Anna\n".strip()` | `"Anna"` |
| `s.split(роздільник)` | розбиває рядок на **список** частин | `"a;b;c".split(";")` | `["a", "b", "c"]` |
| `sep.join(список)` | з'єднує **список рядків** в один рядок через `sep` | `", ".join(["a", "b"])` | `"a, b"` |
| `s.replace(старе, нове)` | замінює всі входження підрядка | `"2,5".replace(",", ".")` | `"2.5"` |
| `s.isdigit()` | `True`, якщо рядок непорожній і складається лише з цифр | `"123".isdigit()` | `True` |

**Приклад.**

```python
line = "  Anna;85;90\n"

clean = line.strip()
parts = clean.split(";")
print(parts)
print(len(parts))
print(parts[0], int(parts[1]) + int(parts[2]))

names = ["Anna", "Ivan", "Olena"]
print(", ".join(names))

price = "2,5"
print(float(price.replace(",", ".")))
```

Очікуваний результат:

```text
['Anna', '85', '90']
3
Anna 175
Anna, Ivan, Olena
2.5
```

**Пояснення.** `strip()` прибирає зайві пропуски й `\n`; `split(";")` перетворює рядок на список із трьох рядків; елементи списку доступні за індексом. Метод `join()` викликають **у роздільника**, а аргументом передають список **рядків** (числа спершу перетворіть: `str(x)`). Метод `replace()` дозволяє замінити десяткову кому на крапку перед `float()`.

**Типові помилки.**

- Викликати `strip()` і не записати результат: `line.strip()` без присвоювання нічого не змінює.
- `", ".join([1, 2])` — `TypeError`, бо елементи не рядки.
- `split()` без аргументів розбиває за пропусками; для іншого роздільника його потрібно вказати.

#### 6.4.3. Перетворення рядків на числа та перевірка коректності

Функції `int()` і `float()` викликають помилку `ValueError`, якщо рядок не є числом. Оскільки в цьому курсі обробка винятків не розглядається, **коректність перевіряють заздалегідь**:

| Що перевіряємо | Умова | `True` для | `False` для |
| -------------- | ----- | ---------- | ----------- |
| невід'ємне ціле | `text.isdigit()` | `"15"`, `"0"` | `"-3"`, `"2.5"`, `"abc"`, `""` |
| невід'ємне дійсне | `text.replace(".", "", 1).isdigit()` | `"15"`, `"2.5"` | `"2.5.1"`, `"abc"`, `""`, `"-2"` |
| поле не порожнє | `text != ""` | `"Anna"` | `""` |
| кількість полів | `len(row) == 4` | рядок із чотирма полями | рядки з меншою чи більшою кількістю |

**Як працює перевірка дійсного числа.** `replace(".", "", 1)` видаляє **одну** крапку (третій аргумент — максимальна кількість замін), і якщо після цього залишилися лише цифри, значення — коректне невід'ємне число. Рядок `"2.5.1"` після видалення першої крапки дає `"25.1"`, де ще лишається крапка, тому `isdigit()` повертає `False`.

```python
values = ["15", "2.5", "-3", "abc", "", "2.5.1"]

for text in values:
    ok = text.replace(".", "", 1).isdigit()
    print(f"{text!r}: {ok}")
```

Очікуваний результат:

```text
'15': True
'2.5': True
'-3': False
'abc': False
'': False
'2.5.1': False
```

**Пояснення.** Запис `{text!r}` у f-рядку виводить значення у лапках (як `repr`), щоб було видно порожній рядок. Негативні числа цією перевіркою відхиляються; у завданнях цієї роботи від'ємних значень немає, а рядок із знаком мінус вважається некоректним.

**Рекомендований порядок перевірок** — від простих до складних: спершу кількість полів, потім непорожність, потім числовий формат, потім змістові обмеження (діапазони, співвідношення). Тільки після успішних перевірок викликайте `int()`/`float()`.

#### 6.4.4. Читання структурованого тексту по рядках

Припустимо, файл `scores.txt` має формат «ім'я;бал;бал» (роздільник — крапка з комою):

```text

Ivan;72;abc
Olena;91;95
```

```python
line_number = 0

with open("scores.txt", "r", encoding="utf-8") as file:
    for line in file:
        line_number += 1
        parts = line.strip().split(";")
        if len(parts) == 3 and parts[1].isdigit() and parts[2].isdigit():
            total = int(parts[1]) + int(parts[2])
            print(f"{parts[0]}: {total}")
        else:
            print(f"Line {line_number}: invalid")
```

Очікуваний результат:

```text

Line 2: invalid
Olena: 186
```

**Пояснення.** Лічильник `line_number` нумерує рядки файлу з 1. Кожен рядок очищується, розбивається на частини й перевіряється; некоректні рядки пропускаються з повідомленням.

#### 6.4.5. Формат CSV та модуль `csv`

**Означення.** **CSV** (Comma-Separated Values) — текстовий формат таблиці: кожен рядок файлу — рядок таблиці, значення розділені комою. Перший рядок найчастіше містить **заголовок** — назви стовпців.

Приклад файлу `scores.csv`:

```text
name,math,physics
Anna,85,90
Ivan,72,abc
Olena,91,95
```

**Чому недостатньо `split(",")`.** Значення може саме містити кому; тоді його беруть у лапки: `"Groceries, market"`. Метод `split(",")` розірве такий рядок неправильно, а модуль `csv` правильно обробляє лапки.

**Модуль `csv`** входить до стандартної бібліотеки; його підключають командою `import csv`.

**Читання.** Функція `csv.reader(file)` створює об'єкт, який у циклі `for` повертає кожен рядок файлу як **список рядків**. Файл для csv відкривають із параметром `newline=""`. Функція `next(reader)` забирає наступний (тут — перший) рядок, її використовують, щоб пропустити заголовок.

```python
import csv

line_number = 1
valid_count = 0
invalid_lines = []

with open("scores.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.reader(file)
    header = next(reader)

    for row in reader:
        line_number += 1
        if len(row) == 3 and row[1].isdigit() and row[2].isdigit():
            valid_count += 1
        else:
            invalid_lines.append(line_number)

print(f"Header: {header}")
print(f"Valid rows: {valid_count}")
print(f"Invalid lines: {invalid_lines}")
```

Очікуваний результат:

```text
Header: ['name', 'math', 'physics']
Valid rows: 2
Invalid lines: [3]
```

**Пояснення.** Заголовок займає рядок 1, тому `line_number` починається з 1 і збільшується на початку кожної ітерації: перший рядок даних має номер 2. Кожен `row` — список із полями, до яких звертаються за індексами. Номери некоректних рядків накопичуються в списку.

**Інший роздільник.** Для файлів із роздільником `;` або табуляцією передають параметр `delimiter`:

```python
reader = csv.reader(file, delimiter=";")
```

**Запис.** Функція `csv.writer(file)` створює об'єкт, метод `writerow(список)` записує один рядок (значення з лапками, якщо потрібно, екранує сам модуль). Файл відкривають у режимі `"w"` також із `newline=""`.

```python
import csv

results = [["Anna", 87.5], ["Olena", 93.0]]

with open("result.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "average"])
    for item in results:
        writer.writerow([item[0], f"{item[1]:.2f}"])
```

Вміст `result.csv`:

```text
name,average
Anna,87.50
Olena,93.00
```

**Типові помилки.**

- Забути `newline=""` при відкритті файлу для `csv`: у вихідному файлі можуть з'явитися зайві порожні рядки.
- Не пропустити заголовок: `int("math")` або `"math".isdigit()` стають джерелом помилки/хибних результатів.
- Забути, що **всі** поля з `csv.reader` — рядки; числа треба перетворювати.
- Звертатися до `row[3]` без перевірки `len(row)`: для короткого рядка — `IndexError`.

#### 6.4.6. Типовий шаблон програми обробки файлу

1. Відкрити вхідний файл, пропустити заголовок.
2. Для кожного рядка: перевірити кількість полів, непорожність і формат чисел. Якщо рядок некоректний — запам'ятати його номер і перейти до наступного. Якщо коректний — перетворити поля й додати їх до підсумків (лічильників, сум, словників).
3. Після циклу обчислити підсумкові показники (середні, мінімуми, найкращі).
4. Записати результати у вихідний файл та/або вивести на екран.

**Некоректні рядки не призводять до завершення програми**: вони пропускаються й обліковуються. Якщо коректних рядків немає, програма виводить `No valid data` і не виконує обчислень (щоб уникнути ділення на нуль).

**Формування рядка з номерами некоректних рядків.** Номери зберігають у списку цілих чисел; щоб з'єднати їх методом `join()`, їх спершу перетворюють на рядки:

```python
invalid_lines = [5, 7, 10]
texts = []
for number in invalid_lines:
    texts.append(str(number))

print(f"Invalid rows: {len(invalid_lines)} (lines: {', '.join(texts)})")
```

Очікуваний результат:

```text
Invalid rows: 3 (lines: 5, 7, 10)
```

### 6.5. Індивідуальні завдання

Номер варіанта визначає викладач. Для кожного варіанта нижче наведено **повний приклад вхідного файлу з реалістичними даними** та очікуваний результат.

#### Загальні правила для всіх варіантів

- Перший рядок файлу — **заголовок** (рядок 1). Рядки даних нумеруються з 2.
- Файли розташовано в одній папці з програмою; вхідний файл відкривається з `encoding="utf-8"`, для CSV — додатково `newline=""`; вихідні файли також відкриваються з `encoding="utf-8"`.
- Для варіантів 1–11 вхідний файл читається модулем `csv` (`csv.reader`), для варіанта 12 — `csv.reader` з параметром `delimiter=";"`.
- Рядок даних **некоректний**, якщо кількість його полів не дорівнює кількості полів заголовка, будь-яке поле порожнє, або числове поле не відповідає опису в умові (використовуйте перевірки з розділу 6.4.3, `isdigit()` для цілих і `replace(".", "", 1).isdigit()` для дійсних). Додаткові обмеження зазначено в умові варіанта.
- Некоректні рядки не впливають на підсумки. Кількість та номери некоректних рядків виводяться у форматі `Invalid rows: k (lines: a, b, c)`; якщо таких рядків немає — `Invalid rows: 0`.
- Якщо коректних рядків немає (наприклад, у файлі лише заголовок), програма виводить `No valid data` замість підсумків (для варіантів із вихідним CSV-файлом у ньому записується лише заголовок).
- Дійсні числа у виводі — з двома знаками після крапки, якщо не зазначено інше.
- Використовуються лише конструкції з робіт №1–6; власні функції, класи, генератори, `try/except` не використовуються. Перевірки «чи число» — лише методами рядків.
- Для кожного варіанта наведено три тести: основний, «лише заголовок» і мінімальний файл.
- У варіанті 12 файл `errors.txt` «порожній» означає, що файл створено, але рядків у ньому немає.

### 6.11. Критерії оцінювання (максимум 10 балів)

| Критерій | Максимум балів | Вимоги для отримання балів |
| -------- | -------------- | -------------------------- |
| Правильність обробки та обчислень | 3 | **3** — підсумкові показники обчислено правильно в усіх тестах (суми, середні, групування, пошук «найкращого», порядок за першою появою). **2** — є помилка в одному показнику або граничному випадку (наприклад, при порожніх даних). **1** — правильна лише частина показників. **0** — обчислення неправильні або програма не запускається. |

### 6.12. Типові помилки, яких варто уникати

1. Не пропущено заголовок CSV — програма намагається перетворити назви стовпців на числа.
2. Перетворення `int()`/`float()` виконується без попередньої перевірки (`ValueError` на некоректному рядку).
3. Звернення до `row[3]` без перевірки `len(row)` (`IndexError` на короткому рядку).
4. Забутий `newline=""` у `open()` для `csv` (зайві порожні рядки у вихідному файлі).
5. Результат методу рядка не збережено (`s.strip()` без присвоювання).
6. Використання `split(",")` для рядків, що містять коми в лапках, замість `csv.reader`.
7. Неправильна нумерація рядків: заголовок не враховано як рядок 1 або лічильник збільшується не на кожній ітерації.
8. Ділення на кількість коректних рядків, коли вона дорівнює нулю (`ZeroDivisionError`).
9. Забутий `encoding="utf-8"` або `"\n"` у кінці рядків вихідного текстового файлу.
10. Порушення порядку виведення (за першою появою ключа), використання нестандартного формату чисел або підписів, відмінних від умови.
